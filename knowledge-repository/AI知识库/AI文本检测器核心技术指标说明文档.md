## 一、背景与基础概念

### 1.1 什么是 AI 文本检测

AI 文本检测（AI Text Detection）指通过算法判断一段文本是「真人撰写」还是「AI 模型生成」的二分类任务。随着 ChatGPT、GLM、文心、通义等大语言模型普及，AI 生成内容（AIGC）充斥网络，催生了对检测工具的需求：

- **教育场景**：判断学生作业是否 AI 代写
- **内容平台**：识别 AI 灌水、洗稿、批量生成的低质内容
- **出版/媒体**：稿件真实性把关
- **SEO 风控**：Google「有用内容更新」会打压 AI 量产内容
- **公众号/头条**：避免被算法判为 AI 内容而限流

### 1.2 检测的根本难题

AI 生成文本与真人文本在表层上几乎无差异，检测器只能依赖**统计层面**的微妙差异：

- AI 走「高概率路径」→ 文本偏「顺」
- 真人写作有「跳跃感」→ 文本偏「乱」

所有指标本质上都在量化「顺」与「乱」的差别。**没有任何单一指标能 100% 判定**，主流检测器都是多指标集成。

### 1.3 三个核心前置概念

| 概念 | 说明 |
|---|---|
| **Token** | 语言模型处理的最小单位，中文一般一个字 ≈ 一个 token，英文一个词 ≈ 1-2 个 token |
| **上下文条件概率** | `P(token_i | token_1...token_{i-1})`，给定前文预测当前 token 的概率 |
| **似然（Likelihood）** | 整段文本在模型下的概率乘积，取对数即对数似然 LL |

## 二、指标分类总览

AI 文本检测指标按技术路线分五大类：

```
┌─────────────────────────────────────────────────┐
│  AI 文本检测指标体系                              │
├─────────────────────────────────────────────────┤
│  ① 语言模型似然类   PPL / LL / Binoculars        │
│  ② 统计分布类       突发度 / TTR / n-gram / 熵   │
│  ③ 扰动对比类       DetectGPT / DNA-GPT / NPR    │
│  ④ 分类器类         RoBERTa / 嵌入向量 / 集成    │
│  ⑤ 可解释特征类     套话词频 / 段首模式 / 数字   │
└─────────────────────────────────────────────────┘
```

| 类别 | 思路 | 优点 | 缺点 |
|---|---|---|---|
| 似然类 | 用 LLM 当裁判量概率 | 准确率高 | 计算成本高 |
| 统计类 | 纯文本特征统计 | 快、轻量 | 易被规避 |
| 扰动类 | 改一改看反应 | 鲁棒性好 | 慢 |
| 分类器类 | 端到端学习 | 综合表现好 | 黑盒、易过拟合 |
| 可解释类 | 人能看懂的特征 | 可解释、可改稿 | 单一准确率低 |

## 三、基于语言模型似然的指标

> 核心思想：**用一个或多个 LLM 当「裁判」，衡量文本是不是这个模型「会自然生成」的**。AI 文本走高概率路径，所以似然偏高、困惑度偏低。

### 3.1 困惑度（Perplexity, PPL）⭐实测主流

#### 定义
模型预测每个 token 的概率的几何平均，取倒数。直观理解：**模型预测这段文本「下一个词」时的「惊讶程度」**。

#### 公式
```
PPL = exp( -1/N · Σ_{i=1}^{N} log P(token_i | context) )
```

#### 判别规则
- **PPL 低** → 模型觉得「意料之中」→ 文本偏「顺」→ 疑似 AI
- **PPL 高** → 模型觉得「没想到」→ 文本有意外感→ 疑似真人

#### 直观例子
句子「今天天气真好，我们去公园 ___」：
- 模型预测：玩 / 散步 / 走走 → 概率高 → PPL 低
- 真人写：「喂蚊子」 → 概率低 → PPL 高

#### 检测器用法
朱雀、GPTZero 等会算**整篇平均 PPL** 和**每句 PPL**：
- 平均 PPL 偏低 → AI 嫌疑
- 每句 PPL 分布均匀（没有忽高忽低）→ AI 嫌疑

#### 局限
- 对短文本不敏感
- 真人写「规范」文本（公文、新闻）也会被判低 PPL，易误伤
- 不同基础模型算出的 PPL 不一样，需选对裁判模型

---

### 3.2 对数似然（Log Likelihood, LL）⭐实测主流

#### 定义
整段文本在参考模型下的对数概率总和。

#### 公式
```
LL = Σ_{i=1}^{N} log P(token_i | context)
```

#### 判别规则
- **LL 高** → 文本命中训练分布 → 疑似 AI
- **LL 低** → 文本偏离训练分布 → 疑似真人

#### 与 PPL 的关系
`PPL = exp(-LL / N)`，本质等价，只是表达方式不同。

#### 跨模型检测
单一模型可能漏检其他模型生成的文本，所以现代检测器会用多个参考模型分别算 LL，取最大值或加权：
```
LL_max = max(LL_GPT, LL_GLM, LL_Llama, LL_Qwen, ...)
```

---

### 3.3 Token 概率均值与方差 ⭐学术经典

#### 定义
所有 token 预测概率的算术平均和方差：
```
mean_prob = 1/N · Σ P(token_i)
var_prob  = 1/N · Σ (P(token_i) - mean_prob)²
```

#### 判别规则
- AI 文本：均值高（如 0.4+），方差小（每词都很「自信」）
- 真人文本：均值低，方差大（有的词很顺，有的词很跳）

---

### 3.4 Binoculars 指标 ⭐学术经典

#### 定义
用两个不同参数量的模型 A（大）、B（小）算同一文本的似然，做比值：
```
Binoculars = LL(模型A) / LL(模型B)
```

#### 判别规则
AI 文本对两个模型的似然比值落在某个区间，真人文本落在另一个区间。

#### 优点
- 零样本（zero-shot），不需要训练数据
- 对中文也有效
- 比 PPL 单值更鲁棒

#### 论文
Hans Schwarzschild 等，2024，*Binoculars: Zero-Shot Detection of Pre-Training Data in LLMs*

---

### 3.5 似然类指标速查

| 指标 | 公式 | AI 表现 | 真人表现 | 主流检测器 |
|---|---|---|---|---|
| PPL | `exp(-LL/N)` | 低 | 高 | GPTZero、朱雀 |
| LL | `Σ log P` | 高 | 低 | 多模型检测 |
| Token 概率均值 | `mean(P)` | 高 | 低 | GLTR 可视化 |
| Token 概率方差 | `var(P)` | 低 | 高 | GLTR 可视化 |
| Binoculars | `LL_A / LL_B` | 偏一侧 | 偏另一侧 | Binoculars |

## 四、基于统计分布的指标

> 核心思想：**不依赖 LLM，纯统计文本特征**。AI 文本天然「均匀、规整」，真人文本天然「跳跃、杂乱」。

### 4.1 突发度（Burstiness）⭐实测主流

#### 定义
**句子级别 PPL（或句长）的波动幅度**。和困惑度是配套指标。

#### 公式
```
Burstiness = var(句子PPL) / mean(句子PPL)
            或
Burstiness = std(句长) / mean(句长)
```

#### 判别规则
- **突发度低** → 每句 PPL/句长接近 → 疑似 AI
- **突发度高** → 有的句子平铺直叙，有的句子突然跳脱 → 疑似真人

#### 为什么重要
人写文章天然「忽长忽短、忽正经忽口语」，AI 写文章天然「均匀」。突发度就是量化这个差异。**GPTZero 把 PPL + Burstiness 作为招牌双指标**。

---

### 4.2 词汇丰富度（Type-Token Ratio, TTR）⭐学术经典

#### 定义
不同词数（type）与总词数（token）之比：
```
TTR = 不同词数 / 总词数
```

#### 判别规则
- AI 文本：TTR 低（爱重复核心词，词汇面窄）
- 真人文本：TTR 高（同一个意思会用不同词表达）

#### 变体（解决文本长度影响）
| 变体 | 算法 |
|---|---|
| MTLA | 移动平均 TTR |
| Herdan's C | `log(V) / log(N)` |
| Maas | `(log N - log V) / log²N` |
| Yule's K | 基于词频分布的复杂度 |

---

### 4.3 n-gram 重复率 ⭐实测主流

#### 定义
连续 2/3/4 个词的重复片段占比：
```
n-gram_repeat = 不同 n-gram 数 / 总 n-gram 数
                或
              = 重复 n-gram 出现次数 / 总 n-gram 数
```

#### 判别规则
- AI 文本：n-gram 重复率高（爱用固定搭配：「值得注意的是」「综上所述」）
- 真人文本：n-gram 重复率低（除非是专业术语复现）

#### 应用
GLTR 工具会按 n-gram 是否常见给文本涂色，越红越像 AI。

---

### 4.4 句长分布熵 ⭐学术经典

#### 定义
句长（按字符/词数计）的香农熵：
```
H(句长) = - Σ p(L_i) · log p(L_i)
```

#### 判别规则
- AI 文本：句长熵低（句长集中在一个区间）
- 真人文本：句长熵高（长短句悬殊）

---

### 4.5 标点熵 ⭐推测存在

#### 定义
标点符号种类的分布熵。

#### 判别规则
- AI 文本：标点熵低（逗号、句号为主，偶尔冒号）
- 真人文本：标点熵高（混入 ——、！、……、（）、～）

---

### 4.6 段落长度熵 ⭐推测存在

#### 定义
段落字符数的分布熵。

#### 判别规则
- AI 文本：段落长度熵低（每段差不多长）
- 真人文本：段落长度熵高（有的段一句，有的段一整段）

---

### 4.7 统计类指标速查

| 指标 | AI 表现 | 真人表现 |
|---|---|---|
| 突发度 | 低 | 高 |
| TTR | 低 | 高 |
| n-gram 重复率 | 高 | 低 |
| 句长熵 | 低 | 高 |
| 标点熵 | 低 | 高 |
| 段落长度熵 | 低 | 高 |

## 五、基于扰动与对比的指标

> 核心思想：**对原文做小改动，看模型反应**。AI 文本是模型的「最优路径」，一改就偏离；真人文本本就不是最优路径，改了无所谓。

### 5.1 扰动 PPL 变化（DetectGPT 核心指标）⭐学术经典

#### 定义
对原文做 k 次掩码填充扰动（用 MLM 替换部分 token），算扰动后 PPL 与原文 PPL 的差：
```
score = mean(PPL_perturbed) - PPL_original
```

#### 判别规则
- **AI 文本**：扰动后 PPL 明显上升（原文是最优路径，一改就偏离）
- **真人文本**：扰动后 PPL 变化小（本来就不是最优路径）

#### 论文
Mitchell et al., 2023, *DetectGPT: Zero-Shot Machine-Generated Text Detection using Probability Curvature*

---

### 5.2 DNA-GPT 指标 ⭐学术经典

#### 定义
让模型续写原文的前半段，对比续写部分和原文后半段的相似度：
```
similarity = sim(模型续写后半段, 原文后半段)
```

#### 判别规则
- **AI 文本**：相似度高（同一模型风格一致）
- **真人文本**：相似度低

---

### 5.3 NPR（Negative Perturbation Ratio）⭐学术经典

#### 定义
扰动后 PPL **下降**的样本占比：
```
NPR = count(PPL_perturbed < PPL_original) / k
```

#### 判别规则
- **AI 文本**：NPR 极低（AI 文本几乎不会扰动后更顺）
- **真人文本**：NPR ≈ 50%（扰动可能让它更顺，也可能更不顺）

---

### 5.4 概率曲率（Probability Curvature）⭐学术经典

#### 定义
DetectGPT 论文提出的几何解释：在文本的 token 概率空间中，AI 文本位于「曲率正」的局部最小值，真人文本位于「曲率平」的区域。

#### 直观理解
AI 文本就像山顶上的小球，一推就滚下去（PPL 上升）；真人文本就像平地上的小球，推一下位置变化不大。

---

### 5.5 扰动类指标速查

| 指标 | AI 表现 | 真人表现 |
|---|---|---|
| 扰动 PPL 变化 | 大 | 小 |
| DNA-GPT 相似度 | 高 | 低 |
| NPR | 极低 | ≈50% |
| 概率曲率 | 正 | 平 |

## 六、基于分类器的指标

> 核心思想：**训一个二分类模型，直接判「AI/真人」**。端到端学习，不依赖单一指标。

### 6.1 RoBERTa / DeBERTa 分类分数 ⭐实测主流

#### 定义
在大量 AI 文本 + 真人文本上微调的判别模型，输出 0-1 概率：
```
P(AI | text) = RoBERTa(text)
```

#### 代表
- OpenAI 自家分类器（已下线，因误伤率高）
- Originality.ai 的核心引擎
- 朱雀底层大概率有这一层

#### 优点
- 综合表现好，能学到人难以定义的特征
- 推理快

#### 缺点
- 黑盒，不可解释
- 易过拟合到训练时的模型版本（GPT-3.5 训的分类器检测 GPT-4 会失效）
- 对抗样本脆弱

---

### 6.2 嵌入向量距离 ⭐实测主流

#### 定义
用 Sentence-BERT、BGE 等编码器把文本编码成向量，对比 AI 生成文本向量库的余弦相似度：
```
sim = cosine(Embed(text), centroid_AI_corpus)
```

#### 判别规则
- AI 文本：相似度高（落在一个聚类中心附近）
- 真人文本：分散，远离聚类中心

#### 应用
Originality.ai、Copyleaks 等使用，常作为集成的一部分。

---

### 6.3 多模型集成分数（Ensemble）⭐实测主流

#### 定义
综合 PPL、突发度、分类器、扰动等多指标，加权或训一个 meta 分类器：
```
score = w1·PPL + w2·Burstiness + w3·Classifier + w4·Perturbation + ...
```

#### 代表
朱雀大概率是这类，覆盖面广但解释性弱。集成方式：
- **加权平均**：人工设定权重
- **Stacking**：用 meta 模型学习权重
- **Voting**：多指标投票

---

### 6.4 分类器类指标速查

| 指标 | 输出 | 优点 | 缺点 |
|---|---|---|---|
| RoBERTa 分类 | 0-1 概率 | 综合强 | 黑盒 |
| 嵌入向量距离 | 相似度 | 跨语言 | 依赖向量库 |
| 集成分数 | 0-1 概率 | 鲁棒 | 解释弱 |

## 七、基于可解释特征的指标

> 核心思想：**把「AI 味」拆成人能看懂的特征，再做统计判别**。可解释、可改稿，但单一准确率低，常作为辅助。

### 7.1 高频 AI 套话词频 ⭐实测主流

#### 定义
统计黑名单词的出现频率。这些词在 AI 生成文本中显著过 represented。

#### 黑名单词表

**连接词类**：
- 综上所述、总而言之、值得注意的是
- 不仅……而且、与此同时、在此基础上
- 然而、尽管如此、与此同时

**程度副词类**：
- 显著、明显、极大、有效、充分、切实

**抽象名词类**：
- 方面、角度、层面、维度、关键、核心、重要

**评价套话类**：
- 至关重要、不可或缺、行之有效、意义重大、前景广阔

**结尾升华类**：
- 让我们一起、相信在……的助力下、期待……、赋能、助力

#### 判别规则
黑名单词频越高，AI 嫌疑越大。**朱雀这类国产检测器权重较大**。

---

### 7.2 段落首句模式熵 ⭐推测存在

#### 定义
所有段落首句的句法结构多样性。

#### 判别规则
- AI 文本：段首模式熵低（爱用「主语+是/有/可以」起句）
- 真人文本：段首模式熵高（语气词、时间状语、问句混用）

#### 例子
AI 写法的段首：
> 猫是肉食动物。
> 猫粮是主要食物。
> 水是必需品。

真人写法的段首：
> 说真的，我以前也以为猫只吃猫粮就行。
> 去年双十一，我囤了一堆 9.9 的猫粮。
> 结果呢？主子拉稀拉了三天。

---

### 7.3 数字出现方式 ⭐推测存在

#### 定义
区分「结构化数字」和「叙事数字」：
- 结构化数字：3 种方法、5 个要点、7 大原则
- 叙事数字：9.9 元、买了三袋、花了 200 块、凌晨三点

#### 判别规则
- AI 文本：结构化数字多
- 真人文本：叙事数字多

---

### 7.4 个人化信号强度 ⭐实测主流

#### 定义
以下信号的出现密度：
- 第一人称（我、我们、我家）
- 具体时间地点（去年双十一、凌晨三点、小区门口宠物店）
- 品牌/型号（皇家、GO!、网易严选饮水机）
- 情绪词（踩雷、真香、崩溃、庆幸）
- 失败经历（拉稀、退货、客服已读不回）

#### 判别规则
- AI 文本：个人化信号弱
- 真人文本：个人化信号强

---

### 7.5 排比密度 ⭐推测存在

#### 定义
连续三句以上相同句式的占比。

#### 判别规则
- AI 文本：排比密度高（爱用排比凑字数）
- 真人文本：排比密度低（偶尔用，更多散句）

---

### 7.6 信息均匀度 ⭐推测存在

#### 定义
每段信息密度的方差。

#### 判别规则
- AI 文本：信息均匀度高（每段信息量相当）
- 真人文本：信息均匀度低（有的段密集数据，有的段纯闲笔）

---

### 7.7 可解释类指标速查

| 指标 | AI 表现 | 真人表现 |
|---|---|---|
| 套话词频 | 高 | 低 |
| 段首模式熵 | 低 | 高 |
| 数字方式 | 结构化 | 叙事化 |
| 个人化信号 | 弱 | 强 |
| 排比密度 | 高 | 低 |
| 信息均匀度 | 均匀 | 不均匀 |

## 八、主流检测器指标对照

### 8.1 检测器指标依赖表

| 检测器 | 主要指标 | 特色 | 局限 |
|---|---|---|---|
| **GPTZero** | PPL + 突发度 | 经典双指标，英文准 | 中文一般 |
| **DetectGPT** | 扰动 PPL 变化 | 鲁棒、零样本 | 慢 |
| **Binoculars** | 双模型似然比 | 零样本，中文有效 | 需大模型 |
| **GLTR** | Token 概率可视化 | 直观、可解释 | 不输出分数 |
| **OpenAI Classifier** | RoBERTa 分类器 | 官方出身 | 已下线，误伤高 |
| **Originality.ai** | 集成（分类器+嵌入+统计） | 综合强 | 付费、英文为主 |
| **Copyleaks** | 集成 | 跨语言 | 付费 |
| **朱雀（腾讯）** | 集成 + 中文套话词频 + 段首模式 | 中文最准、国产 | 黑盒 |
| **Winston AI** | 集成 | 教育场景 | 付费 |

### 8.2 检测器选择建议

| 场景 | 推荐检测器 |
|---|---|
| 中文公众号过审 | 朱雀（最对症） |
| 英文学术作业 | GPTZero + Originality.ai |
| 跨语言内容风控 | Copyleaks |
| 需要可解释改稿 | GLTR + 人工查套话词 |
| 零样本、低成本 | Binoculars 自部署 |

### 8.3 检测器的局限

所有检测器都存在以下问题，使用时需警惕：

1. **误伤率**：真人写「规范」文本（公文、新闻、学术）易被判 AI
2. **漏检率**：经过润色、改写、混合的 AI 文本可绕过
3. **模型版本漂移**：检测器针对旧模型训练，对新模型失效
4. **短文本不准**：低于 200 字的文本所有指标都不稳
5. **语言依赖**：多数检测器对英文准，中文次之，小语种差
6. **对抗攻击**：故意插入低概率词、改句长可绕过

## 九、实战：如何降低 AI 检测分

> 本节从「写作策略」角度反推指标，给出可操作的改稿方向。**仅用于合法的内容创作场景，不鼓励学术不端或欺骗性使用。**

### 9.1 按「似然类」改稿

| 目标 | 策略 | 具体做法 |
|---|---|---|
| 提高 PPL | 塞反预期表达 | 「喂蚊子」「踩了个寂寞」「主子翻脸」 |
| 提高 PPL 方差 | 让有的句子很顺，有的句子很跳 | 平铺直叙段后接一句口语吐槽 |
| 降低对数似然 | 写训练数据里少见的组合 | 「9.9 猫粮+拉稀+客服已读不回」连写 |

### 9.2 按「统计类」改稿

| 目标 | 策略 | 具体做法 |
|---|---|---|
| 提高突发度 | 句长悬殊 | 一句 5 字 + 一句 80 字交替 |
| 提高 TTR | 同义词轮换 | 「猫粮」→「粮」「主子口粮」「这玩意儿」 |
| 降低 n-gram 重复 | 避开固定搭配 | 删「综上所述」「值得注意的是」 |
| 提高句长熵 | 长短句交错 | 短句断段、长句铺陈 |
| 提高标点熵 | 用多种标点 | 加 ——、！、……、（） |
| 提高段落长度熵 | 段落长度悬殊 | 有的段一句，有的段一整段 |

### 9.3 按「扰动类」改稿

扰动类指标主要靠「让文本不是模型的最优路径」，做法和似然类一致：

- 多用低概率词
- 故意打破搭配习惯
- 加入口语化、地域化表达

### 9.4 按「分类器类」改稿

分类器是黑盒，对抗手段有限，主要靠：

- **混合写作**：AI 生成初稿 + 人工重写 60% 以上
- **风格迁移**：用风格转换工具把 AI 文本转成「口语风格」
- **多次润色**：每轮润色都让 PPL 上升一点

### 9.5 按「可解释类」改稿

| 目标 | 策略 | 具体做法 |
|---|---|---|
| 降低套话词频 | 删黑名单词 | 全文搜「综上」「值得注意」全删 |
| 提高段首模式熵 | 多样化段首 | 语气词、时间状语、问句、感叹句混用 |
| 数字叙事化 | 把结构化数字改叙事 | 「3 种方法」→「我试过三种，第一种就翻车」 |
| 增强个人化信号 | 加具体细节 | 时间、地点、品牌、型号、价格、情绪 |
| 降低排比密度 | 拆排比 | 三句排比改成一句结论 + 一句例子 |
| 打破信息均匀度 | 加闲笔 | 数据段后插一段「话说」「扯远了」 |

### 9.6 改稿检查清单

改完稿子后，按以下清单自查（对照本文档第七节指标）：

- [ ] 全文无「综上所述」「值得注意的是」「不仅……而且」
- [ ] 段落首句句法结构多样化
- [ ] 句长有悬殊（最短句 < 10 字，最长句 > 50 字）
- [ ] 标点多样（至少出现 ——、！、…… 中的两种）
- [ ] 段落长度悬殊（最短段 < 30 字，最长段 > 200 字）
- [ ] 包含第一人称视角
- [ ] 包含具体时间地点
- [ ] 包含具体品牌/型号/价格
- [] 包含至少一处失败经历或踩坑
- [ ] 数字以叙事数字为主（9.9 元、买了三袋），非结构化数字
- [ ] 有反预期表达（让 PPL 上升的「跳」句）
- [ ] 核心词有同义词轮换，不重复
- [ ] 排比密度低（连续三句以上排比不超过 2 处）
- [ ] 信息密度不均匀（有密集数据段，有纯闲笔段）

## 十、术语表

| 术语 | 英文 | 说明 |
|---|---|---|
| 困惑度 | Perplexity, PPL | 模型预测文本的「惊讶程度」，越低越像 AI |
| 对数似然 | Log Likelihood, LL | 文本在模型下的对数概率，越高越像 AI |
| 突发度 | Burstiness | 句子间 PPL/句长的波动幅度，越低越像 AI |
| 词汇丰富度 | Type-Token Ratio, TTR | 不同词/总词数，越低越像 AI |
| n-gram | n-gram | 连续 n 个词的片段 |
| 香农熵 | Shannon Entropy | 分布的不确定度，越低越规整 |
| 扰动 | Perturbation | 对文本做小改动 |
| 掩码填充 | Masked Language Modeling, MLM | 随机遮盖 token 让模型补全 |
| 零样本 | Zero-shot | 不需训练数据即可检测 |
| 嵌入向量 | Embedding | 文本的向量表示 |
| 余弦相似度 | Cosine Similarity | 两向量方向的相似度 |
| Token | Token | 语言模型最小处理单位 |
| 上下文条件概率 | Conditional Probability | `P(token_i | context)` |
| 概率曲率 | Probability Curvature | 文本在概率空间的几何特征 |
| 集成 | Ensemble | 多指标融合 |
