## 九、推荐学习顺序（建议按此顺序推进）

1. 先通读《大规模语言模型：从理论到实践》前 5 章 → 建立 LLM 全貌
2. 跟做 HuggingFace NLP Course → 掌握 Transformers 库
3. 用 LLaMA-Factory 跑一次 LoRA 微调 → 理解训练流程
4. 学习 LangChain 官方文档 → 搭建第一个 RAG
5. 学习 MCP 官方文档 → 实现 MCP Server
6. 学习 vLLM → 部署模型 API
7. 持续读论文 + 写博客输出
