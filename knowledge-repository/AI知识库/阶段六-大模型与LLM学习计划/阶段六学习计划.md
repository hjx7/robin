# 阶段六：大模型与 LLM 学习计划 [[学习资料清单]] [[推荐项目实战]]

> 本计划基于《AI学习路线图.md》阶段六制定，目标是从零系统掌握大语言模型的理论、微调、应用开发与工程实践。

---

## 一、学习目标

完成本阶段学习后，你应当能够：

1. 理解 Transformer / Decoder-only 架构与 LLM 预训练原理
2. 使用 HuggingFace Transformers 加载、推理主流开源模型
3. 使用 LoRA / QLoRA 完成模型微调（SFT）
4. 独立搭建 RAG 检索增强生成系统
5. 开发基于 Agent + MCP + Skills 的应用
6. 完成大模型推理部署与优化

---

## 二、学习阶段拆分（共 6 个 Module）

### Module 1：LLM 基础理论（1-2 周）

**目标**：建立对大语言模型的整体认知。

**学习内容**：
- Transformer 架构回顾（Self-Attention、Multi-Head、Positional Encoding）
- Decoder-only 架构详解（GPT 系列）
- 预训练范式：CLM（因果语言建模）、MLM（掩码语言建模）
- Scaling Law 与涌现能力（Emergent Abilities）
- Tokenizer 原理：BPE、WordPiece、SentencePiece
- 上下文窗口、KV-Cache 原理

**产出**：能用自己的语言讲清「LLM 是如何被训练出来的」。

---

### Module 2：开源模型与工具链（1-2 周）

**目标**：掌握主流开源模型的使用方法。

**学习内容**：
- 主流开源模型对比：LLaMA、Qwen、ChatGLM、Mistral、Baichuan、DeepSeek
- HuggingFace 生态：Transformers、Datasets、Tokenizer、Accelerate
- 模型加载与推理：`from_pretrained`、`generate`、采样参数（temperature、top-p、top-k）
- 量化推理：bitsandbytes、GPTQ、AWQ
- GGUF 格式与 llama.cpp 本地部署

**产出**：在本地或 Colab 成功运行一个开源模型并完成对话推理。

---

### Module 3：微调技术 SFT & PEFT（2-3 周）

**目标**：掌握让模型「听话」的核心技术。

**学习内容**：
- 全参微调（Full Fine-tuning）流程与数据格式
- 指令微调（SFT）数据构造：alpaca、sharegpt 格式
- **PEFT 技术**：
  - LoRA 原理与实现
  - QLoRA（4bit 量化 + LoRA）
  - Adapter、P-Tuning v2、Prompt Tuning
- 训练框架：Transformers Trainer、LLaMA-Factory、Axolotl
- 分布式微调入门：DeepSpeed、FSDP

**产出**：使用 LoRA 在垂直领域数据集上完成一次完整的微调训练。

---

### Module 4：对齐技术 RLHF & DPO（1-2 周）

**目标**：理解如何让模型输出符合人类偏好。

**学习内容**：
- RLHF 完整流程：SFT → RM（奖励模型）→ PPO
- DPO（Direct Preference Optimization）原理与实现
- 其他对齐方法：KTO、ORPO、SimPO
- 偏好数据集构造方法

**产出**：理解 RLHF 与 DPO 的差异，能使用trl库跑通一次 DPO 训练。

---

### Module 5：应用开发（3-4 周，核心重点）

**目标**：将 LLM 落地为实际应用。

#### 5.1 Prompt Engineering
- Zero-shot / Few-shot Prompting
- Chain-of-Thought (CoT)
- ReAct 框架
- 自我一致性（Self-Consistency）

#### 5.2 RAG（检索增强生成）
- 文档切分策略（chunk size、overlap）
- Embedding 模型：bge、e5、OpenAI embeddings
- 向量数据库：FAISS、Milvus、Chroma、Qdrant
- 检索策略：稠密检索、稀疏检索、混合检索
- RAG 框架：LangChain、LlamaIndex
- 进阶：Rerank、Self-RAG、GraphRAG

#### 5.3 Agent 与工具调用
- Agent 基本概念：Planning、Memory、Tools
- ReAct Agent 实现原理
- 多智能体框架：AutoGen、MetaGPT、CrewAI
- LangGraph 状态机式 Agent

#### 5.4 Function Calling & MCP
- Function Calling：OpenAI 格式、工具描述规范
- **MCP（Model Context Protocol）**：
  - 架构理解：Client、Server、Host
  - Tools / Resources / Prompts 三类原语
  - 用 Python / TypeScript 实现 MCP Server
  - 与 Claude Desktop、Cursor 等 Host 集成

#### 5.5 Skills（能力封装）
- Skills 概念：将特定领域能力标准化封装为 Agent 可调用的技能模块
- Skills 与 Tools / Plugins 的关系
- Skills 设计原则：单一职责、可组合、可复用
- Skills 的描述规范与注册机制
- 实践：为一个 Agent 编写并注册一组 Skills（如「文档总结」「代码生成」「数据查询」）

**产出**：
1. 搭建一个完整的 RAG 知识库问答系统
2. 开发一个具备工具调用能力的 Agent
3. 实现一个 MCP Server 或 Skill 包

---

### Module 6：推理优化与部署（2 周）

**目标**：让模型在生产环境高效运行。

**学习内容**：
- 推理加速框架对比：vLLM、TGI、TensorRT-LLM、SGLang
- 量化部署：INT8 / INT4、GPTQ、AWQ、GGUF
- 服务化部署：FastAPI + vLLM、Triton Inference Server
- 监控与日志：Token 吞吐、延迟、GPU 利用率
- 端侧部署：llama.cpp、Ollama、MLC-LLM

**产出**：使用 vLLM 部署一个模型 API 服务并完成压测。

## 五、学习原则

1. **理论够用即可**：不要陷入数学推导，优先理解工程实现
2. **先跑通再优化**：先复现 demo，再深入细节
3. **优先官方文档**：HuggingFace、LangChain、vLLM 官方文档质量很高
4. **持续关注前沿**：LLM 技术迭代快，关注 arXiv、GitHub Trending
5. **动手写代码**：每个 Module 都要有可运行的代码产出
