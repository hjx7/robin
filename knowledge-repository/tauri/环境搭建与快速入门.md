## 系统要求

### 通用要求
- **Node.js**：>= 18.0.0（推荐使用 LTS 版本）
- **Rust**：>= 1.70.0（stable 版本）
- **包管理器**：npm >= 9 / pnpm >= 8 / yarn >= 1.22

### 各平台特定要求
| 平台 | WebView 引擎 | 最低系统版本 |
|------|-------------|-------------|
| Windows | WebView2 (Edge Chromium) | Windows 10 1809+ |
| macOS | WKWebView | macOS 10.15+ (Catalina) |
| Linux | WebKitGTK | 大多数现代发行版 |

## Windows 环境搭建

### 步骤 1：安装 Microsoft Visual Studio C++ Build Tools

Tauri 在 Windows 上需要 C++ 构建工具来编译 Rust 代码和原生组件。

1. 下载 [Visual Studio Build Tools 2022](https://visualstudio.microsoft.com/visual-cpp-build-tools/)
2. 安装时选择以下工作负载：
   - ✅ **使用 C++ 的桌面开发** (Desktop development with C++)
   - ✅ 确保包含 **Windows 10 SDK**（或 Windows 11 SDK，根据您的系统）
   - ✅ **MSVC v143 - VS 2022 C++ x64/x86 生成工具**

> 💡 安装包较大（约 6-8GB），请确保有足够的磁盘空间。

### 步骤 2：安装 WebView2（Windows 10 1809 之前版本）

Windows 10 2004+ 和 Windows 11 已内置 WebView2。如果您的系统较旧，需要手动安装：

- 下载并安装 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/#download-section)（选择 **Evergreen Bootstrapper**）

### 步骤 3：安装 Rust

访问 [https://www.rust-lang.org/tools/install](https://www.rust-lang.org/tools/install)，下载并运行 `rustup-init.exe`：

```powershell
# 安装完成后，验证安装
rustc --version
cargo --version
```

> 💡 Rustup 会自动配置环境变量，安装完成后需重新打开终端。

### 步骤 4：安装 Node.js

推荐使用 [nvm-windows](https://github.com/coreybutler/nvm-windows) 管理 Node.js 版本：

```powershell
# 安装 Node.js LTS 版本
nvm install 20
nvm use 20

# 验证安装
node --version  # 应输出 v20.x.x
npm --version
```

或直接从 [Node.js 官网](https://nodejs.org/) 下载安装。

### 步骤 5：配置 Rust 国内镜像（可选，加速下载）

在 `%USERPROFILE%\.cargo\config.toml` 中添加：

```toml
[source.crates-io]
replace-with = 'rsproxy'

[source.rsproxy]
registry = "https://rsproxy.cn/crates.io-index"

[registries.rsproxy]
index = "https://rsproxy.cn/crates.io-index"

[net]
git-fetch-with-cli = true
```

## macOS 环境搭建

### 步骤 1：安装 Xcode Command Line Tools

```bash
xcode-select --install
```

如果弹出安装窗口，点击「安装」即可。

### 步骤 2：安装 Rust

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

安装过程中选择默认选项（1）即可。安装完成后：

```bash
source $HOME/.cargo/env
rustc --version
```

### 步骤 3：安装 Node.js

推荐使用 nvm：

```bash
# 使用 Homebrew 安装 nvm
brew install nvm
mkdir ~/.nvm

# 在 ~/.zshrc 或 ~/.bash_profile 中添加：
export NVM_DIR="$HOME/.nvm"
[ -s "/usr/local/opt/nvm/nvm.sh" ] && . "/usr/local/opt/nvm/nvm.sh"

# 安装 Node.js
nvm install 20
nvm use 20
node --version
```

### 步骤 4：安装其他依赖

```bash
# macOS 通常不需要额外依赖，确保系统已更新到最新版本
softwareupdate --install --all
```

## Linux 环境搭建

### Ubuntu / Debian 系

```bash
# 安装系统依赖
sudo apt update
sudo apt install -y \
    libwebkit2gtk-4.1-dev \
    build-essential \
    curl \
    wget \
    file \
    libxdo-dev \
    libssl-dev \
    libayatana-appindicator3-dev \
    librsvg2-dev \
    libglib2.0-dev \
    libgtk-3-dev
```

### Fedora / RHEL 系

```bash
sudo dnf install -y \
    webkit2gtk4.1-devel \
    openssl-devel \
    curl \
    wget \
    file \
    libX11-devel \
    libXtst-devel \
    libayatana-appindicator3-devel \
    librsvg2-devel \
    cairo-devel \
    pango-devel \
    gtk3-devel \
    glib2-devel
```

### Arch Linux

```bash
sudo pacman -Syu --needed \
    webkit2gtk \
    base-devel \
    curl \
    wget \
    file \
    openssl \
    libappindicator-gtk3 \
    librsvg \
    gtk3
```

### 安装 Rust 和 Node.js

```bash
# Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source $HOME/.cargo/env

# Node.js（使用 nvm）
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
source ~/.bashrc  # 或 source ~/.zshrc
nvm install 20
```

## 创建新项目

### 方式一：使用 create-tauri-app（推荐）

进入项目目录，运行以下命令创建 MyCubby 项目：

```bash
# 进入工作目录
cd g:\program

# 使用 pnpm（推荐）
pnpm create tauri-app@2 MyCubby

# 或使用 npm
npm create tauri-app@2 MyCubby

# 或使用 yarn
yarn create tauri-app MyCubby
```

交互式配置选项参考：

```
✔ Project name (MyCubby) · MyCubby
✔ Choose which language to use for your frontend · TypeScript / JavaScript
✔ Choose your package manager · pnpm
✔ Choose your UI template · Vue (推荐)
  - Vanilla (纯原生 JS/CSS)
  - Vue
  - React
  - Svelte
  - Solid
  - Angular
✔ Choose your UI flavor · TypeScript
✔ Would you like to setup the Rust Tauri project now? · Yes
```

> 💡 本文档后续示例默认使用 **Vue 3 + TypeScript** 前端框架。如果选择了其他框架，部分前端代码示例需要适当调整。

### 方式二：在现有前端项目中添加 Tauri

如果您已经有一个前端项目（如 Vite + Vue 项目），可以按以下步骤集成 Tauri：

```bash
# 1. 进入现有项目目录
cd g:\program\MyCubby

# 2. 安装 Tauri CLI
pnpm add -D @tauri-apps/cli@2

# 3. 初始化 Tauri
pnpm tauri init
```

交互式配置：

```
✔ What is your app name? · MyCubby
✔ What should the window title be? · MyCubby
✔ Where are your web assets (HTML/CSS/JS) located? · ../dist
✔ What is the URL of your dev server? · http://localhost:5173
✔ What is your frontend dev command? · pnpm dev
✔ What is your frontend build command? · pnpm build
```

## 启动开发模式

### 进入项目目录

```bash
cd g:\program\MyCubby
```

### 安装前端依赖

```bash
pnpm install
# 或
npm install
# 或
yarn install
```

### 启动开发服务器

```bash
pnpm tauri dev
# 或
npm run tauri dev
# 或
yarn tauri dev
```

首次运行会：
1. 下载并编译 Rust 依赖（首次较慢，后续会使用缓存）
2. 启动前端开发服务器
3. 编译并启动 Tauri 应用窗口

如果一切顺利，您将看到 Tauri 应用窗口，显示欢迎页面。

### 开发模式特性

- **前端热重载**：修改 `src/` 下的前端代码，界面会自动刷新
- **Rust 自动重编译**：修改 `src-tauri/src/` 下的 Rust 代码，应用会自动重新编译并重启
- **DevTools**：按 `F12` 或 `Ctrl+Shift+I` 打开开发者工具（Windows/Linux），`Cmd+Opt+I`（macOS）

## 常用命令速查

### 开发与调试

| 命令 | 说明 |
|------|------|
| `pnpm tauri dev` | 启动开发模式（含前端热重载） |
| `pnpm tauri dev -- --no-watch` | 启动开发模式，不监听文件变化 |
| `pnpm tauri dev --debug` | 启动调试模式，输出详细日志 |

### 构建与打包

| 命令 | 说明 |
|------|------|
| `pnpm tauri build` | 构建生产版本并打包 |
| `pnpm tauri build --debug` | 构建调试版本（包含调试符号） |
| `pnpm tauri build --verbose` | 构建时输出详细日志 |
| `pnpm tauri build --bundles msi` | 仅构建指定格式的安装包 |

支持的打包格式（`--bundles`）：
- `all`：构建所有可用格式（默认）
- `msi`：Windows 安装程序 (.msi)
- `nsis`：Windows NSIS 安装程序 (.exe)
- `deb`：Debian/Ubuntu 包 (.deb)
- `rpm`：Fedora/RHEL 包 (.rpm)
- `appimage`：Linux AppImage
- `dmg`：macOS 磁盘映像 (.dmg)

### 项目管理

| 命令 | 说明 |
|------|------|
| `pnpm tauri icon ./path/to/icon.png` | 自动生成各平台应用图标 |
| `pnpm tauri info` | 查看 Tauri 环境信息 |
| `pnpm tauri migrate` | 升级 Tauri 配置到新版本 |
| `cargo update -p tauri` | 升级 Tauri Rust 依赖 |

### 自定义命令

可在 `package.json` 的 `scripts` 中添加自定义命令：

```json
{
  "scripts": {
    "dev": "vite",
    "build": "vue-tsc --noEmit && vite build",
    "preview": "vite preview",
    "tauri": "tauri",
    "tauri:dev": "tauri dev",
    "tauri:build": "tauri build",
    "tauri:build:debug": "tauri build --debug",
    "tauri:build:msi": "tauri build --bundles msi",
    "tauri:info": "tauri info"
  }
}
```

使用方式：

```bash
pnpm tauri:dev     # 等同于 pnpm tauri dev
pnpm tauri:build   # 等同于 pnpm tauri build
```

## 验证环境

环境搭建完成后，运行以下命令验证所有组件是否正常安装：

```bash
# 验证 Rust
rustc --version   # 应输出 rustc 1.7x.x (xxxxxxx 202x-xx-xx)
cargo --version   # 应输出 cargo 1.7x.x (xxxxxxx 202x-xx-xx)

# 验证 Node.js
node --version    # 应输出 v18.x.x 或更高
pnpm --version    # 应输出 8.x.x 或更高（或 npm/yarn 对应版本）

# 验证 Tauri（在项目目录下）
pnpm tauri info
```
