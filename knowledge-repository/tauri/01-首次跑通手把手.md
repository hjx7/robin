# 01-首次跑通手把手：从空目录到弹出 Tauri 窗口

> 这是一份"照着做不出错"的傻瓜式手册。如果你在第 2 天按照路线图跑 `tauri dev` 时遇到任何问题，回到这份文档一步一步对照。

---

## 1. 先做"体检"：环境检查清单

在创建任何项目之前，先在一个**新打开的终端窗口**里（重点：新的，不是装环境之前就开着的那一个），一条一条执行以下命令。所有输出都正常，再往下走。

| 步骤 | 你输入的命令 | 正常输出长什么样 | 不通过怎么办 |
| :--- | :--- | :--- | :--- |
| ① Node.js | `node --version` | `v20.17.0` 或更高（v18 也行，但低于 18 不行） | 装 Node.js 20 LTS，用 nvm 管理 |
| ② npm / pnpm | `pnpm --version`（或 `npm --version`） | `pnpm 9.12.x` 或 `npm 10.x` | 没装 pnpm 的话：`npm i -g pnpm` |
| ③ Rustc 编译器 | `rustc --version` | `rustc 1.8x.x (xxxxx 202x-xx-xx)` | 没装的话去 rustup.rs 下载运行 |
| ④ Cargo 包管理器 | `cargo --version` | `cargo 1.8x.x`（跟 rustc 版本号一般一致） | 同上，rustup 会一起装 |
| ⑤ VSCode | 打开 VSCode → 扩展面板 | 能看到 `rust-analyzer`、`Tauri-VSCode`、`Even Better TOML` 这三个扩展已启用 | 没装的去扩展市场搜名字直接装 |

> Windows 用户额外检查：
> - VS Build Tools 是否装了「使用 C++ 的桌面开发」：打开 "Visual Studio Installer" → 修改 → 工作负载页，第一个勾是不是亮的。
> - WebView2：Win+R 运行 `reg query "HKLM\SOFTWARE\WOW6432Node\Microsoft\EdgeUpdate\Clients\{F3017226-FE2A-4295-8BDF-00C3A9A7E4C5}" /v pv`，能查到类似 `12x.x.xxx.x` 的版本号就是有。查不到就去装 WebView2 Evergreen Bootstrapper。

## 2. Windows 用户完整分步（最常见的平台）

### 2.1 配置 Rust 国内镜像（强烈建议）

这步不做，第一次编译大概率因为超时失败。

按下 Win+R，输入 `%USERPROFILE%` 回车，进入你自己的用户目录（一般是 `C:\Users\你的名字\`）。

1. 如果看不到 `.cargo` 文件夹，就新建一个（文件夹名必须是 `.cargo.` 后面加个点，Win10+ 会自动去掉末尾那个点变成 `.cargo`）
2. 进 `.cargo` 目录，新建一个叫 `config.toml` 的文件（注意不是 `.toml.txt`，要开文件扩展名显示）
3. 用 VSCode 打开 `config.toml`，复制粘贴以下内容并保存：

```toml
[source.crates-io]
replace-with = 'rsproxy'

[source.rsproxy]
registry = "https://rsproxy.cn/crates.io-index"

[registries.rsproxy]
index = "https://rsproxy.cn/crates.io-index"

[net]
git-fetch-with-cli = true
```

### 2.2 创建项目

打开一个 PowerShell 或 Windows Terminal 窗口（**不要用 cmd.exe**，Tauri 的某些交互命令在 cmd 下不显示选项），cd 到你打算放项目的目录（比如 `E:\projects`，提前建好）。

执行：

```powershell
cd E:\projects
pnpm create tauri-app@2 my-first-app
```

然后会出来一串交互式问题，**必须严格按照下面选**（别自己瞎选不认识的选项）：

```
✔ Project name (my-first-app) · my-first-app        # 直接回车
✔ Choose which language to use for your frontend · TypeScript / JavaScript   # 光标停这一行回车
✔ Choose your package manager · pnpm               # 用哪个选哪个
✔ Choose your UI template · Vue                     # 第一次用强烈推荐 Vue，坑最少
✔ Choose your UI flavor · TypeScript                # 直接回车
✔ Would you like to setup the Rust Tauri project now? · Yes   # 必须选 Yes
```

看到 `Done! Now run:` 和两行命令说明创建成功了。

**如果卡在 `Installing frontend dependencies` 超过 5 分钟：**
- 按 Ctrl+C 中断
- 手动 `cd my-first-app ; pnpm install`
- 然后手动跑 `pnpm tauri init`（一般会自动识别前端目录）

### 2.3 启动开发模式

```powershell
cd my-first-app
pnpm tauri dev
```

启动过程分四个阶段，每个阶段都有特征：

| 阶段 | 你看到的终端提示 | 耗时 |
| :--- | :--- | :--- |
| 1. 跑前端 dev | `VITE v5.4.x ready in xxx ms → Local: http://localhost:5173/` | 5 秒内 |
| 2. 下载 Rust 依赖 | `Updating crates.io index` + 一堆 `Compiling xxx vx.y.z` | 第一次 5-10 分钟（配了镜像）/ 20-30 分钟（没配） |
| 3. 编译 Rust | `Compiling mycubby v0.1.0 (E:\projects\my-first-app\src-tauri)` | 第一次 3-8 分钟 |
| 4. 打开窗口 | `Finished dev [unoptimized + debuginfo] target(s)` | 3 秒内，桌面弹出一个窗口 |

期间 CPU 跑到 80-100%、风扇狂转，都是**正常的**，千万别关终端。

### 2.4 看到窗口之后的 5 个验证

1. **窗口标题**：标题栏显示 `my-first-app` ✓
2. **欢迎页**：页面中间有个大的 Tauri 绿色图标 ✓
3. **热重载**：VSCode 打开 `src/App.vue`，把 `<h1>` 里的 "Welcome" 改成 "你好 Tauri"，Ctrl+S，窗口文字立刻变了 ✓
4. **DevTools**：窗口内按 F12，弹出开发者工具，Console 栏里全是白字（没有红色 Error）✓
5. **Greet 交互**：在输入框里输入你的名字，点「Greet」按钮，下面显示 `你好, 你的名字！` ✓

5 条全满足 → 首次跑通成功。
缺任何一条 → 去看第 6 节报错排查表。

### 2.5 第一次打包

先去 [iconduck.com](https://iconduck.com/) 找一张 1024×1024 的 PNG 图标（搜任何你喜欢的关键词，download 选「PNG 1024」），存到项目根目录叫 `icon-1024.png`。

```powershell
pnpm tauri icon ./icon-1024.png
```

控制台输出一堆 `Generating icon.ico / icon.icns / ...` 就是成功了。

然后打包：

```powershell
pnpm tauri build --bundles nsis
```

只打 NSIS 安装包（用户最常双击那种 `.exe` 安装程序），比打全平台快点。

编译完成后安装包在这里：
`E:\projects\my-first-app\src-tauri\target\release\bundle\nsis\My-First-App_0.1.0_x64-setup.exe`

大小一般在 8-14MB 之间，正常。发给朋友双击安装就行。

## 3. macOS 用户完整分步

### 3.1 前置准备

打开 Terminal（终端）：

```bash
# 1. 装 Xcode 命令行工具
xcode-select --install
# 弹安装窗口，点「安装」，等几分钟

# 2. 装 Homebrew（没装过的话）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 3. 装 nvm 和 Rust
brew install nvm
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh   # 一路选 1 默认
source $HOME/.cargo/env

# 4. 用 nvm 装 Node.js 20
mkdir ~/.nvm
# 把下面两行加到 ~/.zshrc 或 ~/.bash_profile
export NVM_DIR="$HOME/.nvm"
[ -s "$(brew --prefix nvm)/nvm.sh" ] && . "$(brew --prefix nvm)/nvm.sh"
# 回到终端执行：
source ~/.zshrc
nvm install 20 ; nvm use 20

# 5. 验证环境
node -v        # v20.x.x
rustc -V       # rustc 1.8x.x
cargo -V       # cargo 1.8x.x
```

### 3.2 Rust 国内镜像（国内 macOS 用户同样建议）

```bash
mkdir -p ~/.cargo
cat > ~/.cargo/config.toml << EOF
[source.crates-io]
replace-with = 'rsproxy'
[source.rsproxy]
registry = "https://rsproxy.cn/crates.io-index"
[registries.rsproxy]
index = "https://rsproxy.cn/crates.io-index"
[net]
git-fetch-with-cli = true
EOF
```

### 3.3 创建项目 + 启动

```bash
cd ~/projects   # 自己提前建好
corepack enable   # 启用 pnpm/yarn（可选）
pnpm create tauri-app@2 my-first-app
# 交互式：TypeScript/JavaScript → pnpm → Vue → TypeScript → Yes

cd my-first-app
pnpm install
pnpm tauri dev
```

首次启动耗时跟 Windows 差不多。

### 3.4 打包 dmg

```bash
pnpm tauri icon ./icon-1024.png
pnpm tauri build --bundles dmg
```

生成的文件在 `src-tauri/target/release/bundle/dmg/My First App_0.1.0_aarch64.dmg`（M 系列芯片）或 `x64.dmg`（Intel 芯片）。

⚠️ M 系列 Mac 不能打 x64 的 dmg，反之亦然。要双平台就要两台机器或 CI。

## 4. Linux (Ubuntu/Debian) 用户完整分步

### 4.1 一次装齐系统依赖

```bash
sudo apt update
sudo apt install -y \
  libwebkit2gtk-4.1-dev \
  build-essential \
  curl \
  wget \
  file \
  libxdo-dev \
  libssl-dev \
  libayatana-appindicator3-dev \
  librsvg2-dev \
  libglib2.0-dev \
  libgtk-3-dev
```

### 4.2 装 Rust + Node

```bash
# Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source $HOME/.cargo/env

# Node 20
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
source ~/.bashrc     # 或者你的 shell 是 ~/.zshrc
nvm install 20 && nvm use 20
npm i -g pnpm
```

### 4.3 启动和打包

```bash
pnpm create tauri-app@2 my-first-app
cd my-first-app
pnpm install
pnpm tauri dev

# 打包
pnpm tauri icon ./icon-1024.png
pnpm tauri build --bundles deb,appimage
```

输出：
- `bundle/deb/my-first-app_0.1.0_amd64.deb`（Debian/Ubuntu 双击安装）
- `bundle/appimage/my-first-app_0.1.0_amd64.AppImage`（所有 Linux 发行版通用，`chmod +x` 后直接跑，不用安装）

## 5. 三个常见的「我以为坏了其实正常」的现象

好多人第一次跑会被下面现象吓到，以为出 bug 了，其实都是设计如此：

**① 第一次 `tauri dev` 终端一动不动，卡在 Compiling：**

这是 Rust 在把几十上百个依赖 crate 全编译成本地二进制。Rust 是 Ahead-of-Time 编译的，每次改一小段代码不会重编所有依赖。第一次最慢，后续增量编译就是几秒钟的事。

看终端里有没有不断刷新的 `Compiling xxx` 行。有就正常，耐心等。没刷了、卡死在同一行超过 10 分钟，一般是网络问题，回 2.1 节配镜像。

**② 启动后窗口里一片空白，白屏：**

分两种情况：
- DevTools Console 报错说 `Failed to fetch dynamically imported module` / `net::ERR_CONNECTION_REFUSED` → Vite dev server 没起来。查终端前端部分是不是崩了。90% 是因为 vite.config.ts 里 `strictPort: true` 且 5173 端口被占了。解决方案：要么关掉占用 5173 的进程，要么把 vite.config.ts 的 port 改成 5174，同时改 tauri.conf.json 的 `devUrl` 也改成 5174。
- DevTools 没有报错，就是啥也不显示 → CSP 问题。Tauri 默认 CSP 会阻止外链。如果你在 `index.html` 里引用了 unpkg/jsdelivr 的外链 CDN，要么删掉改成本地装，要么调松 CSP（详见 [04-安全与权限专题.md](./04-安全与权限专题.md)）。

**③ `tauri dev` 成功了，`tauri build` 报错一堆 Compiling：**

dev 是 `unoptimized + debuginfo`（未优化 + 带调试符号），build 是 `release + LTO`（做链接时优化）。build 时 rustc 做了更激进的优化，有些在 dev 模式下通过的 warning 在 release 会变成 error，而且优化时间长很多。不用慌，按错误提示一条条修就好。

## 6. 高频报错排查表（按你能看到的关键词搜）

> 这个表会一直迭代。报错时，先 Ctrl+F 搜报错里最有特征的那几个单词。

| 你能看到的报错关键词 | 原因 | 怎么修 |
| :--- | :--- | :--- |
| **`link.exe` not found** / **LNK1181** / **error: linker \`link.exe\` not found** | VS Build Tools 的 C++ 链没装全 | 打开 Visual Studio Installer → 修改 → 勾上「使用 C++ 的桌面开发」→ 右边明细里必须有「MSVC v143」+「Windows 10/11 SDK」→ 修改后重启电脑 |
| **Could not find webkit2gtk** / **error while loading shared libraries** | Linux 系统缺少 WebKitGTK 4.1 开发包 | 回第 4 步重新执行那个 apt install 全部装齐，装完 reboot |
| **Microsoft Edge WebView2 Runtime is required** | Windows 老版本没装 WebView2 | 去微软官网搜 "WebView2 Runtime download"，下载 Evergreen Bootstrapper 双击安装即可 |
| **Port 5173 is already in use** | Vite 默认端口 5173 被别的程序占了 | 1. 关了其他 Vite 项目；或 2. `vite.config.ts` 改 `port: 5174`，`tauri.conf.json` 的 `build.devUrl` 也改成 http://localhost:5174 |
| **Cannot find binary path** / **No such file or directory** | 前端还没 build 完就跑 tauri dev | 前端没装好依赖。`pnpm install` 完整跑一次，确保 `node_modules` 下有 `@tauri-apps/cli` |
| **command \`xxx\` not registered, allowed commands: \[\]** | 你在前端 `invoke('xxx')` 但是这个命令没在 Rust 端注册 | 1. 命令函数上面加了 `#[tauri::command]` 吗？2. 在 `lib.rs` 的 `generate_handler![]` 宏里加上函数名了吗？3. 保存后 Rust 编译成功了吗？ |
| **Unhandled Promise Rejection: scope not defined for url ...** | 用了 fs/http 插件但没在 capabilities 里配 scope | 打开 `src-tauri/capabilities/default.json`，给 fs/http 加 scope 配置，详见 [04-安全与权限专题](./04-安全与权限专题.md) |
| **additional properties not allowed / unknown field \`xxx\`** | tauri.conf.json 或 capabilities 里写了 schema 里没有的字段 | 报错里会写具体哪个文件哪一行。你要么删了那个字段，要么看 [tauri.conf.json 全字段文档](https://v2.tauri.app/reference/config/) 确认字段名拼对了（很多是从 1.x 升级时字段名改了，比如 whitelist → permissions） |
| **`cargo check`** 长时间没输出 | 网络慢，在下载 crates.io-index | 配国内镜像（2.1 节）。已经配了还慢 → 终端设置代理环境变量 `$env:RUSTUP_DIST_SERVER="https://rsproxy.cn"`（PowerShell） |
| **failed to select a version for the requirement `tauri = "^2"`** | crate 版本冲突 | 打开 `src-tauri/Cargo.toml`，看 tauri 和各插件的版本号是否一致，不要一个 2.0 一个 2.0-beta。建议统一写 `2.0` 让 cargo 自己挑最新 |
| **Building for windows, but macOS frameworks are being linked** (或反过来) | target 选错，交叉编译了 | 确保你没装什么奇怪的 target，在项目根目录执行 `rustup target remove x86_64-unknown-linux-gnu`（把不相关的 target 全卸了，留你本机一个就好） |
| **Error Could not locate Cargo.toml in src-tauri directory** | 项目结构被你破坏了，或者你是在非项目根目录跑的命令 | cd 回项目根目录（就是跟 `package.json` 同级那一层）再跑 tauri |
| **Permission denied**（Linux）/ **Operation not permitted**（macOS） | 系统权限被拒 | Linux: 别用 sudo 跑 tauri dev/build，容易把文件权限搞乱。macOS: 第一次打开终端会问你是否允许访问「文档」「桌面」目录，全部点允许。设置 → 隐私与安全性 → 完全磁盘访问 → 勾上你的终端程序 |
| **Desktop containing invalid path** / **couldn't convert to file** | 系统中用户桌面/下载等路径有中文或特殊字符，插件的 scope 路径解析出错 | 升级 tauri-plugin-fs 到最新版；或者你写的路径里有 `~`，请用 `home_dir()` crate 手动展开成绝对路径 |

## 7. 动手小练习

1. 照着 Windows 2.2/2.3 步骤走一遍，跑起来窗口。
2. 修改 App.vue，把输入框占位符从「Enter your name」改成「输入你的名字」。
3. 加一个按钮「点我弹个窗」，点击用 dialog 插件的 `message()` 弹出 "Hello from 我自己！"。
4. 完成后去做 01-03 里的「首次打包」，生成一个 NSIS 安装包，发给朋友让他装一下。
5. （选做）把刚才的项目用 `git init` 初始化仓库，`git commit -m "first tauri app"` 提交一次。
