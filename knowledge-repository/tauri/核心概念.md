## 架构总览

Tauri 采用 **前后端分离 + 多进程** 架构：

```
┌─────────────────────────────────────────────────────────────────┐
│                        Tauri 应用进程                           │
│                                                                 │
│  ┌──────────────────────┐         ┌──────────────────────────┐  │
│  │   WebView 进程      │  IPC    │       Rust 主进程       │  │
│  │                      │◄──────►│                          │  │
│  │  ┌────────────────┐  │         │  ┌──────────────────┐   │  │
│  │  │ 前端应用       │  │         │  │ 核心运行时       │   │  │
│  │  │ (HTML/CSS/JS)  │  │         │  └──────────────────┘   │  │
│  │  └────────────────┘  │         │  ┌──────────────────┐   │  │
│  │                      │         │  │ 自定义 Commands  │   │  │
│  │  @tauri-apps/api     │         │  └──────────────────┘   │  │
│  │  (JS 调用层)         │         │  ┌──────────────────┐   │  │
│  └──────────────────────┘         │  │ 官方插件         │   │  │
│                                   │  └──────────────────┘   │  │
│                                   │  ┌──────────────────┐   │  │
│                                   │  │ 系统 API 访问    │   │  │
│                                   │  └──────────────────┘   │  │
│                                   └──────────────────────────┘  │
└─────────────────────────────────────────────────────────────────┘
```

### 关键设计原则

1. **WebView 渲染前端**：界面使用系统 WebView（Edge/WebKit）渲染，不内置 Chromium，因此体积小
2. **Rust 处理系统层**：所有文件系统、网络、系统 API 调用都通过 Rust 端完成
3. **IPC 通信**：前端和后端通过 **IPC（Inter-Process Communication，进程间通信）** 进行数据交换
4. **最小权限原则**：默认禁止一切系统访问，必须显式声明权限（capabilities）

## 命令系统 (Commands)

命令系统是 Tauri 前后端通信的核心机制。前端通过 `invoke` 调用 Rust 端注册的函数，Rust 端返回处理结果。

### 工作流程

```
前端 (JS/TS)                          Rust 后端
      │                                    │
      │ invoke('greet', { name: 'Tom' })   │
      │ ──────────────────────────────────►│
      │                                    │ #[tauri::command]
      │                                    │ fn greet(name: &str) -> String {
      │                                    │   format!("Hello, {}!", name)
      │                                    │ }
      │     返回值 Promise<String>         │
      │ ◄──────────────────────────────────│
      ▼                                    ▼
```

### Rust 端：定义命令

在 `src-tauri/src/commands/` 中创建命令：

#### 1. 同步命令

```rust
use serde::{Deserialize, Serialize};

// 输入参数结构体
#[derive(Deserialize)]
pub struct UserQuery {
    pub id: u32,
    pub include_details: bool,
}

// 输出数据结构体
#[derive(Serialize)]
pub struct User {
    pub id: u32,
    pub name: String,
    pub email: String,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub details: Option<UserDetails>,
}

#[derive(Serialize)]
pub struct UserDetails {
    pub age: u8,
    pub address: String,
}

#[tauri::command]
pub fn get_user(query: UserQuery) -> Result<User, String> {
    if query.id == 0 {
        return Err("用户 ID 不能为 0".to_string());
    }

    let mut user = User {
        id: query.id,
        name: "张三".to_string(),
        email: "zhangsan@example.com".to_string(),
        details: None,
    };

    if query.include_details {
        user.details = Some(UserDetails {
            age: 28,
            address: "北京市朝阳区".to_string(),
        });
    }

    Ok(user)
}
```

#### 2. 异步命令

用于耗时操作，避免阻塞主线程：

```rust
use std::time::Duration;
use tokio::time::sleep;

#[tauri::command]
pub async fn process_data(input: String) -> Result<String, String> {
    // 模拟 IO 等待或复杂计算
    sleep(Duration::from_millis(500)).await;

    if input.is_empty() {
        Err("输入不能为空".into())
    } else {
        Ok(input.chars().rev().collect())
    }
}
```

#### 3. 访问应用状态

通过 `State` 参数访问全局共享状态：

```rust
use tauri::State;
use std::sync::Mutex;

// 定义全局状态
pub struct AppState {
    pub counter: Mutex<i32>,
}

#[tauri::command]
pub fn increment(state: State<AppState>) -> Result<i32, String> {
    let mut counter = state.counter.lock().map_err(|e| e.to_string())?;
    *counter += 1;
    Ok(*counter)
}

#[tauri::command]
pub fn get_counter(state: State<AppState>) -> i32 {
    *state.counter.lock().unwrap()
}
```

#### 4. 访问窗口和 AppHandle

```rust
use tauri::{AppHandle, Manager, WebviewWindow};
use tauri_plugin_dialog::DialogExt;

#[tauri::command]
pub fn show_message(window: WebviewWindow, message: String) {
    window
        .dialog()
        .message(message)
        .title("MyCubby")
        .show(|_| {});
}

#[tauri::command]
pub fn create_sub_window(app: AppHandle) -> Result<(), String> {
    tauri::WebviewWindowBuilder::new(
        &app,
        "settings",
        tauri::WebviewUrl::App("/settings".into()),
    )
    .title("设置")
    .inner_size(600.0, 500.0)
    .center()
    .resizable(false)
    .build()
    .map_err(|e| e.to_string())?;

    Ok(())
}
```

#### 5. 注册命令

在 `src-tauri/src/lib.rs` 中注册：

```rust
pub fn run() {
    tauri::Builder::default()
        // 注入全局状态
        .manage(AppState {
            counter: Mutex::new(0),
        })
        // 注册命令
        .invoke_handler(tauri::generate_handler![
            greet,
            get_user,
            process_data,
            increment,
            get_counter,
            show_message,
            create_sub_window,
        ])
        .run(tauri::generate_context!())
        .expect("error while running tauri application");
}
```

### 前端：调用命令

```typescript
import { invoke } from '@tauri-apps/api/core'

// 1. 基本调用
const result = await invoke<string>('greet', { name: 'Tom' })
console.log(result)  // "Hello, Tom! 欢迎使用 MyCubby!"

// 2. 调用带结构体参数的命令
const user = await invoke<User>('get_user', {
  query: {
    id: 123,
    include_details: true,
  },
})
console.log(user.name, user.details?.address)

// 3. 错误处理
try {
  await invoke('get_user', { query: { id: 0, include_details: false } })
} catch (error) {
  console.error('调用失败:', error)  // "用户 ID 不能为 0"
}

// 4. 调用异步命令
const processed = await invoke<string>('process_data', { input: 'Hello' })
console.log(processed)  // "olleH"

// 5. 状态相关命令
const count1 = await invoke<number>('increment')  // 1
const count2 = await invoke<number>('increment')  // 2
const current = await invoke<number>('get_counter')  // 2
```

### 命令系统最佳实践

1. **统一返回格式**：推荐所有命令返回 `Result<T, E>`，前端统一使用 try/catch 处理
2. **参数校验**：在 Rust 端做严格的参数校验，不信任前端传入的任何数据
3. **命名规范**：使用 `snake_case` 命名 Rust 命令，前端调用时保持一致
4. **避免大对象传输**：IPC 有性能开销，传输大文件/大量数据时使用文件路径或流式处理
5. **超时处理**：前端对可能耗时的命令设置超时

## 窗口管理 (Windows)

Tauri 支持多窗口，可以动态创建、销毁、配置窗口。

### 窗口配置

在 `tauri.conf.json` 中定义窗口，或在运行时动态创建。

#### 在配置中定义主窗口

```json
{
  "app": {
    "windows": [
      {
        "label": "main",
        "title": "MyCubby",
        "url": "/",
        "width": 1200,
        "height": 800,
        "center": true,
        "resizable": true,
        "decorations": true,
        "minWidth": 800,
        "minHeight": 600
      }
    ]
  }
}
```

#### 动态创建窗口

```rust
use tauri::{AppHandle, Manager, WebviewWindowBuilder, WebviewUrl};

pub fn create_log_window(app: &AppHandle) -> Result<(), String> {
    // 如果窗口已存在，只聚焦显示
    if let Some(existing) = app.get_webview_window("logs") {
        existing.show().map_err(|e| e.to_string())?;
        existing.set_focus().map_err(|e| e.to_string())?;
        return Ok(());
    }

    // 创建新窗口
    WebviewWindowBuilder::new(
        app,
        "logs",  // 唯一标识 label
        WebviewUrl::App("/logs".into()),  // 加载的前端路由
    )
    .title("日志查看器")
    .inner_size(900.0, 600.0)
    .min_inner_size(600.0, 400.0)
    .position(100.0, 100.0)
    .resizable(true)
    .decorations(true)
    .transparent(false)
    .always_on_top(false)
    .build()
    .map_err(|e| format!("创建窗口失败: {}", e))?;

    Ok(())
}
```

## 事件机制 (Events)

Tauri 提供全局事件系统，支持前后端双向通信和多窗口间消息传递。

### 事件类型

| 类型 | 说明 | 场景 |
|------|------|------|
| 前端 → Rust 事件 | 前端 emit，Rust listen | 通知后端执行操作（不等待返回值） |
| Rust → 前端事件 | Rust emit，前端 listen | 后端状态更新、进度通知、异步任务回调 |
| 窗口间事件 | 从一个窗口 emit 到另一个窗口 | 多窗口数据同步 |

### Rust → 前端：发送事件

适合后台任务的进度通知、异步回调等场景。

```rust
use tauri::{AppHandle, Emitter, Manager};
use std::time::Duration;
use tokio::time::sleep;

#[tauri::command]
pub async fn start_long_task(app: AppHandle, total: u32) -> Result<(), String> {
    for i in 1..=total {
        sleep(Duration::from_millis(200)).await;

        let progress = (i as f64 / total as f64) * 100.0;

        // 👉 向所有窗口发送事件
        app.emit("task-progress", serde_json::json!({
            "current": i,
            "total": total,
            "percent": progress.round() as u32,
        }))
        .map_err(|e| e.to_string())?;

        // 👉 向指定窗口发送事件
        if let Some(window) = app.get_webview_window("main") {
            window.emit_to("main", "task-progress-window-only", progress)
                .map_err(|e| e.to_string())?;
        }
    }

    Ok(())
}
```

### 前端：监听事件

```typescript
import { listen } from '@tauri-apps/api/event'

// 监听来自 Rust 的事件
const unlisten = await listen<{ current: number; total: number; percent: number }>(
  'task-progress',

    console.log(`进度: ${event.payload.percent}% (${event.payload.current}/${event.payload.total})`)
    // 更新 UI 进度条

  }
)

// 触发任务
await invoke('start_long_task', { total: 50 })

// 不需要时取消监听
// unlisten()
```


## 安全模型 (Security)

Tauri 的安全模型是其核心优势之一，默认遵循「最小权限原则」。

### 1. Capabilities 权限系统

Tauri 2.x 使用 Capabilities 机制声明权限。每个插件的 API 调用必须显式声明。

配置文件：`src-tauri/capabilities/default.json`

```json
{
  "identifier": "default",
  "windows": ["main", "settings"],  // 此权限配置适用的窗口
  "permissions": [
    // 对话框权限
    "dialog:allow-open",
    "dialog:allow-save",
    "dialog:allow-message",

    // 文件系统权限（指定 scope 更安全）
    "fs:allow-read-file",
    "fs:allow-write-file",
    "fs:scope-documents",     // 限制在用户 Documents 目录

    // Shell 权限（非常危险，仅在必要时启用）
    // "shell:allow-execute"
  ]
}
```

> ⚠️ **重要**：不要为了方便就启用所有权限。仅启用实际需要的权限。

### 2. 文件系统 Scope

对于文件系统操作，使用 Scope 限制可访问的目录：

```json
{
  "permissions": [
    {
      "identifier": "fs:allow-read-file",
      "allow": ["$DOCUMENT/**", "$DESKTOP/mycubby-exports/**"],
      "deny": ["$DOCUMENT/private/**"]
    }
  ]
}
```

可用的路径变量：
- `$HOME` / `$HOME/`：用户主目录
- `$DOCUMENT` / `$DOCUMENTS`：文档目录
- `$DESKTOP`：桌面目录
- `$DOWNLOAD` / `$DOWNLOADS`：下载目录
- `$AUDIO`：音乐目录
- `$PICTURE` / `$PICTURES`：图片目录
- `$VIDEO` / `$VIDEOS`：视频目录
- `$TEMP`：临时目录
- `$APP` / `$APPLOCALDATA` / `$APPCONFIG` / `$APPDATA` / `$APPLOG`：应用专属目录

### 3. CSP (Content Security Policy)

Tauri 默认使用严格的 CSP，阻止加载不安全的外部资源。

修改 `tauri.conf.json` 自定义 CSP：

```json
{
  "app": {
    "security": {
      "csp": "default-src 'self'; img-src 'self' asset: data: https://*.mycubby.com; style-src 'self' 'unsafe-inline'; script-src 'self'; connect-src 'self' https://api.mycubby.com;"
    }
  }
}
```

### 4. IPC 安全

```rust
// ✅ 正确：严格校验输入参数
#[tauri::command]
pub fn read_config(path: String, state: State<AppState>) -> Result<String, String> {
    // 路径遍历攻击防护：确保路径在允许的目录内
    let base_dir = state.config_dir.lock().unwrap().clone();
    let full_path = std::fs::canonicalize(&path).map_err(|_| "无效路径")?;
    if !full_path.starts_with(&*base_dir) {
        return Err("访问被拒绝：路径不在允许范围内".into());
    }

    std::fs::read_to_string(&full_path).map_err(|e| e.to_string())
}
```

## 状态管理 (State)

### Rust 端全局状态

```rust
use tauri::{Manager, State};
use std::sync::{Arc, Mutex};
use serde::{Serialize, Deserialize};

// 定义配置结构体
#[derive(Serialize, Deserialize, Clone, Default)]
pub struct AppConfig {
    pub theme: String,
    pub language: String,
    pub auto_update: bool,
}

// 状态容器
pub struct ConfigState {
    pub config: Mutex<AppConfig>,
    pub db_connection: Mutex<Option<Database>>,
}

pub fn run() {
    tauri::Builder::default()
        // 注入状态
        .manage(ConfigState {
            config: Mutex::new(load_config()),
            db_connection: Mutex::new(None),
        })
        .invoke_handler(tauri::generate_handler![get_config, save_config])
        .setup(|app| {
            // 初始化时连接数据库
            let state = app.state::<ConfigState>();
            *state.db_connection.lock().unwrap() = Some(Database::connect());
            Ok(())
        })
        .run(tauri::generate_context!())
        .expect("error");
}

// 在命令中访问状态
#[tauri::command]
pub fn get_config(state: State<ConfigState>) -> AppConfig {
    state.config.lock().unwrap().clone()
}

#[tauri::command]
pub fn save_config(state: State<ConfigState>, new_config: AppConfig) -> Result<(), String> {
    *state.config.lock().unwrap() = new_config.clone();
    persist_config(&new_config).map_err(|e| e.to_string())
}
```

### 前端状态管理

推荐结合前端生态的状态管理库（Pinia/Zustand），并与 Tauri 持久化存储插件配合：

```typescript
// stores/app.ts
import { defineStore } from 'pinia'
import { Store } from '@tauri-apps/plugin-store'
import { ref, watch } from 'vue'

const store = new Store('app-config.bin')

export const useAppStore = defineStore('app', () => {
  const theme = ref<'light' | 'dark'>('light')
  const language = ref<'zh-CN' | 'en-US'>('zh-CN')

  // 启动时从磁盘加载
  async function init() {
    theme.value = (await store.get('theme')) || 'light'
    language.value = (await store.get('language')) || 'zh-CN'
  }

  // 监听变化，自动持久化
  watch(theme, (val) => store.set('theme', val))
  watch(language, (val) => store.set('language', val))
  watch([theme, language], () => store.save())

  return { theme, language, init }
})
```

### 自定义托盘菜单

```rust
use tauri::{
    menu::{Menu, MenuItem, Submenu, PredefinedMenuItem},
    tray::{MouseButton, MouseButtonState, TrayIconBuilder, TrayIconEvent},
    Manager,
};

pub fn setup_tray(app: &mut tauri::App) -> Result<(), Box<dyn std::error::Error>> {
    let show_main = MenuItem::with_id(app, "show-main", "显示主窗口", true, None::<&str>)?;
    let settings = MenuItem::with_id(app, "settings", "设置", true, Some("Ctrl+,"))?;
    let quit = MenuItem::with_id(app, "quit", "退出", true, Some("Ctrl+Q"))?;

    let tray_menu = Menu::with_items(
        app,
        &[
            &show_main,
            &PredefinedMenuItem::separator(app)?,
            &settings,
            &PredefinedMenuItem::separator(app)?,
            &quit,
        ],
    )?;

    TrayIconBuilder::new()
        .with_menu(tray_menu)
        .with_tooltip("MyCubby")
        .with_icon_as_template(true)
        .on_menu_event(|app, event| match event.id.as_ref() {
            "show-main" => {
                if let Some(window) = app.get_webview_window("main") {
                    let _ = window.show();
                    let _ = window.set_focus();
                }
            }
            "settings" => {
                println!("打开设置");
            }
            "quit" => {
                app.exit(0);
            }
            _ => {}
        })
        .on_tray_icon_event(|tray, event| {
            if let TrayIconEvent::Click {
                button: MouseButton::Left,
                button_state: MouseButtonState::Up,
                ..
            } = event
            {
                let app = tray.app_handle();
                if let Some(window) = app.get_webview_window("main") {
                    let _ = window.show();
                    let _ = window.set_focus();
                }
            }
        })
        .build(app)?;

    Ok(())
}
```

### 插件使用三步法

以 `dialog` 插件为例：

**步骤 1：添加 Rust 依赖**（`src-tauri/Cargo.toml`）

```toml
[dependencies]
tauri-plugin-dialog = "2.0"
```

**步骤 2：在 Tauri Builder 中初始化**

```rust
// src-tauri/src/lib.rs
pub fn run() {
    tauri::Builder::default()
        .plugin(tauri_plugin_dialog::init())  // 注册插件
        .run(tauri::generate_context!())
        .expect("error");
}
```

**步骤 3：安装前端 npm 包并调用**

```bash
pnpm add @tauri-apps/plugin-dialog
```

```typescript
import { save, open, message } from '@tauri-apps/plugin-dialog'

// 打开文件选择框
const selected = await open({
  title: '选择文件',
  multiple: true,
  filters: [{
    name: '文本文件',
    extensions: ['txt', 'md', 'json']
  }]
})
console.log('选中:', selected)

// 弹出消息框
await message('操作成功完成！', {
  title: 'MyCubby',
  kind: 'info',  // 'info' | 'warning' | 'error'
})
```
