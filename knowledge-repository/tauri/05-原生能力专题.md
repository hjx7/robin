# 05-原生能力专题：菜单 / 系统托盘 / 通知 / 拖拽 / 对话框 / 自动更新 / 全局快捷键

> 这一章每一节都是一个独立的「用得上」的能力，有完整示例代码（Rust 侧 + 前端侧）和常见坑。你可以按项目实际需要跳着读，不需要一次看完。

## 0. 前置准备：安装 + 权限

本章用到的插件要先 `cargo add` 和加对应的 npm 包：

| 能力 | Cargo.toml add | npm/pnpm add | 必须的 capabilities permission |
| :--- | :--- | :--- | :--- |
| 应用菜单 / 窗口菜单 | `tauri-plugin-menu` | `@tauri-apps/plugin-menu` | `menu:allow-default` 等 |
| 系统托盘 | `tauri-plugin-tray` | `@tauri-apps/plugin-tray` | `tray:allow-default` 等 |
| 系统通知 | `tauri-plugin-notification` | `@tauri-apps/plugin-notification` | `notification:allow-notify` |
| 对话框（选文件/提示） | `tauri-plugin-dialog` | `@tauri-apps/plugin-dialog` | `dialog:allow-open` / `allow-save` / `allow-message` 等 |
| 自动更新 | `tauri-plugin-updater` | `@tauri-apps/plugin-updater` | `updater:allow-check-update` / `allow-install-update` 等 |
| 全局快捷键 | `tauri-plugin-global-shortcut` | `@tauri-apps/plugin-global-shortcut` | `global-shortcut:allow-register` / `allow-unregister` |
| 拖拽文件到窗口里 | **Tauri 核心自带**，不用装插件 | 用原生 HTML5 drag/drop + Tauri 转路径 | 核心权限开了就行 |

下面每一节都默认你已经装好了对应插件和权限。

**👉 高级版（动态菜单：根据用户权限动态显示、菜单项 check/uncheck 状态切换）：** 用 Rust 在 `setup` 里手动构建：

```rust
// Rust
use tauri::{App, Manager};
use tauri_plugin_menu::{Menu, MenuItem, Submenu, MenuEvent, PredefinedMenuItem};

pub fn setup_menu(app: &mut App) -> Result<(), Box<dyn std::error::Error>> {
    let handle = app.handle();

    // 动态菜单项（用户登录才显示的管理员菜单）
    let admin_items = if current_user_is_admin() {
        vec![
            MenuItem::with_id("admin-panel", "打开管理员后台", true, None::<&str>),
            MenuItem::Separator,
        ]
    } else {
        vec![]
    };

    let menu = Menu::with_items(handle, &[
        &Submenu::with_items(
            handle,
            "文件",
            true,
            &[
                &MenuItem::with_id(handle, "new-file", "新建", true, Some("cmdOrCtrl+N"))?,
                &PredefinedMenuItem::quit(handle, Some("退出"))?,
            ],
        )?,
        &Submenu::with_items(
            handle,
            "设置",
            true,
            &[
                &MenuItem::with_id(handle, "theme-light",   "浅色模式", true, None)?,
                &MenuItem::with_id(handle, "theme-dark",    "深色模式", true, None)?,
                &MenuItem::with_id(handle, "theme-auto",    "跟随系统", true, None)?,
            ],
        )?,
    ])?;

    handle.set_menu(menu)?;
    handle.on_menu_event(|app, event| match event.id().0.as_str() {
        "new-file" => {
            println!("用户点了新建");
            let _ = app.emit("menu-new-file", ());
        }
        "theme-light" | "theme-dark" | "theme-auto" => {
            let theme = event.id().0.replace("theme-", "");
            println!("切换主题为：{}", theme);
            let _ = app.emit("theme-changed", theme);
        }
        _ => {}
    });

    Ok(())
}
```

### 1.2 菜单里内置的 action 和 accelerator 速查

| 你想让菜干点啥 | `action` 写啥 |
| :--- | :--- |
| 退出应用 | `"quit"` |
| 关闭当前 Webview 窗口 | `"close"` |
| 最小化 | `"minimize"` |
| 最大化/还原 | `"maximize"` |
| 全屏切换 | `"toggle-fullscreen"` |
| 打开开发者工具 | `"toggle-devtools"` |
| 撤销 | `"undo"` |
| 重做 | `"redo"` |
| 切/复/粘/全选 | `"cut"` / `"copy"` / `"paste"` / `"select-all"` |
| 关于窗口 | `"show-about"` |
| 打开指定网址 | `{ "action": "open-link", "link": "https://..." }` |

accelerator（快捷键）常用格式：
- 单键：`"Delete"`、`"Enter"`、`"F5"`
- 组合：`"cmdOrCtrl+N"`、`"cmdOrCtrl+Shift+S"`、`"alt+F4"`
- Mac 上 `Cmd` 自动对应，Win/Linux 上自动对应 `Ctrl`，所以**绝大多数场景写 `cmdOrCtrl`，不用拆成两个**

## 2. 系统托盘（右下角通知区域小图标）

### 2.1 最小完整示例：一个「主显隐 + 退出」的托盘

```rust
// Rust lib.rs 的 Builder 链加上 .plugin(tauri_plugin_tray::init())
use tauri::{App, Manager, Emitter};
use tauri_plugin_tray::{MouseButton, MouseButtonState, TrayIconBuilder, TrayIconEvent};
use tauri_plugin_menu::{Menu, MenuItem, PredefinedMenuItem};

pub fn setup_tray(app: &mut App) -> Result<(), Box<dyn std::error::Error>> {
    let handle = app.handle();

    let tray_menu = Menu::with_items(handle, &[
        &MenuItem::with_id(handle, "show",   "显示主窗口", true, None::<&str>)?,
        &MenuItem::with_id(handle, "hide",   "隐藏到托盘", true, None::<&str>)?,
        &PredefinedMenuItem::separator(handle)?,
        &PredefinedMenuItem::quit(handle, Some("退出程序"))?,
    ])?;

    TrayIconBuilder::with_id("main-tray")
        .icon(tauri::image::Image::from_bytes(include_bytes!("../icons/icon.png"))?)
        .icon_as_template(true)   // macOS 浅色/深色自动适配
        .menu(&tray_menu)
        .tooltip("我的 Tauri 应用")
        .on_menu_event(|app, event| match event.id().0.as_str() {
            "show" => {
                if let Some(w) = app.get_webview_window("main") {
                    let _ = w.show();
                    let _ = w.set_focus();
                }
            }
            "hide" => {
                if let Some(w) = app.get_webview_window("main") {
                    let _ = w.hide();
                }
            }
            _ => {}
        })
        .on_tray_icon_event(|tray, event| {
            if let TrayIconEvent::Click {
                button: MouseButton::Left,
                button_state: MouseButtonState::Up,
                ..
            } = event
            {
                // 左键单击一下：切换显示/隐藏
                let app = tray.app_handle();
                if let Some(w) = app.get_webview_window("main") {
                    let visible = w.is_visible().unwrap_or(false);
                    if visible {
                        let _ = w.hide();
                    } else {
                        let _ = w.show();
                        let _ = w.set_focus();
                    }
                }
            }
        })
        .build(app)?;

    Ok(())
}
```

### 2.2 常见坑

- ❌ Win 上图标没有：你的 icon 必须是 `.ico` 或至少 32×32 的 PNG。把 `icons/icon.png` 放进去并且 `include_bytes!` 路径对。
- ❌ macOS 上托盘图标全黑全白：加 `.icon_as_template(true)`，让系统按模板模式渲染。
- ❌ 关主窗口后应用直接退出了：`tauri.conf.json → app.windows[0].closeBehavior = "hide"` 或 `"exit"?: "hide"`。要让点 X 不是退出而是躲去托盘，配：
  ```json
  { "app": { "windows": [{ "label": "main", "closeBehavior": "hide" }], "withGlobalTauri": false } }
  ```
  并且别在托盘菜单「退出」之外的任何地方调 `process::exit`。

## 3. 系统通知（右下角弹提示）

### 3.1 前置：先申请权限 + capability

capabilities 里至少要有：
```json
"notification:allow-request-permission",
"notification:allow-is-permission-granted",
"notification:allow-notify",
```

### 3.2 前端 5 行代码弹一个通知

```ts
import {
  isPermissionGranted,
  requestPermission,
  sendNotification,
} from '@tauri-apps/plugin-notification'

const notify = async (title: string, body: string) => {
  let ok = await isPermissionGranted()
  if (!ok) {
    ok = (await requestPermission()) === 'granted'
  }
  if (!ok) {
    console.warn('用户没给通知权限')
    return
  }
  sendNotification({ title, body, icon: 'icons/icon.png' })
}

notify('任务完成', '您的文件已经全部上传完毕 ✅')
```

### 3.3 Rust 端弹通知（后台任务完成后，命令返回前主动弹）

```rust
use tauri::{AppHandle, Emitter};
use tauri_plugin_notification::NotificationExt;

#[tauri::command]
pub fn long_running_job(app: AppHandle) -> Result<(), String> {
    // 干活 3 秒
    std::thread::sleep(std::time::Duration::from_secs(3));

    // 弹系统通知
    app
        .notification()
        .builder()
        .title("任务完成")
        .body("您请求的压缩包已生成在桌面")
        .show()
        .map_err(|e| e.to_string())?;

    Ok(())
}
```

> Mac 上首次调用会弹系统授权，Windows 上默认就有权限，但如果用户手动关闭了「应用通知」，那你得让用户去开。

## 4. 文件拖拽（两种方向）

### 4.1 方向一：用户把外部文件「拖进窗口里」→ 前端拿到路径

用原生 HTML5 drag/drop 事件，拿到 `DataTransfer.files[0].path`，但这个 path 是 WebView 转义过的 URL（比如 `file:///C:/Users/...`），**要让 Tauri 帮你转成真实绝对路径**，用 `convertFileSrc` 反向转的反函数 `Path.fromFileUrl`：

```ts
// 前端
import { WebviewWindow } from '@tauri-apps/api/window'
import { convertFileSrc } from '@tauri-apps/api/core'
import { sep } from '@tauri-apps/api/path'

interface DropItem {
  realPath: string   // 真实磁盘路径，能直接传给 Rust 命令
  displayName: string
  size: number
}

const onDrop = async (e: DragEvent) => {
  e.preventDefault()
  const files = Array.from(e.dataTransfer?.files ?? [])

  const results: DropItem[] = []
  for (const f of files) {
    // WebKit 给的路径（Win 上是 `/C:/Users/...`，前面多一个斜杠）
    const rawPath = (f as any).path ?? (f as any).webkitRelativePath ?? ''
    // 用 path 插件标准化
    const normalized = await normalizeSlashesWin(rawPath)
    results.push({
      realPath: normalized,
      displayName: f.name,
      size: f.size,
    })
  }
  console.log('用户拖进来的文件：', results)
  // 然后就可以 invoke('read_file', { path: results[0].realPath }) 了
}

// Windows 上 path 开头多一个 / 处理掉
const normalizeSlashesWin = async (p: string) => {
  // 用 path.join 的思路处理
  const { sep, isAbsolute, normalize } = await import('@tauri-apps/api/path')
  let s = p
  // WebView on Windows often gives /C:/foo/bar.txt
  if (/^\/[A-Za-z]:\//.test(s)) s = s.slice(1)
  return normalize(s)
}
```

### 4.2 方向二：前端某个元素「拖出窗口」→ 系统获得真实文件

比如你做了一个笔记应用，笔记列表里用户把某条笔记拖到桌面，自动生成 `.md` 文件。这需要在 Rust 端写「拖拽源」注册：

```rust
// Rust（简化版）：注册 drag_source
use tauri::Window;
use tauri_plugin_drag::DragExt;   // cargo add tauri-plugin-drag

#[tauri::command]
pub fn start_drag_note(window: Window, note_path: String) -> Result<(), String> {
    let image = tauri::image::Image::from_bytes(include_bytes!("../icons/file-md.png"))
        .map_err(|e| e.to_string())?;

    window
        .drag_start(
            vec![note_path],  // 要被「拖出去」的真实磁盘文件列表
            image,            // 跟随鼠标的缩略图
            None::<fn(_)>,    // 结束回调
        )
        .map_err(|e| e.to_string())?;
    Ok(())
}
```

> 注意：你必须先把内容写入磁盘真实存在的文件，再告诉 Tauri「把这个文件拖出去」。否则系统不会认。

## 5. 对话框（选文件/存文件/提示弹窗/输入确认）

### 5.1 四类常用对话框前端示例

```ts
import {

}

const pickFolder = async () => {
  const folder = await open({
    title: '选择要导出的文件夹',
    directory: true,
  })
  if (folder && typeof folder === 'string') {
    // invoke('export_all', { folder })
  }
}

// ③ 弹保存对话框，返回用户选的保存路径
const saveAs = async (defaultName: string) => {
  const path = await save({
    title: '导出 Markdown',
    defaultPath: defaultName,   // 可以写默认文件名，也可以写完整路径

const showError = async (msg: string) => {

```

### 5.2 权限提醒

**dialog 必须在 capabilities 里把 allow-open / allow-save / allow-message / allow-confirm / allow-ask 都开齐。** 没开的话控制台会报 `ScopeNotDefined`，调它直接 reject Promise。

## 6. 自动更新（Updater）

### 6.1 两种分发方式的更新策略

| 你打包给用户的格式 | 支持自动更新吗 | 说明 |
| :--- | :--- | :--- |
| `.msi`（Windows 安装器） | ✅ | 推荐生产 |
| `.exe`（NSIS 安装器） | ✅ | 最常用 |
| `.dmg`（macOS 磁盘镜像） | ✅ | 只更新 `.app`，不重新装 dmg |
| `.deb` / `.AppImage` / `.rpm`（Linux） | ✅ 大部分 | AppImage 支持最好 |
| `.appx` / `.msix` / 微软商店 | ❌ | 商店自己会更新 |

### 6.2 三步跑通

**第一步：`tauri.conf.json` 启用 updater + 签名**

```json
{
  "bundle": {
    "updater": {
      "active": true,
      "endpoints": [
        "https://cdn.mycubby.com/releases/latest.json"
      ],
      "dialog": false,        // 用 false，自己写前端的更新提示 UI（更灵活）
      "pubkey": "dW50cnVzdGVkIGNvbW1lbnQ6IG1pbmlzaWduIHB1YmxpYyBrZXk6IDE3MTk0YjM2ZTk3NzgxY2E..."
    }
  }
}
```

`pubkey` 是第一次用 `pnpm tauri signer generate` 生成的公钥。私钥保存好，之后打包时要设置环境变量：
- `TAURI_SIGNING_PRIVATE_KEY`：私钥内容
- `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`：如果私钥有密码

**第二步：后端 CDN 放好 `latest.json`，格式固定**

```json
{
  "version": "v1.2.0",
  "notes": "- 修复了导出闪退\n- 新增全局快捷键\n- 菜单支持浅色深色",
  "pub_date": "2026-08-27T10:00:00Z",
  "platforms": {
    "windows-x86_64": {
      "signature": "dW50cnVzdGVkIGNvbW1lbnQ6IHNpZ25hdHVyZSBmcm9tIG1pbmlzaWduOiBCbE1sOHg...",
      "url": "https://cdn.mycubby.com/releases/1.2.0/my-app_1.2.0_x64-setup.exe"
    },
    "darwin-aarch64": {
      "signature": "dW50cnVzdGVkIGNvbW1lbnQ6IHNpZ25hdHVyZSBmcm9tIG1pbmlzaWduOiBhb2t6a0...",
      "url": "https://cdn.mycubby.com/releases/1.2.0/my-app_1.2.0_aarch64.dmg"
    },
    "darwin-x86_64": { "signature": "...", "url": "..." },
    "linux-x86_64.AppImage": { "signature": "...", "url": "..." }
  }
}
```

> ✨ 省事推荐：GitHub Releases 就可以做你的静态更新服务器，不用自己搭 CDN。`endpoints` 写一个你自己的 GitHub Actions 生成的 `latest.json` 地址即可。

**第三步：前端检测 + 下载 + 安装（自己掌控 UI，不要用 Tauri 内建的简陋 dialog）**

```ts
import { check } from '@tauri-apps/plugin-updater'

interface UpdateProgress {
  contentLength: number
  chunkLength: number
}

const checkUpdate = async () => {
  const update = await check()
  if (!update?.available) {
    console.log('已是最新版', update?.currentVersion)
    return
  }

  if (!confirm(`发现新版本 ${update.version}（当前 ${update.currentVersion}），是否更新？
\n更新说明：\n${update.body ?? ''}`)) {
    return
  }

  let downloaded = 0
  let total = 0

  await update.downloadAndInstall(
    // 进度回调：每下载一个 chunk 就调用一次
    (e: UpdateProgress) => {
      total = e.contentLength
      downloaded += e.chunkLength
      const percent = Math.round((downloaded / total) * 100)
      console.log(`下载中 ${percent}%`)
    },
    // 结束回调：安装前让你做点事（比如保存用户工作，关闭数据库）
    () => {
      console.log('安装即将开始，应用会自动重启')
    },
  )
}
```

### 6.3 常见坑

- ❌ Windows 上签名过不了：你用了中文/空格的私钥密码？把密码改成纯字母数字。私钥不要带 BOM。
- ❌ 安装完用户打开还是旧版本：.msi 安装器会在应用运行中安装失败（文件被锁）。装之前先让前端调用 `app.exit()` 把自己退出。Updater 插件新版已经帮你做了，老版本要自己处理。
- ❌ Mac 上更新后报错「已损坏」：macOS 13+ 要求应用必须公证（notarize），打包时加上 `TAURI_SIGNING_PRIVATE_KEY` 且 Apple Developer ID 证书要全。

## 7. 全局快捷键（应用没在焦点也能响应）

### 7.1 最小示例：Ctrl+Alt+S 快速截图、Ctrl+Alt+M 弹出主窗口

```rust
// Rust
use tauri::{App, Manager, Emitter};
use tauri_plugin_global_shortcut::{Code, GlobalShortcutExt, Modifiers, Shortcut, ShortcutState};

pub fn setup_shortcuts(app: &mut App) -> Result<(), Box<dyn std::error::Error>> {
    let handle = app.handle();
    let gs = handle.global_shortcut();

    let ctrl_alt_s = Shortcut::new(Some(Modifiers::CONTROL | Modifiers::ALT), Code::KeyS);
    let ctrl_alt_m = Shortcut::new(Some(Modifiers::CONTROL | Modifiers::ALT), Code::KeyM);

    gs.on_shortcut(move |handle, shortcut, state| {
        if state != ShortcutState::Pressed {
            return;
        }
        if shortcut == &ctrl_alt_s {
            println!("用户按了 Ctrl+Alt+S，开始截图");
            let _ = handle.emit("hotkey-screenshot", ());
        } else if shortcut == &ctrl_alt_m {
            println!("用户按了 Ctrl+Alt+M，拉起主窗口");
            if let Some(w) = handle.get_webview_window("main") {
                let _ = w.show();
                let _ = w.unminimize();
                let _ = w.set_focus();
            }
        }
    });

    // 注册上去
    gs.register(ctrl_alt_s)?;
    gs.register(ctrl_alt_m)?;

    Ok(())
}
```

### 7.2 坑提醒

- 全局快捷键是系统级别抢的，用户如果已经用了 Ctrl+Alt+S 绑定微信截图、QQ 截图、Snipaste、PowerToys，你再注册会失败或不生效。**注册前先 `unregister`、失败时用弹提示告诉用户「快捷键冲突」。**
- 应用退出时 Tauri 会自动取消注册，不会泄漏。
- 权限别忘了：`"global-shortcut:allow-register"`, `"global-shortcut:allow-unregister"`。

## 8. 本章小结：一份「实用 Checklist」

做桌面应用时，按顺序想这 7 件事，基本就不会漏原生能力：

1. **菜单**：顶栏/菜单栏能不能覆盖常用操作？Ctrl+N/S/Z/Y/C/V 全吗？
2. **托盘**：用户关掉主窗口，应用是退出还是躲后台？
3. **通知**：耗时任务完成后有没有弹通知提醒？
4. **拖拽**：拖入文件有 UI 高亮反馈吗？文件能拖出去导出吗？
5. **对话框**：保存/打开用的是原生对话框还是自己画的丑 Web 版？
6. **自动更新**：你有 `latest.json` 分发 + pubkey 签名流程吗？
7. **快捷键**：最常用的 2-3 个核心操作有没有全局快捷键？

这 7 个点都做到，你的应用已经有「专业桌面感」了，用户一看就知道不是简单的网页套壳。
