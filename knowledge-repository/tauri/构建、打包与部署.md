## 构建前检查

发布前请逐项检查：

- [ ] **版本号**：`package.json` 中的 `version` 和 `src-tauri/Cargo.toml` 中的 `version`、`src-tauri/tauri.conf.json` 中的 `version` 保持一致
- [ ] **应用图标**：各尺寸图标已正确生成（`src-tauri/icons/`）
- [ ] **应用名称**：`tauri.conf.json` 中 `productName` 与 `identifier`（反向域名格式）设置正确
- [ ] **权限配置**：`capabilities/default.json` 仅启用了必要的权限
- [ ] **CSP 策略**：`tauri.conf.json` 中 `security.csp` 符合生产环境需求
- [ ] **前端构建**：`pnpm build` 无错误、无警告
- [ ] **Rust 编译**：`cargo check` 在 `src-tauri` 下无错误
- [ ] **日志级别**：生产环境日志级别设置为 `info` 或 `warn`，不要输出 `debug`/`trace`
- [ ] **调试代码**：移除前端和 Rust 中的 `console.debug`、`dbg!` 等调试代码
- [ ] **API 地址**：后端 API 地址使用生产环境地址
- [ ] **测试验证**：关键功能已在开发模式下测试通过

## 构建生产版本

### 基本命令

```bash
# 在项目根目录
pnpm tauri build

# 或使用 package.json scripts
pnpm tauri:build
```

执行流程：
1. 运行 `beforeBuildCommand`（例如 `pnpm build`，打包前端到 `dist/`）
2. Cargo 以 `release` profile 编译 Rust 代码（执行 LTO、体积优化）
3. 读取 `frontendDist` 目录中的前端资源，嵌入到二进制中
4. 根据平台生成安装包

### 常用构建选项

```bash
# 构建但不生成安装包（仅生成可执行文件）
pnpm tauri build --no-bundle

# 仅生成指定类型的安装包（Windows 示例）
pnpm tauri build --bundles msi          # 仅 MSI 安装包
pnpm tauri build --bundles nsis         # 仅 NSIS 安装包
pnpm tauri build --bundles "msi,nsis"   # 两者都生成

# 查看详细构建日志
pnpm tauri build --verbose

# 构建调试版的安装包（包含符号表和调试信息，用于排查生产问题）
pnpm tauri build --debug

# 跳过前端构建（当你已经手动构建过前端）
# （需先确保 dist/ 目录是最新的生产版本）
pnpm tauri build --config '{"build": { "beforeBuildCommand": "" }}'

# 针对特定 CPU 架构交叉编译（需安装对应 target）
# 例：在 x64 Windows 上构建 ARM64 版本
cd src-tauri && cargo build --release --target aarch64-pc-windows-msvc
```

### 统一版本号

推荐使用脚本同步三个文件的版本号。创建 `scripts/version.mjs`：

```javascript
// scripts/version.mjs
import { readFileSync, writeFileSync } from 'node:fs'
import { resolve, dirname } from 'node:path'
import { fileURLToPath } from 'node:url'

const __dirname = dirname(fileURLToPath(import.meta.url))
const root = resolve(__dirname, '..')
const version = process.argv[2]

if (!version || !/^\d+\.\d+\.\d+(-[\w.]+)?$/.test(version)) {
  console.error('用法: node scripts/version.mjs 1.2.3 或 1.2.3-beta.1')
  process.exit(1)
}

// 1. package.json
const pkgPath = resolve(root, 'package.json')
const pkg = JSON.parse(readFileSync(pkgPath, 'utf8'))
pkg.version = version
writeFileSync(pkgPath, JSON.stringify(pkg, null, 2) + '\n')

// 2. Cargo.toml
const cargoPath = resolve(root, 'src-tauri/Cargo.toml')
let cargo = readFileSync(cargoPath, 'utf8')
cargo = cargo.replace(/^version\s*=\s*"[^"]+"/m, `version = "${version}"`)
writeFileSync(cargoPath, cargo)

// 3. tauri.conf.json
const confPath = resolve(root, 'src-tauri/tauri.conf.json')
const conf = JSON.parse(readFileSync(confPath, 'utf8'))
conf.version = version
writeFileSync(confPath, JSON.stringify(conf, null, 2) + '\n')

console.log(`版本号已更新为: ${version}`)
```

在 `package.json` 中添加脚本：

```json
{
  "scripts": {
    "version:set": "node scripts/version.mjs"
  }
}
```

使用：

```bash
pnpm version:set 1.0.0
pnpm version:set 1.1.0-beta.1
```

## 各平台打包说明

### Windows 平台

Tauri 在 Windows 上支持两种安装包格式：

#### MSI 安装包（推荐企业环境）

- 使用 WiX Toolset 构建
- 适合企业批量部署、组策略安装
- 支持安装/修复/卸载
- 默认产物位置：`src-tauri/target/release/bundle/msi/MyCubby_1.0.0_x64_zh-CN.msi`

配置（`tauri.conf.json`）：

```json
{
  "bundle": {
    "windows": {
      "wix": {
        "language": "zh-CN",
        "template": null
      },
      "webviewInstallMode": {
        "type": "downloadBootstrapper",
        "silent": true
      }
    }
  }
}
```

#### NSIS 安装包（推荐普通用户）

- 使用 NSIS（Nullsoft Scriptable Install System）构建
- 体积更小、安装更灵活，支持自定义安装界面
- 支持「只为当前用户安装」和「为所有用户安装」两种模式
- 默认产物位置：`src-tauri/target/release/bundle/nsis/MyCubby_1.0.0_x64-setup.exe`

配置：

```json
{
  "bundle": {
    "windows": {
      "nsis": {
        "installMode": "currentUser",        // currentUser | perMachine | both
        "displayLanguageSelector": false,    // 是否显示语言选择
        "language": "SimpChinese",           // 安装界面语言（SimpChinese = 简体中文）
        "languages": ["SimpChinese", "English"],
        "differentialPackage": true,         // 是否生成增量补丁包
        "startMenuShortcut": true,
        "desktopShortcut": true,
        "shortcutName": "MyCubby",
        "sidebarImage": "side-image.bmp",    // 可选：自定义侧边图
        "headerImage": "header-image.bmp"    // 可选：自定义页眉图
      }
    }
  }
}
```

#### WebView2 安装模式

如果目标系统（Windows 10 1809 之前）没有内置 WebView2，可配置自动安装：

```json
{
  "bundle": {
    "windows": {
      "webviewInstallMode": {
        "type": "downloadBootstrapper",  // 安装时在线下载并引导安装
        "silent": true
      }
    }
  }
}
```

`type` 可选值：
- `downloadBootstrapper`：下载 WebView2 Bootstrapper 后引导用户安装（体积小）
- `embedBootstrapper`：将 Bootstrapper 嵌入安装包（约 1.5MB，无需联网）
- `embedFixedVersion`：嵌入固定版本 WebView2（约 150MB，完全无需联网，但会显著增大安装包）
- `skip`：不处理 WebView2，用户自行安装

### macOS 平台

构建产物为 `.dmg` 磁盘镜像和 `.app` 应用包。

#### 构建要求
- 需要 macOS 系统（无法在 Windows/Linux 上构建 macOS 版本）
- Xcode Command Line Tools 已安装
- 如需签名，需要 Apple Developer 账号和证书

#### 配置

```json
{
  "bundle": {
    "macOS": {
      "frameworks": [],
      "minimumSystemVersion": "10.15",
      "category": "public.app-category.productivity",
      "exceptionDomain": "",

      // 签名与公证（发布到 App Store 或分发时需要）
      "signingIdentity": "Developer ID Application: Your Name (TEAMID123)",
      "entitlements": "entitlements.plist",
      "providerShortName": "TEAMID123",

      // 信息补充
      "license": "LICENSE.txt",
      "helpBookFolder": "",
      "helpBookName": "",
      "bundleVersion": null,
      "bundleVersionShort": null,
      "copyright": "Copyright © 2026 MyCubby Team",
      "preferredArchitecture": "universal",  // universal (x64 + arm64), x86_64, aarch64
    }
  }
}
```

#### Entitlements 示例（`src-tauri/entitlements.plist`）

```xml

  <true/>
  <key>com.apple.security.network.server</key>
  <true/>
  <key>com.apple.security.files.downloads.read-write</key>
  <true/>

  <true/>
  <key>com.apple.security.files.desktopFolder.read-write</key>
  <true/>

```

#### 通用二进制（Universal Binary）

如果需要同时支持 Intel (x86_64) 和 Apple Silicon (arm64)：

```bash
# 安装两个 target
rustup target add x86_64-apple-darwin aarch64-apple-darwin

# 在配置中设置 preferredArchitecture: "universal"
# 然后执行 build：
pnpm tauri build
# Tauri 会自动为两个架构分别编译，然后合并为 Universal Binary
```

#### 构建产物
- `.dmg`：`src-tauri/target/release/bundle/dmg/MyCubby_1.0.0_aarch64.dmg`
- `.app`：`src-tauri/target/release/bundle/macos/MyCubby.app`

        "enhances": [],
        "preDepends": [],
        "section": "utils",
        "priority": "optional",
        "conflicts": [],
        "replaces": [],
        "provides": [],
        "maintainerScripts": {
          "postinst": null,   // 安装后脚本
          "prerm": null,      // 卸载前脚本
          "postrm": null      // 卸载后脚本
        }
      },
      "rpm": {
        "files": {},

## 体积优化技巧

Tauri 默认配置已经很优化，但可以进一步压缩体积。

### Rust 端优化（Cargo.toml）

```toml
[profile.release]
panic = "abort"        # 去除 panic 栈展开
codegen-units = 1      # 单代码单元编译（体积+性能）
lto = "fat"            # 全局链接时优化（strip + lto 体积减小最显著）
opt-level = "s"        # s = 优化体积，z = 极致优化体积（可能略慢）
strip = "symbols"      # 去除符号表
debug = false          # 不嵌入调试信息
```

### 使用 `tauri-plugin-updater` 压缩

无需，updater 会自动处理。

### 前端资源优化

```bash
# 构建前端时开启压缩
# Vite 默认已经是最佳化，但可以手动配置

# 检查前端构建体积
pnpm build -- --mode production
```

Vite 配置补充：

```typescript
// vite.config.ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

export default defineConfig({
  plugins: [vue()],
  build: {
    outDir: 'dist',
    cssCodeSplit: true,
    minify: 'esbuild',  // 使用 esbuild 压缩（快），可选 'terser'（体积更小）
    sourcemap: false,   // 不要包含 source map
    // 代码分割
    rollupOptions: {
      output: {
        manualChunks: {
          vue: ['vue', 'vue-router', 'pinia'],
          tauri: ['@tauri-apps/api'],
        }
      }
    },
    // chunk 警告阈值调整
    chunkSizeWarningLimit: 1000,
  },
})
```

### 使用 UPX 压缩（可选，⚠️ 可能误报为病毒）

UPX 可以将可执行文件再压缩 40%-70%，但会被部分杀毒软件误报，不推荐用于正式发布。

```bash
# 安装 UPX: https://upx.github.io/

# Windows
upx --lzma --best src-tauri/target/release/mycubby.exe

# macOS（不建议 UPX，会破坏签名）

# Linux
upx --lzma --best src-tauri/target/release/mycubby
```

### 最终体积参考

典型 Vue + 常用插件的 Tauri 2.x 应用：

| 平台 | 格式 | 体积范围 |
|------|------|----------|
| Windows | NSIS 安装包 | **3-8 MB** |
| Windows | MSI 安装包 | **4-10 MB** |
| Windows | 裸 EXE | **3-6 MB** |
| macOS | DMG | **4-8 MB** |

> 对比 Electron 通常 80-200MB 的体积，Tauri 非常轻量。

## 自动更新 (Updater)

使用 `tauri-plugin-updater` 实现应用内自动更新。

### 1. 添加依赖

```toml
# src-tauri/Cargo.toml
[dependencies]
tauri-plugin-updater = "2.0"
```

```bash
# 前端
pnpm add @tauri-apps/plugin-updater
```

### 2. 注册插件

```rust
// src-tauri/src/lib.rs
pub fn run() {
    tauri::Builder::default()
        .plugin(
            tauri_plugin_updater::Builder::new()
                .installer_mode(tauri_plugin_updater::InstallerMode::Passive)
                .build(),
        )
        .run(tauri::generate_context!())
        .expect("error");
}
```

### 3. 配置更新服务器地址

```json
// src-tauri/tauri.conf.json
{
  "plugins": {
    "updater": {
      "endpoints": [
        "https://releases.mycubby.com/latest.json"
      ],
      "dialog": false,      // 使用自定义 UI（不使用 Tauri 内置对话框）
      "pubkey": "dW50cnVzdGVkZW50aXR5"  // 见下方签名部分
    }
  }
}
```

### 4. 服务器端 latest.json 格式

### 5. 前端检查更新 UI

```typescript
import { check } from '@tauri-apps/plugin-updater'
import { relaunch } from '@tauri-apps/plugin-process'
import { on, emit } from '@tauri-apps/api/event'

export async function checkForUpdates(showNoUpdateToast = true): Promise<void> {
  try {
    const update = await check()

    if (!update?.available) {
      if (showNoUpdateToast) {
        toast.info('当前已是最新版本')
      }
      return
    }

    const confirmed = await showUpdateDialog({
      currentVersion: update.currentVersion,
      newVersion: update.version,
      body: update.body,
      date: update.date,
    })
    if (!confirmed) return

    // 监听下载进度
    const unlisten = await on('tauri://update-progress', (event) => {
      const payload = event.payload as { chunkLength: number; contentLength: number | null }
      if (payload.contentLength) {
        const percent = Math.round(payload.chunkLength / payload.contentLength * 100)
        updateProgressBar(percent)
      }
    })

    // 下载并安装
    await update.downloadAndInstall()
    unlisten()

    const restart = await confirmRestartDialog()
    if (restart) await relaunch()
  } catch (e) {
    console.error('更新检查失败:', e)
  }
}
```

### 6. 生成签名密钥

首次发布前生成签名密钥：

```bash
# 在项目根目录（或 src-tauri 目录下）运行
cd src-tauri

# 生成签名密钥对
cargo tauri signer generate -w ~/.tauri/mycubby-signing.key
# 系统会提示设置密码，请牢记
# 输出示例：
#   Generating new signing key
#   Private: "dW50cnVzdGVkZW50aXR5..."  (不要公开)
#   Public: "dW50cnVzdGVkZW50aXR5..."   (放到 tauri.conf.json 的 pubkey)
```

**环境变量配置**（构建时自动签名）：

```bash
# Windows PowerShell
$env:TAURI_SIGNING_PRIVATE_KEY = "dW50cnVzdGVkZW50aXR5..."
$env:TAURI_SIGNING_PRIVATE_KEY_PASSWORD = "your-password"

# 构建时 Tauri 会自动为更新包签名
pnpm tauri build
```

也可以在 CI 中使用 Secrets 管理。

> 💡 Updater 会在每次 `tauri build` 时自动生成：
> - Windows: `*.nsis.zip`（NSIS 安装包的 zip 压缩版，用于增量更新）
> - macOS: `*.app.tar.gz`（签名后的 App 压缩包）
> - Linux: `*.AppImage.tar.gz`
> - 以及对应的 `.sig` 签名文件

## 应用代码签名

代码签名可以防止 SmartScreen 拦截、macOS Gatekeeper 阻止。

### Windows: EV/OV 代码签名证书

1. 购买代码签名证书（DigiCert、Sectigo、Certum 等，EV 证书可立即消除 SmartScreen 警告）
2. 安装证书到 Windows 证书存储区
3. 配置 Tauri 使用证书签名：

```bash
# 方法一：通过 signtool 手动签名
signtool sign /fd SHA256 /a /tr http://timestamp.digicert.com /td SHA256 /d "MyCubby" ^
  src-tauri\target\release\mycubby.exe
signtool sign /fd SHA256 /a /tr http://timestamp.digicert.com /td SHA256 /d "MyCubby" ^
  src-tauri\target\release\bundle\nsis\MyCubby_1.0.0_x64-setup.exe
signtool sign /fd SHA256 /a /tr http://timestamp.digicert.com /td SHA256 /d "MyCubby" ^
  src-tauri\target\release\bundle\msi\MyCubby_1.0.0_x64_zh-CN.msi
```

Tauri 2.x 支持自动签名配置：

```json
{
  "bundle": {
    "windows": {
      "certificateThumbprint": "0123456789ABCDEF0123456789ABCDEF01234567",
      "digestAlgorithm": "sha256",
      "timestampUrl": "http://timestamp.digicert.com"
    }
  }
}
```

### macOS: Apple Developer 签名 + 公证

1. 加入 Apple Developer Program（$99/年）
2. 创建 "Developer ID Application" 证书
3. 配置 `TAURI_SIGNING_PRIVATE_KEY` 或使用 Keychain 中的证书
4. 在构建配置中：

```json
{
  "bundle": {
    "macOS": {
      "signingIdentity": "Developer ID Application: Your Company (TEAMID123)",
      "entitlements": "entitlements.plist",
      "providerShortName": "TEAMID123"
    }
  }
}
```

5. 设置环境变量并构建：

```bash
export APPLE_ID="your-apple-id@example.com"
export APPLE_PASSWORD="app-specific-password"   # 需在 appleid.apple.com 生成
export APPLE_TEAM_ID="TEAMID123"

pnpm tauri build
```

构建完成后，Tauri 会自动执行 `notarytool` 提交公证。

## CI/CD 自动化构建

### GitHub Actions 示例（推荐）

创建 `.github/workflows/release.yml`：

```yaml
name: Build & Release

on:
  push:
    tags:
      - 'v*.*.*'
  workflow_dispatch:

permissions:
  contents: write

jobs:
  # ======================= Windows 构建 =======================
  build-windows:
    name: Windows (x64)
    runs-on: windows-latest
    steps:
      - uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'pnpm'

      - name: Setup Rust
        uses: dtolnay/rust-toolchain@stable
        with:
          targets: x86_64-pc-windows-msvc

      - name: Install pnpm
        run: npm i -g pnpm

      - name: Cache Rust
        uses: Swatinem/rust-cache@v2
        with:
          workspaces: src-tauri

      - name: Install deps & build
        run: |
          pnpm install --frozen-lockfile
          pnpm build
        env:
          TAURI_SIGNING_PRIVATE_KEY: ${{ secrets.TAURI_SIGNING_PRIVATE_KEY }}
          TAURI_SIGNING_PRIVATE_KEY_PASSWORD: ${{ secrets.TAURI_SIGNING_PRIVATE_KEY_PASSWORD }}

      - name: Upload artifacts
        uses: actions/upload-artifact@v4
        with:
          name: windows-release
          path: |
            src-tauri/target/release/bundle/nsis/*.exe
            src-tauri/target/release/bundle/nsis/*.zip
            src-tauri/target/release/bundle/msi/*.msi

  # ======================= macOS 构建 =======================
  build-macos:
    name: macOS (universal)
    runs-on: macos-latest
    steps:
      - uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'pnpm'

      - name: Setup Rust
        uses: dtolnay/rust-toolchain@stable
        with:
          targets: x86_64-apple-darwin, aarch64-apple-darwin

      - name: Install pnpm
        run: npm i -g pnpm

      - name: Cache Rust
        uses: Swatinem/rust-cache@v2
        with:
          workspaces: src-tauri

      - name: Install deps & build
        run: |
          pnpm install --frozen-lockfile
          pnpm build
        env:
          TAURI_SIGNING_PRIVATE_KEY: ${{ secrets.TAURI_SIGNING_PRIVATE_KEY }}
          TAURI_SIGNING_PRIVATE_KEY_PASSWORD: ${{ secrets.TAURI_SIGNING_PRIVATE_KEY_PASSWORD }}
          APPLE_ID: ${{ secrets.APPLE_ID }}
          APPLE_PASSWORD: ${{ secrets.APPLE_PASSWORD }}
          APPLE_TEAM_ID: ${{ secrets.APPLE_TEAM_ID }}

      - name: Upload artifacts
        uses: actions/upload-artifact@v4
        with:
          name: macos-release
          path: |
            src-tauri/target/release/bundle/dmg/*.dmg
            src-tauri/target/release/bundle/macos/*.app.tar.gz
            src-tauri/target/release/bundle/macos/*.app.tar.gz.sig

  # ======================= Linux 构建 =======================
  build-linux:
    name: Linux (x64)
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Install system dependencies
        run: |
          sudo apt update
          sudo apt install -y libwebkit2gtk-4.1-dev build-essential curl wget file \
            libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev \
            patchelf

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'pnpm'

      - name: Setup Rust
        uses: dtolnay/rust-toolchain@stable

      - name: Install pnpm
        run: npm i -g pnpm

      - name: Cache Rust
        uses: Swatinem/rust-cache@v2
        with:
          workspaces: src-tauri

      - name: Install deps & build
        run: |
          pnpm install --frozen-lockfile
          pnpm build
        env:
          TAURI_SIGNING_PRIVATE_KEY: ${{ secrets.TAURI_SIGNING_PRIVATE_KEY }}
          TAURI_SIGNING_PRIVATE_KEY_PASSWORD: ${{ secrets.TAURI_SIGNING_PRIVATE_KEY_PASSWORD }}

      - name: Upload artifacts
        uses: actions/upload-artifact@v4
        with:
          name: linux-release
          path: |
            src-tauri/target/release/bundle/deb/*.deb
            src-tauri/target/release/bundle/rpm/*.rpm
            src-tauri/target/release/bundle/appimage/*.AppImage

  # ======================= 发布到 GitHub Release =======================
  release:
    name: Create GitHub Release
    needs: [build-windows, build-macos, build-linux]
    runs-on: ubuntu-latest
    steps:
      - uses: actions/download-artifact@v4
        with:
          path: release

      - name: List files
        run: ls -R release/

      - name: Create Release
        uses: softprops/action-gh-release@v2
        with:
          files: release/**/*
          generate_release_notes: true
          draft: false
          prerelease: ${{ contains(github.ref, 'beta') || contains(github.ref, 'rc') }}
```
