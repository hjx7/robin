## 环境准备

### 安装前端 Tauri 依赖

在项目根目录安装核心包和需要的插件：

```bash
# 核心 API
pnpm add @tauri-apps/api@2

# 常用插件
pnpm add @tauri-apps/plugin-dialog         # 对话框
pnpm add @tauri-apps/plugin-notification   # 系统通知
pnpm add @tauri-apps/plugin-fs             # 文件系统
pnpm add @tauri-apps/plugin-shell          # Shell 操作
pnpm add @tauri-apps/plugin-store          # 持久化存储
pnpm add @tauri-apps/plugin-os             # 系统信息
pnpm add @tauri-apps/plugin-path           # 路径管理
pnpm add @tauri-apps/plugin-process        # 进程控制
pnpm add @tauri-apps/plugin-clipboard-manager  # 剪贴板
pnpm add @tauri-apps/plugin-global-shortcut   # 全局快捷键
```

### 开发环境检测

有时需要区分当前是在浏览器中预览（比如只开发前端时）还是在 Tauri 窗口中运行：

```typescript
// src/utils/env.ts
import { invoke } from '@tauri-apps/api/core'

export function isTauriAvailable(): boolean {
  return typeof window !== 'undefined' && '__TAURI_INTERNALS__' in window
}

/**
 * 安全地 invoke 命令，如果不在 Tauri 环境中则返回 mock 数据
 */
export async function safeInvoke<T>(
  command: string,
  args?: Record<string, unknown>,
  fallback?: T
): Promise<T> {
  if (isTauriAvailable()) {
    return invoke<T>(command, args)
  }
  console.warn(`[Tauri 不可用] 命令 ${command} 使用 fallback 数据`, fallback)
  return fallback as T
}
```

使用示例：

```typescript
import { safeInvoke } from '@/utils/env'

// 调用命令，在浏览器中预览时也不会报错
const result = await safeInvoke<string>(
  'greet',
  { name: 'Tom' },
  'Hello Tom! (浏览器模拟模式)'
)
```

## 核心 API 使用

### invoke - 调用 Rust 命令

```typescript
import { invoke } from '@tauri-apps/api/core'

// 基本用法
const greeting = await invoke<string>('greet', { name: 'World' })

// 带错误处理
try {
  const user = await invoke<User>('get_user', { id: 123 })
} catch (err) {
  console.error('获取用户失败:', err)
  // err 通常是字符串，对应 Rust 返回的 Err(String)
}

// 设置超时
const timeoutPromise = new Promise((_, reject) =>
  setTimeout(() => reject(new Error('命令超时')), 5000)
)
const result = await Promise.race([
  invoke('heavy_task'),
  timeoutPromise,
])
```

### convertFileSrc - 资源路径转换

用于加载本地文件系统中的图片、视频等资源：

```typescript
import { convertFileSrc } from '@tauri-apps/api/core'

// 将本地路径转换为 Tauri 可访问的 URL
const filePath = 'C:/Users/Pictures/photo.jpg'  // 或 /home/user/Pictures/photo.jpg
const assetUrl = convertFileSrc(filePath)

// 在 Vue/React 中使用
// <img :src="assetUrl" alt="本地图片" />
```

### 事件系统

```typescript
import { listen, emit, emitTo, once } from '@tauri-apps/api/event'

// 监听事件（可多次触发）
const unlisten = await listen('custom-event', (event) => {
  console.log('收到事件:', event.payload)
  console.log('事件来源窗口:', event.windowLabel)
})

// 取消监听
// unlisten()

// 监听一次（触发后自动取消）
await once('one-time-event', (event) => {
  console.log('只执行一次:', event.payload)
})

// 向前端/后端广播事件
await emit('my-event', { data: 'hello' })

// 向指定窗口发送事件
await emitTo('settings-window', 'refresh-settings', { theme: 'dark' })
```

```typescript
console.log('目录:', dirname(targetPath))
console.log('文件名:', basename(targetPath))

// ---- 读取文本文件 ----
async function readJsonConfig<T>(path: string): Promise<T> {
  const text = await fs.readTextFile(path)
  return JSON.parse(text) as T
}

// ---- 写入文本文件 ----
async function saveJsonConfig(path: string, data: unknown): Promise<void> {
  // 确保目录存在
  const dir = dirname(path).replace(/\\/g, '/')
  try {
    await fs.createDir(dir, { recursive: true })
  } catch (e) {
    // 目录已存在时忽略错误
  }

  const text = JSON.stringify(data, null, 2)
  await fs.writeTextFile(path, text)
}

// ---- 读取二进制文件（如图像）----
async function readImageToArrayBuffer(path: string): Promise<Uint8Array> {
  return await fs.readBinaryFile(path)
}

// ---- 写入二进制文件 ----
async function saveImageFromDataUrl(path: string, dataUrl: string): Promise<void> {
  const base64 = dataUrl.split(',')[1]
  const bytes = Uint8Array.from(atob(base64), c => c.charCodeAt(0))
  await fs.writeBinaryFile(path, bytes)
}

// ---- 遍历目录 ----
async function listFiles(dir: string): Promise<{ name: string; isDir: boolean; size: number }[]> {
  const entries = await fs.readDir(dir, { recursive: false })
  return entries.map(e => ({
    name: e.name || 'unknown',
    isDir: e.children !== undefined,
    size: 0,  // 需要单独获取
  }))
}

// ---- 文件/目录操作 ----
await fs.createDir(await join(docDir, 'MyCubby', 'exports'), { recursive: true })
await fs.exists(targetPath)               // 检查是否存在
await fs.renameFile(oldPath, newPath)     // 重命名/移动
await fs.copyFile(srcPath, destPath)      // 复制
await fs.removeFile(path)                 // 删除文件
await fs.removeDir(dirPath, { recursive: true })  // 删除目录（含内容）

// ---- 获取元数据 ----

console.log('创建时间:', new Date(meta.createdAt))
```

```json
// 执行命令需要额外在 tauri.conf.json 中 scope 白名单中配置
```


> ⚠️ **重要**：执行系统命令（Command/Child）有安全风险，必须在配置中严格白名单化。推荐将此类操作通过自定义 Rust Command 实现，比前端直接 shell 调用更安全。

## Tauri API 封装最佳实践

建议对 Tauri API 进行统一封装，集中处理错误、权限、环境检测。

### 创建统一封装层

```typescript
// src/utils/tauri.ts

import { invoke } from '@tauri-apps/api/core'
import { open, save, message, confirm, type DialogFilter } from '@tauri-apps/plugin-dialog'
import { Store } from '@tauri-apps/plugin-store'
import {
  readTextFile, writeTextFile,
  readBinaryFile, writeBinaryFile,
  readDir, createDir,
  exists, removeFile, removeDir, renameFile, copyFile,
  metadata,
  type FsOptions, type FsDirOptions,
} from '@tauri-apps/plugin-fs'
import {
  documentDir, downloadDir, desktopDir, homeDir,
  appDataDir, appConfigDir, join,
} from '@tauri-apps/plugin-path'

import { isTauriAvailable } from './env'

// ============ 错误处理 ============
export class TauriError extends Error {
  code?: string
  constructor(message: string, code?: string) {
    super(message)
    this.name = 'TauriError'
    this.code = code
  }
}

function handleError(err: unknown, context: string): never {
  const msg = err instanceof Error ? err.message : String(err)
  console.error(`[Tauri 错误] ${context}:`, msg)
  throw new TauriError(msg, context)
}

// ============ invoke 封装 ============
export async function call<T>(
  command: string,
  args?: Record<string, unknown>,
): Promise<T> {
  if (!isTauriAvailable()) {
    throw new TauriError('Tauri 运行环境不可用', 'ENV_NOT_AVAILABLE')
  }
  try {
    return await invoke<T>(command, args)
  } catch (err) {
    handleError(err, `invoke:${command}`)
  }
}

// ============ 对话框封装 ============
export const Dialog = {
  async openFile(filters: DialogFilter[] = [{ name: '所有文件', extensions: ['*'] }], multiple = false): Promise<string | string[] | null> {
    try { return await open({ filters, multiple }) }
    catch (err) { handleError(err, 'dialog:open') }
  },
  async openDirectory(): Promise<string | null> {
    try { return await open({ directory: true }) as string | null }
    catch (err) { handleError(err, 'dialog:openDir') }
  },
  async saveFile(defaultPath?: string, filters?: DialogFilter[]): Promise<string | null> {
    try { return await save({ defaultPath, filters }) }
    catch (err) { handleError(err, 'dialog:save') }
  },
  async info(text: string, title = '提示'): Promise<void> {
    await message(text, { title, kind: 'info' })
  },
  async warn(text: string, title = '警告'): Promise<void> {
    await message(text, { title, kind: 'warning' })
  },
  async error(text: string, title = '错误'): Promise<void> {
    await message(text, { title, kind: 'error' })
  },
  async confirm(text: string, title = '确认', okLabel = '确定', cancelLabel = '取消'): Promise<boolean> {
    return await confirm(text, { title, okLabel, cancelLabel, kind: 'warning' })
  },
}

// ============ 路径封装 ============
export const Path = {
  documentDir, downloadDir, desktopDir, homeDir,
  appDataDir, appConfigDir, join,
}

// ============ 文件系统封装 ============
export const FS = {
  async readText(path: string): Promise<string> {
    try { return await readTextFile(path) }
    catch (err) { handleError(err, `fs:readText:${path}`) }
  },
  async writeText(path: string, content: string): Promise<void> {
    try {
      const dir = (await join(path, '..')).replace(/\\\\$/, '')
      await createDir(dir, { recursive: true }).catch(() => {})
      await writeTextFile(path, content)
    } catch (err) { handleError(err, `fs:writeText:${path}`) }
  },
  async readJson<T>(path: string): Promise<T> {
    const text = await this.readText(path)
    try { return JSON.parse(text) as T }
    catch { throw new TauriError('JSON 解析失败', 'JSON_PARSE') }
  },
  async writeJson<T>(path: string, data: T, pretty = true): Promise<void> {
    const content = pretty ? JSON.stringify(data, null, 2) : JSON.stringify(data)
    await this.writeText(path, content)
  },
  async readBinary(path: string): Promise<Uint8Array> {
    try { return await readBinaryFile(path) }
    catch (err) { handleError(err, `fs:readBinary:${path}`) }
  },
  async writeBinary(path: string, data: Uint8Array): Promise<void> {
    try { await writeBinaryFile(path, data) }
    catch (err) { handleError(err, `fs:writeBinary:${path}`) }
  },
  async listDir(path: string, recursive = false): Promise<{ name: string; path: string; isDir: boolean }[]> {
    try {
      const entries = await readDir(path, { recursive })
      return entries.flatMap(e => {
        const result: { name: string; path: string; isDir: boolean }[] = []
        if (e.name && e.path) {
          result.push({ name: e.name, path: e.path, isDir: !!e.children })
        }
        return result
      })
    } catch (err) { handleError(err, `fs:listDir:${path}`) }
  },
  exists, createDir, removeFile, removeDir, renameFile, copyFile, metadata,
}

// ============ Store 封装 ============
class StoreWrapper {
  private cache = new Map<string, Store>()

  private async get(name: string): Promise<Store> {
    let store = this.cache.get(name)
    if (!store) {
      store = new Store(name)
      this.cache.set(name, store)
    }
    return store
  }

  async get<T>(storeName: string, key: string, defaultValue?: T): Promise<T | undefined> {
    const store = await this.get(storeName)
    return (await store.get<T>(key)) ?? defaultValue
  }

  async set(storeName: string, key: string, value: unknown): Promise<void> {
    const store = await this.get(storeName)
    await store.set(key, value)
    await store.save()
  }

  async has(storeName: string, key: string): Promise<boolean> {
    const store = await this.get(storeName)
    return await store.has(key)
  }

  async delete(storeName: string, key: string): Promise<void> {
    const store = await this.get(storeName)
    await store.delete(key)
    await store.save()
  }

  async save(storeName: string): Promise<void> {
    const store = await this.get(storeName)
    await store.save()
  }
}

export const PersistentStore = new StoreWrapper()
```

```vue
    return
  }

    await Path.desktopDir() || '',
    `mycubby-export-${Date.now()}.json`
  )

  const savePath = await Dialog.saveFile(defaultPath, [{ name: 'JSON 数据', extensions: ['json'] }])
  if (!savePath) return

    await Dialog.info(`导出成功！文件已保存至：\n${savePath}`)
    // 记住上次导出位置

  }
}
```

## 状态管理集成

### Vue + Pinia + Tauri Store 持久化

```typescript
// src/stores/useAppStore.ts
import { defineStore } from 'pinia'
import { ref, watch } from 'vue'
import { PersistentStore } from '@/utils/tauri'

export const useAppStore = defineStore('app', () => {
  const inited = ref(false)

  const theme = ref<'light' | 'dark'>('light')
  const language = ref<'zh-CN' | 'en-US'>('zh-CN')
  const sidebarCollapsed = ref(false)
  const autoUpdate = ref(true)
  const recentFiles = ref<string[]>([])

  // 初始化：从持久化存储加载
  async function init() {
    if (inited.value) return

    theme.value = await PersistentStore.get('settings.bin', 'theme', 'light') as any
    language.value = await PersistentStore.get('settings.bin', 'language', 'zh-CN') as any
    sidebarCollapsed.value = !!await PersistentStore.get('settings.bin', 'sidebarCollapsed', false)
    autoUpdate.value = !!await PersistentStore.get('settings.bin', 'autoUpdate', true)
    recentFiles.value = (await PersistentStore.get('settings.bin', 'recentFiles', [])) || []

    // 应用主题到 DOM
    applyTheme(theme.value)

    // 监听变化自动保存
    watch(theme, (v) => { PersistentStore.set('settings.bin', 'theme', v); applyTheme(v) })
    watch(language, (v) => PersistentStore.set('settings.bin', 'language', v))
    watch(sidebarCollapsed, (v) => PersistentStore.set('settings.bin', 'sidebarCollapsed', v))
    watch(autoUpdate, (v) => PersistentStore.set('settings.bin', 'autoUpdate', v))
    watch(recentFiles, (v) => PersistentStore.set('settings.bin', 'recentFiles', v), { deep: true })

    inited.value = true
  }

  function applyTheme(t: 'light' | 'dark') {
    document.documentElement.dataset.theme = t
  }

  function addRecentFile(path: string) {
    const idx = recentFiles.value.indexOf(path)
    if (idx !== -1) recentFiles.value.splice(idx, 1)
    recentFiles.value.unshift(path)
    if (recentFiles.value.length > 10) recentFiles.value.pop()
  }

  return {
    inited,
    theme, language, sidebarCollapsed, autoUpdate, recentFiles,
    init, addRecentFile,
  }
})
```

```typescript
import { fetch, Body, ResponseType } from '@tauri-apps/plugin-http'

interface ApiResponse<T> { code: number; data: T; message: string }

class ApiClient {
  baseUrl = import.meta.env.VITE_API_BASE_URL

  async request<T>(
    path: string,
    options: RequestInit = {}
  ): Promise<T> {
    const url = path.startsWith('http') ? path : `${this.baseUrl}${path}`

    console.log('[API]', options.method || 'GET', url, options.body)

    const res = await fetch(url, {
      ...options,
      headers: {
        'Content-Type': 'application/json',
        ...options.headers,
      },
    })

    const data = await res.json() as ApiResponse<T>

    if (!res.ok || data.code !== 0) {
      console.error('[API 错误]', url, data)
      throw new Error(data.message || `HTTP ${res.status}`)
    }

    console.log('[API 返回]', url, data)
    return data.data
  }

  get<T>(path: string) { return this.request<T>(path, { method: 'GET' }) }
  post<T>(path: string, body: unknown) {
    return this.request<T>(path, { method: 'POST', body: JSON.stringify(body) })
  }
  put<T>(path: string, body: unknown) {
    return this.request<T>(path, { method: 'PUT', body: JSON.stringify(body) })
  }
  delete<T>(path: string) { return this.request<T>(path, { method: 'DELETE' }) }
}

export const api = new ApiClient()
```
