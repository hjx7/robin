# 猫 · 行为心理

> 看懂猫在干什么，写文章才有真实的"我家猫怎么怎么了"。

---

## 一、肢体语言

### 尾巴
- **竖起、尖微弯**：友好、开心、打招呼。回家时这个姿态 = "你回来啦"。
- **炸毛（像松鼠刷子）**：受惊 / 威胁。弓背炸毛 = "我很可怕别过来"。
- **甩 / 用力抽打**：烦躁、不耐烦、生气。再摸要挨抓。
- **轻摆尾尖**：思考、犹豫、专注（盯鸟时常见）。
- **夹尾巴（贴肚子）**：害怕、示弱。
- **盘腿上、尾尖轻抖**：放松陪伴。

### 耳朵
- **朝前立起**：放松、好奇。
- **转向两侧（飞机耳）**：紧张、防备、要攻击。
- **完全压平贴头**：极度害怕 / 生气。
- **一只朝前一只转向后**：半信半疑。

### 眼睛
- **缓慢眨眼**：信任、亲昵。你回一个慢眨眼给它，是猫界的"我爱你"。
- **瞳孔骤大（圆睁）**：兴奋、紧张、攻击前。
- **半闭**：放松、信任或身体不适（生病也会半闭眼，注意区分）。
- **直视、瞳孔不动**：锁定目标，捕猎或攻击前。

### 声音
- **呼噜声（purring）**：开心放松，但也会在疼痛 / 紧张时呼噜（自我安抚）。
- **喵叫**：主要对人叫（猫之间不靠喵叫交流）。需求：饿了、要开门、求关注。
- **短促颤音 / 咕噜叫**：打招呼、看到你回来。
- **长嚎 / 哀鸣**：发情、极度不适。
- **哈气（嘶嘶）**：警告、防备。别硬碰。
- **咔咔牙（嘎嘎叫）**：看到鸟 / 虫子激动，捕猎模式。

## 二、行为解读

### 揉面 / 踩奶（前爪交替踩）
- 来自幼猫期刺激母猫泌乳的本能。说明它在你身上找到了"安全感、妈妈味儿"。
- 成年猫在你肚子上踩奶 = 极致信任。

### 磨头蹭人
- 头部、脸颊、身体侧面有腺体，蹭你是留信息素 = "这个人是我的"。也是打招呼。

### 送"礼物"（死老鼠 / 死虫子 / 玩具叼来）
- 捕猎本能 + 把你当家人，"教你怎么吃饭"。室内猫送玩具 / 袜子同理。
- 别骂，它觉得自己做了好事。

### 钻箱 / 钻袋 / 钻缝
- 猫喜欢"被包住的安全感"。狭小空间 + 高处 = 完美据点。
- 留几个不同大小的纸箱，能玩一周。

### 凌晨跑酷（3-4 点暴走）
- 猫是晨昏活动动物，黄昏和黎明最活跃。
- 睡前用逗猫棒高强度玩 15-20 分钟，玩完喂饭，模拟"捕猎 → 进食 → 睡觉"循环，能缓解夜间跑酷。

### 推东西下桌
- 部分是好奇（东西动了想去追），部分是吸引注意（推下去你就来了）。
- 别养成"它推我就过去捡"的条件反射，否则它会天天推。

## 三、常见"问题行为"与成因

### 乱尿 / 不用砂盆
- 原因排查顺序：疾病（泌尿问题先排除）→ 砂盆问题（脏 / 不喜欢新砂 / 位置 / 太少）→ 应激（搬家 / 新猫 / 新人）→ 标记行为（未绝育公猫）。
- 别先骂，先排查身体和环境。

### 抓家具 / 抓沙发
- 本能行为，磨爪 + 留气味标记。
- 解决：放抓板在它爱抓的位置旁边，让它有的选。沙发喷防抓喷雾（短暂有效），用双面胶封住常抓点。
- 别剪指甲就不抓了，指甲定期剪也不耽误它要磨。

### 咬人手
- 多数是小时候被人用手逗出来的。手 ≠ 玩具，从幼猫起就用逗猫棒逗，别拿手拨它。
- 咬的时候立刻停手、离开、不反应，让它知道"咬 = 游戏结束"。

### 半夜嚎叫
- 母猫发情（未绝育）：解决靠绝育。
- 老年猫夜间嚎叫：可能认知障碍（猫痴呆）或甲亢、高血压、疼痛，要查。
- 单纯无聊 / 饿：睡前玩 + 加餐，留个漏食球。

### 藏起来不见人
- 新猫到家、应激、生病会藏。别硬拉出来。
- 老年猫突然躲藏 + 不吃 → 高度警惕生病。

## 四、猫的"压力源"清单

猫是极怕变的生物，下列都会引发应激：

- 搬家
- 新成员（新猫 / 新生儿 / 新室友）
- 家具变动、装修
- 换粮、换砂、换碗位置
- 去医院、寄养、坐车
- 节日（鞭炮、客人多、噪音）
- 长时间独自在家（虽然猫独立，但粘人品种长时间无人会焦虑）

应激反应：躲藏、不食、过度舔毛（肚子 / 腿毛秃）、乱尿、上厕所频繁、自发性膀胱炎发作。

## 五、多猫相处

- 新猫到家先隔离 7-14 天，分房间，先闻味再见面。
- 资源 N+1：食盆、砂盆、抓点、高处都按猫数 +1 配置，减少争夺。
- 互相哈气、低吼正常，给时间。打起来才需干预，且别用手（水枪 / 大声拍手打断）。
- 真打架有伤要分开。

---

## 六、猫的智力 / 训练可能

- 猫能学会名字、简单口令（坐下、握手）、按钮交流。
- 训练用正向奖励（零食 + clicker），别用惩罚，惩罚只会让猫躲你。
- 短时多次（一次 3-5 分钟）效果最好。
