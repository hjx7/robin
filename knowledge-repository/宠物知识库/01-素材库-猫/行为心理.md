# 猫 · 行为心理

> 看懂猫在干什么，写文章才有真实的"我家猫怎么怎么了"。
> 这不是百科解释，是"给普通主人讲人话"的素材库：每条行为都带真实解释、容易踩的坑、写文章时能直接抄的场景细节。

---

## 一、肢体语言

### 尾巴
- **竖起、尖微弯**：友好、开心、打招呼。回家时这个姿态 = "你回来啦"。
- **炸毛（像松鼠刷子）**：受惊 / 威胁。弓背炸毛 = "我很可怕别过来"。
- **甩 / 用力抽打**：烦躁、不耐烦、生气。再摸要挨抓。
- **轻摆尾尖**：思考、犹豫、专注（盯鸟时常见）。
- **夹尾巴（贴肚子）**：害怕、示弱。
- **盘腿上、尾尖轻抖**：放松陪伴。

### 耳朵
- **朝前立起**：放松、好奇。
- **转向两侧（飞机耳）**：紧张、防备、要攻击。
- **完全压平贴头**：极度害怕 / 生气。
- **一只朝前一只转向后**：半信半疑。

### 眼睛
- **缓慢眨眼**：信任、亲昵。你回一个慢眨眼给它，是猫界的"我爱你"。
- **瞳孔骤大（圆睁）**：兴奋、紧张、攻击前。
- **半闭**：放松、信任或身体不适（生病也会半闭眼，注意区分）。
- **直视、瞳孔不动**：锁定目标，捕猎或攻击前。

### 声音
- **呼噜声（purring）**：开心放松，但也会在疼痛 / 紧张时呼噜（自我安抚）。
- **喵叫**：主要对人叫（猫之间不靠喵叫交流）。需求：饿了、要开门、求关注。
- **短促颤音 / 咕噜叫**：打招呼、看到你回来。
- **长嚎 / 哀鸣**：发情、极度不适。
- **哈气（嘶嘶）**：警告、防备。别硬碰。
- **咔咔牙（嘎嘎叫）**：看到鸟 / 虫子激动，捕猎模式。

## 二、具体行为解读（按主人最常问的来）

### 1. 冲你露肚皮
> 这坑最多。90% 的新手伸手去摸，直接挨咬。

- **不是"来摸我肚子"，更像是"我信任你，我现在很放松"。**
- 猫的腹部是最脆弱的位置（内脏全在这，没骨头护着），能在你面前翻出来，等于说"我判断你不会攻击我"。
- 摸了会怎么样：三种结果。① 部分是真的亲人，让人摸两下；② 摸 3 秒，猫突然抱手啃（这是反射性的"被攻击了"自卫，不是它翻脸快）；③ 直接后脚连环蹬 + 咬。
- **判断能不能摸**：看它翻肚皮的状态。刚睡醒迷迷糊糊翻的、平时就极其亲人爱撒娇的，可以轻轻摸 1-2 下；它特意走过来在你面前翻肚皮、眼神清醒的，基本是"摆个信任姿势"，摸了必挨咬。
- **写文章素材句**："我家那只刚开始翻肚皮我还激动得不行，以为终于信任我了。结果手一伸，直接四个爪 + 嘴一起上。胳膊上两道红印子。后来才知道，猫翻肚皮是信任你不假，但那意思是'我信任你不会来伤害我'，不是'快来摸我'。哎。"

### 2. 跟着你去厕所
> 这是网上问疯了的一个。

- 目前没有 100% 确认的单一原因，但主流观察有这几条最准：
  - **它觉得你是它的"猫群成员"。** 猫是群居但半独立的动物，核心群成员的活动它要盯。你去的地方 = 安全领地范围的一个点，它要确认。
  - **厕所是你"放下戒备"的地方。** 你在里面关门独处 10 分钟，它怕你出事 / 怕你干了没带它的事。
  - **气味+关门声响的条件反射。** 你每次关门它就知道"主人消失了"，叫声你就开门、出来给零食。久而久之它学会了：关门 = 跟过去。
  - **厕所里有它的气味标记。** 你每次进去，它觉得你在"进入它的地盘"，要过来确认有没有留下它的味。
- 公猫跟着的比例更高，尤其是没绝育的。
- **不是"它怕你掉马桶里"那种搞笑解释。** 但写文章可以先拿这个梗吐槽一下再讲真的。
- **写文章素材句**："我家那只，我一去卫生间它准在门口蹲。关门它就叫，开门它就一溜烟钻进去满地闻。我之前还笑它'是怕我把屎冲没了没你份吗？'后来查了才知道不是。其实更像——你是它的'人'，你去哪它都想知道。有点甜，也有点烦，因为你上个厕所它全程盯着你，拉不出来。"

### 3. 睡你身上 / 睡你床上 / 睡你枕头边
> 位置不同意义完全不同。

- **趴在你胸口 / 肚子上**：极致信任 + 想取暖 + 能听到你的心跳。心跳声像猫在妈妈肚子里的感觉。体重 4-6 公斤的猫，夏天压一身汗，冬天是真暖。
- **睡你大腿上**：你坐着不动的时候来趴 = 它选了"最温暖最稳的据点"。同时跟你保持近距离，你手一动就能摸到它。
- **睡你脚边 / 床尾**：信任你，但还要保留"随时能跑"的退路。很多独立性格的猫就选这个位置。
- **睡你枕头边 / 贴你头旁边**：把你当成"猫群头领 / 妈妈角色"，贴着你有安全感。也有另一种可能——你的头发味它喜欢。
- **挤你进 1/3 个枕头**：它不是故意挤你，是它觉得"这个温度这个味道的地方就这么大，我得占一块"。
- **写文章素材句**："我家那只冬天固定在我胸口睡，10 斤，压得我半夜喘不上气。推它下去，十分钟又爬上来。后来我没办法，侧着睡，它改趴我腰上。现在它睡哪基本决定了我今晚用什么姿势睡。谁懂啊。"

### 4. 踩奶 / 揉面（前爪一伸一缩）
- 来自幼猫期刺激母猫泌乳的本能。成年猫在你身上踩奶 = 它把你当"妈妈级的安全对象"。
- 公猫踩奶概率不比母猫低，甚至有的公猫更爱踩。
- 踩奶时有两个细节：① 会呼噜；② 嘴里会衔一块布 / 你衣服 / 舔自己，模拟吃奶。
- **别打断它**：这是放松到极致的状态，打断了它会失落。
- **写文章素材句**："它踩奶的时候我不敢动。爪子尖又长，戳我脖子一下一下的，我还得憋着。有时候踩着踩着呼噜声太大，我反倒睡不着了。但它要是哪天不踩，我还心里空落落的。"

### 5. 磨蹭你（头、脸颊、身体、尾巴缠你腿）
- 猫的头部、脸颊两侧、下巴、身体侧面、尾根都有气味腺体。
- 蹭你 = 把"它的味道"留在你身上 = 你是它的人了。别的猫一闻：哦，这个人类已经有归属了。
- **蹭完舔你**：顺序是先"给你盖章"，再"把你身上多余的味道舔掉"。双重标记。
- **尾巴缠你脚踝 / 腿**：是"用身体圈住你"的行为，母性强的猫更爱做。
- **写文章素材句**："我下班回家它第一件事就是蹭我裤腿，头一下，身体一下，最后尾巴绕个圈。蹭完我整个裤子沾满它的毛。但它蹭完我妈不蹭我爸，我爸就吃醋，说'它只认你一个'。"

### 6. 叼"礼物"给你（死老鼠 / 死虫子 / 玩具 / 袜子）
- 网上流行的"爱的礼物"只讲了一半。更完整的 4 层解读：
  1. **带回猫群分享**：它自己捕猎成功，带回"群体"分给成员。
  2. **教你捕猎（占大头）**：它觉得你不会抓，怕你饿死，所以把猎物/玩具拿来，示范给你看。你是它眼里"不会捕猎的笨成员"。
  3. **交换**：它叼来 → 你给零食 → 它觉得这是"猎物换饭"的交易，下次还来。
  4. **单纯找你炫耀**：我厉害吧，快夸我。
- 室内猫大多没有真猎物，就叼玩具 / 橡皮筋 / 袜子来顶替。
- **绝对不能骂**：它觉得自己做了好事。骂了它很懵，可能下次藏起来你反而找不到（袜子就这么没的）。
- **正确反应**：当着它的面夸两句"厉害厉害"，给个零食，然后趁它不注意丢了。
- **写文章素材句**："我家那只上周叼了只蟑螂放在我枕头边。我早上醒过来一睁眼，差点原地去世。但我不敢扔，我得先给它拍个马屁，'哇你太厉害了'，赶紧给个冻干。等它转头去吃冻干，我把蟑螂一把丢垃圾桶，手都在抖。"

### 7. 凌晨 3-4 点跑酷
- 猫是晨昏活动动物（crepuscular），不是纯夜行动物。**凌晨 3-5 点、黄昏 5-7 点**是它最活跃的两个时段，基因带的。
- 你在睡觉，它没别的事做，就跑酷 + 玩。
- **跑酷的另一个冷原因：气味扩散标记（90% 主人以为"它开心"）。** 你下班回家 / 洗完澡，身上的味道全变了（外面的气味 / 洗浴液味 / 别人的味道）。猫觉得"这不是我熟悉的群体味道"，需要高速跑几圈，把它自己身上的气味腺体（脸颊/身体侧面/尾根的费洛蒙）蹭到空气中、蹭到地板家具上，重新把你和屋子"标记回同一个群体"。所以典型场景：你推门进来，它门口等，然后突然炸满屋子跑；你洗完澡出来，它当着你面开始跑。
- **缓解方法**：睡前 11 点左右用逗猫棒高强度玩 15-20 分钟，玩完立刻喂饭，模拟"捕猎 → 进食 → 睡觉"的野生循环。吃饱了它就困了，凌晨能安静不少。
- **别半夜起来打它 / 骂它**：它不懂你在气什么，反而觉得"我一跑主人就跟我玩"，更起劲。
- **写文章素材句**："我家那只最神的一次，凌晨 4 点，从我枕头边起步，飞过我脸，踩过我胸口，在我肚子上蹬一脚，直接冲客厅。那一脚我现在都记得，五脏六腑给我踩得一震。第二天眼睛黑圈，我同事说我是不是被打了。"

### 8. 推东西下桌
- 一部分是好奇：东西推了会动会响，像猎物。
- 一部分是吸引注意力：它推下东西的瞬间 = 你会有反应（哪怕是骂它、过去捡）。对无聊猫来说，这就是"互动"。
- **别养成"推 → 你过来捡"的循环**。它推了不要理，等它走了再捡。慢慢它就觉得推东西不好玩了。
- 易碎的杯子化妆品，直接收抽屉。别指望它能"学会"不推那个。
- **写文章素材句**："我桌上之前放了三个杯子，两个被它推下去了。最后一个我放它够不到的书架顶层，它从旁边的窗帘爬上去还是给我推了。我现在水杯用带吸盘的。就离谱。"

### 9. 钻纸箱 / 钻袋子 / 钻缝
- 猫的安全感公式：**狭小空间 + 能看到外面 + 位置偏高 = 完美据点**。
- 几十块的猫窝从来不睡，几块钱的快递箱能睡一个月。
- 冬天箱子保暖，夏天箱子凉快（箱子通风、遮太阳）。
- **写文章素材句**："我给它买了个 199 的猫窝，雪貂那个，毛绒绒的。它闻了一下就走了。最后快递纸箱，9 块 9 的猫粮箱子，它在里面睡了整个冬天。我那 199 打水漂了，现在猫窝我自己放椅子上坐。"

### 10. 盯着你看，然后缓慢眨眼
- 这就是猫界的"飞吻"。意思 = "我信任你，我现在很放松，你在我面前我不紧张"。
- **你能回它**：也慢眨回去。它能看懂，有时候会再回你一个，或者过来蹭你。
- 写文章可以写一个小场景："我跟它有时候就对着慢眨。一次能眨三四个来回。特别傻，但你试了就知道，挺治愈的。"

### 11. 趴在你电脑 / 键盘 / 书上 / 你要用的东西上
- 原因就一个：**它知道这个东西你要用来把注意力从它身上挪开**。
- 你打字的时候，键盘就是"把主人从我这抢走的敌人"，所以它要坐上去，让你不能用，只能摸它。
- **怎么处理**：旁边放一张白纸 / 一个小毯子，它觉得那个是"可以抢的"就会趴过去。
- **写文章素材句**："我坐下来写东西，它三分钟必到位。先跳上桌，绕一圈，精准地趴在我键盘正中间。Ctrl + Shift + 一排乱码。我现在写文章都用手机蓝牙键盘，电脑给它用。它是老板我是助理。"

### 12. 舔你（舔手、舔胳膊、舔头发 / 舔完马上咬一口）
- **舔你** = 给你"梳毛"，在猫群里只有关系好的成员才互相舔（allogrooming）。它把你当家人。
- **舔完突然咬一口**：两种情况。① 它舔你舔得不耐烦了 / 觉得你"脏得没法舔了"。② 它是想跟你玩，舔完"换游戏模式"。
- 猫舔人力气大的时候是糙舌头（有倒钩），舔得皮肤疼。它这是真心在给你梳毛，别嫌疼。
- **写文章素材句**："它舔我胳膊，倒钩舌头皮都舔红了。我想把手抽回来，它还不乐意，抱住我手继续舔。但它舔头发我是真受不了，我一脑袋发胶它也舔，我怕它中毒，每次都得跑。"

### 13. 喵喵叫（不同叫法是什么意思）
> 这个最实用，写文章能用上细节。

- **短的一声 "喵"**：打招呼。"嗨。"
- **连续两三声短喵**：热情的"你回来了！"。
- **中长音 "喵——"**：有需求。饿了、要开门、水碗空了。
- **低音 "呜噜噜喵"（带颤音）**：抱怨 / 不满。比如你把它关在门外了。
- **高音尖喵**：受惊、疼了。听到这个得去看看。
- **夜里持续长嚎**：未绝育的母猫发情、老年猫认知障碍 / 甲亢。
- **写文章素材句**："我家那只叫得有调子。饿了是'喵——'，三个全音符长。要开门是短促两下'喵喵'。我每次一听调子就知道它要干嘛，比闹钟都准。它饿了叫我不起，它就过来把鼻子贴我耳朵叫，那分贝，能把我震醒。"

### 14. 咬手、咬脚（不是攻击的那种软咬）
- 幼猫的"玩咬"，它没轻重，觉得这就是游戏。
- **核心处理原则**：手 ≠ 玩具。从小用逗猫棒跟它玩，别拿手拨它。
- 它咬你的时候，**立刻不动、不叫、不抽手**。你一抽它以为你跟它玩捕猎。你完全没反应，它自己就松口了。
- 松开之后你起身离开，3 分钟不理它。让它知道"咬 = 游戏结束 + 主人没了"。
- **绝对不能弹它鼻子 / 打它**，它会更恨手，以后见手就咬。

### 15. 屁股对着你（把菊花怼你脸上 / 蹲你头旁边屁股朝你）
- 猫群里，它主动把屁股给你看 = "我完全信任你，我觉得你不会偷袭我"。
- 还有一层意思：猫小时候母猫会舔它屁股刺激排泄，它把这个行为当"妈妈照顾我"的记忆。现在它把屁股给你，是想你重复那个动作（它自己忘了小时候具体是什么了）。
- 你不用真舔，意思意思拍两下它屁股就行，它很满足。
- **写文章素材句**："我每次坐在沙发上，它跳我后背蹲着，然后屁股直接怼我脸。臭倒是不臭，但……就很尴尬。后来我查了才知道这是信任。我跟我朋友说，他们说我这信任有点费脸。"

### 16. 藏你东西（发圈、笔、袜子）
- 小物件（圆形、长条、软软的）对它来说是"能捕猎的东西"。它会用嘴叼走，藏到猫窝底下 / 沙发缝 / 床底下。
- 我家统计：一年能从床底扫出 27 根皮筋、11 支笔、3 只袜子。
- 别让它叼到皮筋、发卡、小扣子，吞了要开刀。发圈、头绳这种尽量收抽屉。

### 17. 偷看你洗澡
> 跟"跟着去厕所"相关但不完全一样。

- 你洗澡关门，它觉得这个空间是"危险信号区"（有水声 + 你独处），它要在门口 / 帘子边盯着你，确保你不被水"吃掉"。
- 有的猫怕水，但就是要在旁边守着。你洗完出来它还得闻你一圈，确认你没事。
- 也有猫是好奇：水是什么？为什么主人天天钻这个雾气腾腾的房间？

### 18. 吃饭时"埋食物"（在碗旁边做扒猫砂的动作）
- 两个极端：① **太好吃了**，想"埋起来留着以后吃"（野生习性，吃不完的猎物藏起来）；② **太难吃了**，当屎埋。
- 怎么区分：埋完还回头吃 = 太好吃；埋完直接走 = 难吃。
- **写文章素材句**："我第一次给它换渴望六种鱼，它扒完碗边扒地板，扒了半天。我以为它嫌难吃，差点把新买的 500 块粮退了。后来才知道好吃的它才埋。它当这是它存起来的肉。谁懂啊。"

### 19. 半夜叫你起床 / 拍你脸
- 要么饿了，要么它醒了无聊找你玩。
- 别起来喂它，不然它会学会"叫 = 有饭吃"，天天叫。
- 把自动喂食器定在早上 6-7 点，它醒了去吃，吃完就睡回笼觉。

### 20. 打呼噜
- 最常见是放松，但注意 **疼痛 / 受伤时猫也会呼噜**（自我安抚机制，呼噜的频率 25-150Hz 有促进骨骼愈合的作用）。
- 区分：平时你摸它它呼噜 = 放松；它窝着不动、姿势奇怪、不让你碰还呼噜 = 可能疼，要排查。

### 21. 突然不搭理你（前几天还粘人，突然躲起来）
- 先排查身体问题：口腔疼、脚疼、尿路堵、发烧。
- 身体没事再排查应激：最近有没有家里来新人 / 新猫 / 搬家 / 家具换位置 / 去医院。
- 别硬拉出来，放吃的放玩具在附近，等它自己出来。连续 24 小时不出来 + 不食 = 要查。

### 22. 转移行为（你骂完它，它突然开始疯狂舔毛 / 挠东西 / 喝水 / 刨地）
- 行为学冷门。当猫同时出现两个冲突的冲动（想攻击你 + 又怕你打它 / 想跑 + 又跑不掉）→ 大脑跳出来，做一个完全不相关的第三种动作缓解压力。就像人紧张时突然开始抠手 / 摸耳朵。
- 典型场景：你骂完它推杯子，它扭头开始疯狂舔自己的背 / 拼命挠沙发 / 跑到水碗大口喝水 / 在地上假装扒拉猫砂。
- **主人最容易踩坑的解读：** "这猫不服气 / 它故意气我 / 它根本不怕我。" → 99% 反了。它正处于高压紧张状态，在自我安抚。
- **正确做法：** 停止责骂，离开现场，让它冷静。别追上去继续骂，不然压力升级可能变攻击。
- **写文章素材句：** "我骂完它推杯子，它开始猛舔自己的背。我以为它装没听见，更气了，追过去又骂了两句。结果它突然哈我。后来查资料才知道，那时候它已经在高压临界点了，是我自己把它逼炸的。"

### 23. 裂唇嗅反应（Flehmen Response，鬼脸）
- 猫做了一个"半张嘴、嘴唇上翘、鼻子皱起、目光呆滞"的表情，像看到特别臭的东西一脸嫌弃。
- 它不是嫌弃，是在用**犁鼻器（Jacobson 器官，位于口腔顶部）** 分析气味。专门用来闻异性尿味、其他动物留下的信息素、陌生气味。正常呼吸鼻子接收不到这种分子，它要做这个鬼脸，把气味"泵"进犁鼻器里分析。
- 触发场景：公猫闻母猫尿、发现陌生狗/猫来过家里、闻到没闻过的植物/新鞋味。
- 不是每个气味都做，特别有信息量的气味才会做。别以为它在嘲讽你。

### 24. 咬手分级（3 级，主人 90% 误读）
很多主人被猫咬了要么觉得"它喜欢我"要么觉得"它恨我"，实际按轻重 3 级完全不一样：

| 级别 | 表现 | 是什么 | 怎么处理 |
|---|---|---|---|
| **1 级：软咬（含手、轻轻叼）** | 轻轻含住，不用力，不疼，不出血 | 信任 + 玩耍邀请 / "你是我自己人" | 可以接受，但手 ≠ 玩具，慢慢转用逗猫棒 |
| **2 级：啃破皮 + 后脚连环蹬（兔蹬）** | 咬破手皮（针孔状/轻微流血）+ 后腿同时蹬你肚子 | **它在测试等级，确认谁是老大。** 幼猫间互相打的动作，它觉得你是同类，你不叫疼不反抗，它默认自己等级比你高。 | 立刻不动（不抽手不叫）→ 等它松口 → 起身离开 3 分钟。下次不允许咬手。 |
| **3 级：攻击咬（深深扎进去 + 甩头）** | 狠狠咬下去 + 头部左右甩（狗常见猫也有）+ 出血量大 + 后续哈气炸毛 | 真攻击。它真的怕了 / 真的恨了 / 你碰了它极度反感的部位 | 立刻松手 / 后撤。后续查应激源 / 身体疼痛。这种咬不要训练，先找原因。 |

## 三、常见"问题行为"与成因

### 乱尿 / 不用砂盆
- 原因排查顺序：疾病（泌尿问题先排除）→ 砂盆问题（脏 / 不喜欢新砂 / 位置 / 太少）→ 应激（搬家 / 新猫 / 新人）→ 标记行为（未绝育公猫）。
- 别先骂，先排查身体和环境。

### 不埋屎（主人 90% 骂"笨 / 没教好"，其实有 4 层真实原因）
- 排查顺序：身体问题先排除 → 猫砂本身问题 → 行为/地位问题 → 心理压力。
- 具体 4 层解读：

| 层级 | 原因 | 典型特征 | 解决 |
|---|---|---|---|
| 1 | **地位高（头领不用盖味道）** | 多猫家庭固定那一只不埋，其他猫都埋；它不怕被报复 | 自然现象，不用管。它是头领。 |
| 2 | **砂盆 / 猫砂它极度嫌弃** | 新换了猫砂（尤其从豆腐砂突然换膨润土）；砂盆太脏（2-3 天没铲）；砂盆位置吵/被盯着；盆边太高中老年猫跳不进去 | 换回原来的砂，每天铲，检查位置，大猫换矮边盆 |
| 3 | **身体疼（蹲姿痛）** | 上完立刻跳走，不埋；伴随走路姿势奇怪 / 上厕所哼哼 | 查关节痛 / 结肠炎 / 肛周炎 / FLUTD 尿痛 |
| 4 | **被另一只猫压制（不敢留味）** | 埋完扒的是盆边空气，没真扒到砂；趁另一只不在才敢上，上完赶紧跑 | 多猫加盆，分开放不同区域，给弱势猫单独一个安静盆 |

- 别一上来就骂"你连屎都不会埋！"、手动抓它爪子扒砂。猫会更焦虑。

### 抓家具 / 抓沙发
- 本能行为，磨爪 + 留气味标记。
- 解决：放抓板在它爱抓的位置旁边，让它有的选。沙发喷防抓喷雾（短暂有效），用双面胶封住常抓点。
- 别剪指甲就不抓了，指甲定期剪也不耽误它要磨。

### 咬人手
- 多数是小时候被人用手逗出来的。手 ≠ 玩具，从幼猫起就用逗猫棒逗，别拿手拨它。
- 咬的时候立刻停手、离开、不反应，让它知道"咬 = 游戏结束"。

### 半夜嚎叫
- 母猫发情（未绝育）：解决靠绝育。
- 老年猫夜间嚎叫：可能认知障碍（猫痴呆）或甲亢、高血压、疼痛，要查。
- 单纯无聊 / 饿：睡前玩 + 加餐，留个漏食球。

### 藏起来不见人
- 新猫到家、应激、生病会藏。别硬拉出来。
- 老年猫突然躲藏 + 不吃 → 高度警惕生病。

### 过度舔毛（肚子 / 腿毛秃一块）
- 90% 是应激引起的"心因性脱毛"。先排除皮肤病 / 真菌感染。
- 常见应激源：新猫来、搬家、主人长时间出差。处理靠费利威扩散 + 给它一个安静小空间 + 慢慢增加游戏时间。

## 四、猫的"压力源"清单

猫是极怕变的生物，下列都会引发应激：

- 搬家
- 新成员（新猫 / 新生儿 / 新室友）
- 家具变动、装修
- 换粮、换砂、换碗位置
- 去医院、寄养、坐车
- 节日（鞭炮、客人多、噪音）
- 长时间独自在家（虽然猫独立，但粘人品种长时间无人会焦虑）

应激反应：躲藏、不食、过度舔毛（肚子 / 腿毛秃）、乱尿、上厕所频繁、自发性膀胱炎发作。

## 五、多猫相处

- 新猫到家先隔离 7-14 天，分房间，先闻味再见面。
- 资源 N+1：食盆、砂盆、抓点、高处都按猫数 +1 配置，减少争夺。
- 互相哈气、低吼正常，给时间。打起来才需干预，且别用手（水枪 / 大声拍手打断）。
- 真打架有伤要分开。

---

## 六、猫的智力 / 训练可能

- 猫能学会名字、简单口令（坐下、握手）、按钮交流。
- 训练用正向奖励（零食 + clicker），别用惩罚，惩罚只会让猫躲你。
- 短时多次（一次 3-5 分钟）效果最好。

## 七、猫的生理冷知识杂项（猎奇向写文章涨粉好用）

> 都是冷门但真实的猫生理特征，写文章当"小彩蛋"放进去，读者愿意转。

| 冷知识 | 说明 | 可以写的梗 |
|---|---|---|
| **猫鼻纹 = 人类指纹，全球唯一** | 每只猫鼻子上的纹路（细小凸起和沟壑）完全不一样。日本、英国已经用鼻纹做"猫护照"、救助站身份识别。 | 以后你家猫丢了，别只拍花色，拍一下鼻子特写。 |
| **只有爪垫能出汗，全身其他地方不出汗** | 猫的汗腺只分布在肉垫里。夏天摸它耳朵内侧发烫、肚皮发热 = 它在散热，不要只摸背。猫正常体温 38-39.2℃，不是人的 36.5-37℃。 | 夏天它踩过的地板都是一个个小汗脚印。 |
| **32 块耳肌，人只有 6 块 → 耳朵可独立转 180°** | 两个耳朵能分别转不同方向，像两个独立雷达。所以它明明面朝前方睡觉，后面你悄悄拆零食，它耳朵立刻转过来。 | 不用回头，也能听见你在背后偷偷开猫条。 |
| **直接注册步态（Registered Gait）** | 猫走路时，后腿每次都精确踩在前腿踩过的同一个脚印里。雪地里看它的脚印 = 永远只有 2 排脚印，不是 4 排。 | 雪后它从雪地走过，地上只剩两个坑，朋友以为你家只有两条腿的猫。 |
| **睡 12-16 小时 / 天，其中 70% 是浅眠** | 它大部分时间是"打盹"，随时能醒过来（捕猎者本能），只有 30% 左右是深度睡眠（四脚朝天、偶尔抽搐做梦）。 | 你出门 8 小时，它睡 6 小时，剩下 2 小时用来蹲门口等你回来。 |
| **跳跃高度是自身体长的 5-6 倍** | 40 厘米长的猫能轻松跳到 2 米高的冰箱顶。它的后肢肌肉是弹射结构。 | 你家冰箱上那层灰，都是它的脚印你看不见。 |
| **眼睛视野 200°，人只有 180°** | 两侧多出来的 20° 让它能看到侧面过来的鸟 / 虫子。但它的近处对焦差（< 30cm 看不清），所以它闻你的脸其实是"我得凑近点才能看清楚你长啥样"。 | 把零食放它鼻子底下，它先找半天。放远 30cm 它一下看见了。 |

## 八、文章素材卡（直接抄场景的）

> 下面是一些"踩过坑的第一人称素材句子"，写文章时挑几条插进去，去 AI 味。

**露肚皮挨咬经历**："我家那只翻肚皮，我摸了三次，挨了三次。第二次我学乖了，手伸到一半停下来，它看我手没过来，自己翻回去睡了。现在我看到它翻肚皮，第一反应是后退半步。"

**跟着去厕所经历**："我上厕所它蹲门外。有一次我便秘，在里面坐了 15 分钟，它在门外那个叫啊，跟我死在里面了一样。我开门出来它围着我转三圈，闻我裤腿，确认我没被冲走。"

**被猫跑酷踩醒经历**："它凌晨 4 点踩我脸跑过去。我跟我对象说'你闺女刚才踩我了'，他说'那是你闺女，叫你妈呢'。气的我。第二天他被踩了才闭嘴。"

**打呼噜认错人经历**："我之前以为它呼噜就是开心。有一次它从桌子上摔下来，瘸着腿还在呼噜，我以为它没事，送医院才知道是骨折了。那时候我才知道呼噜不全是开心。"

**键盘上长猫经历**："我现在写东西，它就趴我键盘上。我手一伸过去摸它，它呼噜。我手伸过去打字，它按住我手。现在我所有东西都是用脚写的（开玩笑），实际上是我把电脑放地上，我站着打字，桌子给它用。"
