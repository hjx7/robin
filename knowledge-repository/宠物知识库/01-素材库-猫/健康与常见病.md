# 猫 · 健康与常见病

> 常见病、急症信号、体检、疫苗、绝育。写文章时拿来当背景知识，别当诊断依据。

---

## 一、疫苗

### 猫三联（核心疫苗）
- **预防**：猫瘟（猫细小病毒 FPV）、猫鼻支（猫疱疹病毒 FHV-1）、猫杯状病毒（FCV）。
- **接种时间**：
  - 首免：8 周龄第一针，间隔 21-28 天打第二针，再隔 21-28 天第三针（具体看厂家，一般 2-3 针）。
  - 加强：第二年打一针。之后每 1-3 年根据抗体检测决定是否加强。
- **疫苗本**：每次打完医生要登记批次、日期、签名。无疫苗本的猫后续寄养 / 进住院都麻烦。

### 狂犬疫苗
- **时机**：3 月龄以上，猫三联打完后。
- **频率**：一年一针。散养 / 经常外出的猫建议打。纯室内 + 不接触其他动物的，可跟医生商量。
- **注意**：有猫打狂犬后出现注射部位肉瘤（FISS）的极低概率风险，打在腿部或尾根，万一发生方便处理。

### 猫白血病（FeLV）
- 散养 / 接触史复杂的多猫家庭建议打，纯室内单猫家庭可选。

## 二、驱虫

### 体内驱虫
- **频率**：室内猫 3 个月一次，散养 / 喂生肉的 1 个月一次。
- **常用药**：拜宠清（吡喹酮，主绦虫）、大宠爱（塞拉菌素，内外同驱）、海乐妙（米尔贝肟）。
- **注意**：体内驱虫要在猫健康时做，生病 / 体弱 / 刚打完疫苗期间别做。

### 体外驱虫
- **频率**：春夏蚊虫季 1 个月一次，冬季可拉长到 2-3 月。经常出门的猫全年每月一次。
- **常用药**：大宠爱（滴脖子，内外同驱）、福来恩（滴剂）、爱沃克。
- **注意**：滴剂滴在猫舔不到的后脖颈，滴完 48 小时别洗澡别被雨水淋湿。

## 三、绝育

### 时机
- 传统建议 6-8 月龄、疫苗齐全后。
- 现在很多医生推荐早期绝育（4-6 月龄，疫苗 + 体重达标后），降低意外怀孕和一些激素相关疾病。
- 母猫建议在第一次发情前绝育，乳腺瘤风险大幅降低。

### 公猫 vs 母猫
- **公猫**：摘睾丸，体表小切口，当天 / 次日能出院，恢复快。费用 200-500。
- **母猫**：开腹摘子宫卵巢，住院 2-3 天，戴伊丽莎白圈 7-10 天，费用 500-1500（地区差异大）。

### 术后注意
- 戴圈！戴够天数！猫舔伤口会感染 / 拆线失败。
- 限制活动 3-5 天，别让它上蹿下跳。
- 公猫基本不用拆线（吸收线），母猫看用的线，10-14 天拆。
- 母猫呼吸性检查：少数猫麻醉后呼吸不畅，住院期间医生会观察。
- **⚠️ 公猫绝育后常见疑问：半年了还骑猫 / 还乱尿。**
  - 90% 不是"没阉干净"。激素完全从身体代谢完需要 3-6 个月，这段时间仍有残留性行为。
  - 6 个月后还频繁骑的常见原因：① 肾上腺皮质增生（肾上腺也会分泌少量性激素）② 性经验记忆（有过配种经历的猫保留了行为习惯）③ 焦虑替代行为（压力大时骑玩偶 / 猫来释放）。
  - 先排查后两条，确实怀疑肾上腺的，去医院查性激素 4 项，不用花钱复检睾丸。

## 四、必须立刻就医的急症信号

记住这些，出现就别等：

1. **尿不出来 / 反复蹲砂盆无尿**：公猫尤其危险，可能是尿道梗阻，48 小时内可致急性肾衰，致命。
2. **持续呕吐不止 / 呕吐物带血 / 呕吐物有粪臭味**：肠梗阻可能。
3. **张嘴呼吸、舌头发紫**：心力衰竭 / 肺水肿 / 哮喘急性危象，马上急诊。
4. **突然瘫倒 / 后腿无力 / 后腿冰凉 / 嚎叫**：血栓栓塞（多见于心脏病猫），分秒必争。
5. **抽搐**：癫痫 / 中毒 / 低血糖 / 高血氨（精氨酸缺乏）。
6. **误食有毒物后 1-2 小时内**：立刻送，路上可打电话给医生准备催吐（看毒物种类，有些不能催）。
7. **持续腹泻 + 不吃不喝超过 24 小时**：幼猫脱水快，几小时就危险。
8. **眼睛突然睁不开、瞳孔不等大、眼球明显肿胀**。
9. **高坠（窗台掉下去）即使表面没事也要查**：高坠综合征常伴肺挫伤、内脏、骨折。
10. **瞬膜（第三眼睑）突然大面积外露：** 99% 新手不知道瞬膜是什么。正常情况下眼角内那层粉白色薄膜只露出一条边，大面积冒出来盖住半个眼球 = 急症信号。常见原因：脱水、发烧、霍纳氏综合征、瞬膜腺脱出（樱桃眼）、急性神经病变。别等。
11. **胡须批量掉落 + 精神差：** 触须（胡子）的生长期是普通毛发的 2-3 倍，正常情况下 1-2 周掉 1-2 根是正常代谢。短时间内（1-2 周）掉 3-5 根以上 + 连根拔起的秃块 = 严重免疫病 / 深层真菌感染 / 蠕形螨。立刻去查皮肤刮片 + 免疫。
    - 另一个冷知识：**人为剪猫胡须 = 剥夺它的空间感知能力。** 胡须是触觉传感器（判断洞口宽度、空气流动），剪了它会走路撞墙、跳不准距离、进食定位困难。完全不能剪。
12. **不明原因流口水 + 空嚼 + 抽搐 + 最近喂过自制粮/纯素：** 高度怀疑**精氨酸缺乏导致的高血氨脑病**，死亡率极高。24 小时内发病。（详见喂养饮食.md 精氨酸章节）。

## 五、常见病速查

### 上呼吸道感染（猫鼻支 / 杯状）
- 症状：打喷嚏、流鼻涕、眼屎多、结膜炎、食欲下降。严重时口腔溃疡（杯状典型）。
- 病原：疱疹病毒（终身带毒，应激复发）、杯状病毒。
- 处理：轻症支持护理（雾化、清理分泌物、强饲），重症用干扰素、赖氨酸（疱疹可减轻）、抗生素防继发感染。
- 家里有杯状猫的，其他猫建议隔离。

### 猫瘟（FPV）
- 症状：高烧、呕吐、腹泻（常带血）、白细胞骤降、迅速脱水。
- 传播：接触传播，幼猫、未免疫猫高危。
- 治疗：住院、输液、抗生素防继发、隔离。
- 预防：疫苗！疫苗！疫苗！成年猫抗体检测可决定是否加强。

### 泌尿系统疾病（FLUTD）
- 包括：自发性膀胱炎（FIC，最常见）、尿路结石、尿道梗阻。
- 症状：频繁上厕所、蹲很久尿少 / 无尿、尿带血、尿砂盆里嚎叫、乱尿。
- 公猫尿道细长，梗阻风险高，是急症。
- 处理：梗阻需导尿 / 冲洗膀胱，住院几天；自发性膀胱炎多与应激有关，长期靠湿粮 + 多喝水 + 降应激管理。
- 处方粮：皇家泌尿处方、希尔斯 c/d、c/d 多护，医生指导下用。

### 慢性肾病（CKD）
- 老年猫高发，7 岁以上建议每年查。
- 症状：多饮多尿、消瘦、口臭（氨味）、食欲差、呕吐。
- 检查：血生化（BUN、CREA、SDMA 早期更敏感）、尿检（尿比重低）。
- 管理：低磷低蛋白处方粮（希尔斯 k/d、皇家肾处方）、皮下补液、降压药、磷结合剂。
- 不能治愈，能拖好几年，早查早管差别很大。

### 糖尿病
- 老年胖猫高发。
- 症状：多饮多尿、吃得多却瘦、后肢跖行（走路踩脚背）。
- 治疗：胰岛素（一天两针，长期）、低碳水高蛋白饮食、减重。
- 部分猫经过饮食 + 减重后可缓解，停胰岛素。

### 肥厚型心肌病（HCM）
- 遗传性，英短、美短、布偶、缅因高发。
- 早期无症状，听诊有杂音后做心超确诊。
- 进展：心衰、肺水肿、血栓栓塞（后腿瘫痪）。
- 管理：心超随访，有心衰用呋塞米、匹莫苯丹等，定期复查。
- 购买上述品种时问父母有无 HCM 基因检测（布偶有已知突变，可查）。

### 食物 / 跳蚤过敏皮炎
- 症状：头部颈部瘙痒、脱毛、小红疹、跳蚤黑点。
- 处理：驱蚤 + 低敏粮试验 8 周以上，类固醇短期止痒。

### 黑下巴 / 粉刺
- 下巴黑点、油腻、掉毛。
- 多数是塑料饭碗 + 油渍 + 细菌。
- 换陶瓷碗、定期用洗必泰擦，顽固的看医生。

### 猫支气管哮喘（干咳）
- 极易被主人当"吐毛球没吐出来"，拖半年以上。
- 典型表现：脖子前伸、弓背、咔咔咔一串干咳（什么都没吐出来），腹部一抽一抽。和吐毛球的胃部收缩呕的动作完全不同。常见诱因为香薰、粉尘、猫砂尘、冷空气、过敏。
- 诊断：胸片（支气管纹理增粗、甜甜圈征），排除心脏后确诊。
- 长期控制：环境去刺激 + 吸入激素（氟替卡松+猫面罩）+ 支气管扩张剂。急性发作张嘴呼吸是急症。
- → 详见疾病深度专题《猫哮喘》。

### 猫脂肪肝（肝脂质沉积症）
- 跟人脂肪肝方向反。**人是吃出来的，猫是饿出来的。** 胖猫断食 3-5 天就能触发黄疸，断食 7 天以上肝细胞不可逆坏死。
- 常见诱因：换粮拒食（宁死不屈型）、搬家应激、其他疾病拒食、主人故意饿减肥、自动喂食器卡粮。
- 典型症状：眼白发黄 → 耳内侧黄 → 牙龈黄，尿橙汁色、大便灰白。
- 治疗核心：不是护肝针，是**饲管强制喂回去**。只要蛋白和热量喂够量，肝会自己排脂肪。
- → 详见疾病深度专题《猫脂肪肝（肝脂质沉积症）》。

### 猫胰腺炎
- 跟狗不一样，**不一定吐**，最常见症状就是"不吃 + 精神差"，非常容易漏诊。
- 症状：厌食、精神萎靡、呕吐（50% 左右有，不是全部）、腹痛（抱起来哼唧）、发热。
- 诊断：生化胰脂酶（cPLI / fPL）敏感性最高，配合腹部 B 超。单独试纸假阳性高。
- 治疗：输液 + 止吐 + 止痛 + 低脂易消化饮食。和脂肪肝常伴随出现（胖猫先胰腺炎不吃，接着脂肪肝）。
- → 常与胆管肝炎、炎性肠病合并出现，见下条"三体炎"。

### 猫三体炎（Triaditis）
- 三种炎症一起出现：**炎性肠病（IBD）+ 胆管肝炎 + 胰腺炎**。中年猫高发，长期管理难度大。
- 症状极不典型：长期软便 / 腹泻、间歇性呕吐、逐渐消瘦、食欲时好时坏、发烧波动。
- 诊断：需要全套生化、超声、胰脂酶、胆汁酸、甚至肠道活检。
- 治疗：长期低脂低敏饮食 + 免疫抑制剂（激素 / 环孢素）+ 利胆 + 胰腺炎支持管理。治疗周期长，易反复。

### 猫慢性龈口炎（区别牙结石）
- 不是"刷牙没刷好"那么简单。猫慢性口炎是**免疫介导**的疾病，口腔黏膜对牙齿上的菌斑过度反应、产生自身免疫攻击。
- 典型：刷牙时一碰就大量出血、口腔后部黏膜红肿溃烂、严重的叫不出声音 / 吃不下饭。
- 和牙结石/牙周炎的区别：牙周炎是牙龈局部的问题；慢性口炎是整个口腔黏膜大片溃烂，**不是洗牙能解决的**。
- 治疗金标准：**全口拔牙 / 全口臼齿拔除**（很多主人接受不了，但这是唯一有效率在 60-80% 的方法）。保守用环孢素、干细胞、干扰素效果不稳定且短期。
- 日常护理章节里的"刷牙"是针对预防牙周炎，对慢性口炎发作期反而不能刺激。

## 六、体检建议

| 年龄 | 频率 | 建议项目 |
|---|---|---|
| 幼猫（接猫时） | 1 次 | 血常规、SAA、猫瘟抗原、粪检、基础体检 |
| 成年猫（1-7 岁） | 一年一次 | 基础体检 + 血常规 + 生化（肝肾功能）+ 尿检 |
| 老年猫（7 岁+） | 半年-一年一次 | 加心超、甲状腺（T4）、SDMA |

- 一次完整血常规 + 生化 + 尿检约 300-600，加心超再加 300-800。地区差异大。
- 提前问医院是否有团购体检套餐，便宜不少。

## 七、家庭常备

- 体温计（肛温 / 耳温）：猫正常体温 38-39.2 度，39.5 以上算发烧。
- 体重秤：每周称一下，突然掉秤要警惕。
- 益生菌（换粮 / 软便应急）。
- 退热 / 止血粉 / 生理盐水（洗伤口 / 洗眼）。
- 碘伏 / 洗必泰（皮肤伤口消毒，酒精别直接用，刺激大）。
- 伊丽莎白圈（备用，PVC 软圈 20 块一个）。
- 急救电话：存好 24 小时急诊医院电话和地址。
