# 猫 · 喂养饮食

> 猫粮、罐头、自制、喂法。带品牌、价位、配料怎么看，写文章时随手用。

---

## 一、猫是严格肉食动物

- 必须从动物性蛋白获取牛磺酸（自己合成不了），缺乏会致盲、心肌肥厚。牛磺酸缺乏是缓慢的，几周几个月才有症状。
- **精氨酸（Arginine）缺乏比牛磺酸还急。** 猫的尿素循环完全依赖精氨酸，一顿不含精氨酸的饭，24 小时内就能出现高血氨 → 昏迷 → 死亡。自制低蛋白粮 / 纯素食是最大坑。这一点 99% 的新手不知道。
- 不能长期吃素。不能长期吃狗粮（狗粮里没有足量牛磺酸，且蛋白偏低）。
- 猫不爱喝水，天性靠食物补水分。只喂干粮的猫普遍喝水不够，是泌尿问题高发的原因之一。
- **猫没有甜受体（Tas1r2 基因缺陷），尝不出甜味。** 抢你的蛋糕/奶油/奶茶，不是喜欢甜味，是闻到了脂肪和蛋白质的味道。但**木糖醇（无糖食品甜味剂）对猫剧毒**，它吃不出来甜味但一样会中毒（低血糖、肝损）。

## 二、干粮怎么看配料表

看配料表，从前往后含量递减。好粮的特征：

1. **前三位是肉**：明确写"鲜鸡肉 / 鸡肉粉 / 三文鱼"这种具体来源，而不是"肉类及制品"这种含糊词。

   > **⚠️ 网红营销反向拆解："鲜肉第一" ≠ 肉多，肉粉蛋白密度更高**
   >
   > 很多品牌用"鲜肉第一位"打营销点，很多人以为这就是好粮。实际上：
   > - **鲜肉（Chicken）含水 70%。** 烘干成粮水分剩下 10%，它的实际干物质重量会掉 60% 以上。写在第一位，烘干后可能排第 6-7 位。
   > - **肉粉（Chicken Meal）蛋白密度 60%+，水分只有 10%。** 同样写在第一位，实际提供的蛋白质可能是鲜肉的 2-3 倍。
   >
   > 真对比方法：看"鲜肉 + 肉粉组合"加起来是不是单点第一，或者看**保证分析里的粗蛋白百分比**。别被"鲜肉第一"四个字忽悠了。

2. **粗蛋白 ≥ 32%**（成猫），幼猫 ≥ 34%。低于 28% 的别考虑。
3. **粗脂肪 10%-20%** 合理。
4. **无谷物 / 低谷物优先**：猫不需要碳水，玉米小麦大豆主要是凑低成本和成型。无谷粮碳水来自豌豆 / 鹰嘴豆 / 木薯。
5. **牛磺酸必须有**：配料表或添加剂里应列出。
6. **避免诱食料**：口味增强剂、宠物复合调味料这种，本质是诱食，让猫爱吃没营养的粮。
7. **避免人工防腐**：BHA / BHT / 乙氧基喹啉，看到这仨基本可以 pass。

## 三、常见猫粮品牌参考（价位梯度）

> 价格仅供参考，会波动。这是写作素材，不是购买建议。

### 顶级进口（40-60 元/斤）
- **渴望（Orijen）**：六种鱼、鸡肉。高蛋白高脂肪，蛋白 40%+，猫爱吃但部分猫会软便（蛋白太高）。
- **爱肯拿（Acana）**：渴望的"平价版"，蛋白略低，性价比更高。
- **纽翠斯（Nutrience）**：黑钻系列冻干粮，中高端口碑稳。

### 中端进口 / 国产高端（25-40 元/斤）
- **Go! Solutions**：九种肉口碑好，蛋白高，同样注意软便问题。
- **Now Fresh**：无谷系列，配方干净。
- **网易严选**：国产双 11 高蛋白款，性价比标杆。
- **诚实一口**：冻干双拼，蛋白实诚，配料表清晰。
- **高爷家 / 网易 / 卫仕 / 伯纳天纯**：国产新势力，性价比梯队。

### 中低端（15-25 元/斤）
- **皇家（Royal Canin）**：处方粮线最全，普通粮中规中矩偏贵。英短专用、绝育猫专用是细分款。
- **比瑞吉 / 伯纳天纯普通款**：配方一般，胜在稳定易买。

### 警示区
- 超市 / 五金店那种十几块一斤散装粮、"宠物调味"重口味的，基本是诱食料 + 劣质原料，长期吃肝肾要出事。
- 三无猫粮、淘宝 9.9 包邮的，别碰。

## 四、湿粮 / 罐头

### 主食罐 vs 零食罐
- **主食罐**：营养完整可替代干粮，配料表里通常有"完整营养"标识，蛋白 8%-12%（含水高）。
  - 常见：希尔斯科学计划、 ziwi 巅（巅峰）、K9、宏榴、迈格迷斯、卡比。
  - ziwi 巅（新西兰）300g 一罐 30-50 元，贵但质量硬。
- **零食罐**：补充水分 / 适口性用，营养不完整，不能当主食。泰源、伊纳宝那些一条条的就是零食罐。

### 喂法建议
- 干湿搭配最理想：早晚各一餐，一餐干粮一餐主食罐，水盆另备。
- **生熟粮 / 生骨肉和干粮不能混喂，间隔至少 4 小时。** 生肉需要胃酸 pH1-2 才能杀菌消化（消化周期 12-24 小时），熟食和干粮会把胃酸稀释到 pH4-5。混喂 → 生肉里的细菌活下来没被杀掉 → 急性肠胃炎拉血。自制鲜食和干粮同理。
- 罐头开封后冷藏不超 48 小时，吃前回温。
- 不爱喝水的猫靠主食罐补水效果立竿见影。

## 五、喂食频率与量

| 阶段 | 频率 | 单次量（参考） |
|---|---|---|
| 幼猫（1-3 月） | 一天 4 顿 | 少食多餐，泡软幼猫粮 |
| 幼猫（3-6 月） | 一天 3 顿 | 干粮自由采食也行 |
| 成猫（6 月+） | 一天 2 顿 | 早 7 晚 7，一顿 30-40 克干粮 |
| 绝育后 | 一天 2 顿 | 减量 10-20%，绝育后代谢慢易胖 |
| 老年猫（10 岁+） | 一天 2-3 顿 | 易消化的老年粮，蛋白别降太多 |

- 胖瘦判断：摸肋骨，能轻松摸到是正常；摸不到 = 胖，骨头硌手 = 瘦。
- 7 公斤以上的英短 / 布偶 / 缅因不算胖，骨架大。
- **⚠️ 警惕"挑食型脂肪肝"（宁死不屈型）：** 换粮直接停旧粮、新粮不合口味 → 倔的猫宁可几天不吃。胖猫 3 天完全不吃就能触发黄疸。换粮必须走 7-10 天过渡；如果超过 24h 完全没吃，把旧粮加回去，慢慢再调。
- **⚠️ 节假日自动喂食器 = 脂肪肝隐患：** 自动喂食器卡粮 2 天没人发现，是宠物医院真实常见案例。出门前一定要手动测试 2-3 顿，最好同时备一份备用粮（放邻居/朋友那儿）。

## 六、饮水

- **每天饮水量**：大约 40-60ml/kg。4 公斤猫一天 160-240ml。
- 只喂干粮的猫喝水不够是常态，泌尿结石、慢性肾病高发与此相关。
- **催喝水的招**：
  - 流动水：宠物饮水机（小米 / 雪貂 / 美的，50-200 元），很多猫就爱喝流动的。
  - 多个水点：家里放 2-3 个水碗，不同位置。
  - 玻璃 / 陶瓷碗比塑料好，塑料留味儿猫嫌弃。
  - 水里加一点冻干碎 / 一勺泡水罐头，骗水喝。
  - 水盆别放猫砂盆旁边。

---

## 七、换粮

- 换粮必须 7-10 天过渡，比例从 75% 旧粮慢慢到全新粮，避免肠胃不适应拉肚子。
- 突然换粮拉稀是常见翻车点。
- 换粮期可以拌点益生菌（布拉迪酵母、宠物益生菌）。

## 八、猫不能吃的东西（红线）

- **葱 / 蒜 / 洋葱 / 韭菜**：破坏红细胞，溶血，致命。
- **巧克力 / 可可**：可可碱中毒。
- **葡萄 / 葡萄干**：急性肾衰，少量都不行。
- **咖啡 / 茶 / 功能饮料**：咖啡因中毒。
- **酒精**：猫代谢不了，极少量就中毒。
- **木糖醇**：低血糖、肝损伤。注意无糖食品、无糖口香糖、蛋糕里常加。
- **生鸡蛋清**：含抗生物素蛋白，影响生物素吸收。熟鸡蛋可以。
- **生鱼 / 长期单一海鱼：4 个坑都在这**：
  1. **硫胺素酶破坏维生素 B1**，长期吃会神经症状（抽搐、共济失调）。
  2. **金枪鱼 / 马鲛鱼碘过量** → 长期吃诱发甲亢（猫甲亢高发原因之一）。
  3. **金枪鱼高汞富集** → 长期慢性肾损和神经毒性。
  4. **不新鲜海鱼高组胺中毒** → 身体发红、呕吐、休克（鲭鱼 / 秋刀鱼 / 金枪鱼最常见）。
  → 海鱼偶尔喂一顿可以，别长期天天喂金枪鱼罐、别喂不新鲜的。
- **骨头（特别是煮熟的鸡骨）**：碎裂刺穿肠胃。
- **牛奶**：多数猫乳糖不耐受，拉肚子。要喝用宠物羊奶粉或无乳糖奶。
- **人的剩饭**：盐分油分都超，长期吃肝肾负担大。
- **百合科植物（植物类红线）：** 百合花瓣/花粉、郁金香鳞茎、风信子球根、铃兰全株、芦荟汁液。**哪怕舔一点花粉都能急性肾衰。** 具体见误食中毒急救.md 里的百合科扩大版图。

## 九、营养品 / 补剂

- **牛磺酸**：好粮里够，不用单独补。
- **化毛膏 / 猫草 / 化毛片：**
  - **化毛膏本质 ≠ 化毛。** 主要成分是矿物油（润滑）+ 糖浆（调味）+ 少量纤维。它不是把毛"化掉"，是让毛随着粑粑一起润滑滑出来。多吃会胖（糖多），矿物油长期用影响脂溶性维生素吸收。
  - **猫草（大麦/小麦苗）和化毛片**：靠粗纤维刺激肠道，排出毛球 / 催吐，比化毛膏更干净。长毛猫 / 掉毛季可喂。
  - 短毛猫日常勤梳毛基本够用。
- **鱼油**：Omega-3 对皮肤毛发好，掉毛季可加。别贪多，油大易软便。
- **益生菌**：换粮、软便、应激时短期用。
- **营养膏**：本质是糖 + 脂肪 + 维生素，当零食 / 应激期补能量，不是必需品。
- **钙 / 微量元素**：吃合格猫粮的健康猫不用补，乱补反而出事。
