# 猫 · 喂养饮食

> 猫粮、罐头、自制、喂法。带品牌、价位、配料怎么看，写文章时随手用。

---

## 一、猫是严格肉食动物

- 必须从动物性蛋白获取牛磺酸（自己合成不了），缺乏会致盲、心肌肥厚。
- 不能长期吃素。不能长期吃狗粮（狗粮里没有足量牛磺酸，且蛋白偏低）。
- 猫不爱喝水，天性靠食物补水分。只喂干粮的猫普遍喝水不够，是泌尿问题高发的原因之一。

---

## 二、干粮怎么看配料表

看配料表，从前往后含量递减。好粮的特征：

1. **前三位是肉**：明确写"鲜鸡肉 / 鸡肉粉 / 三文鱼"这种具体来源，而不是"肉类及制品"这种含糊词。
2. **粗蛋白 ≥ 32%**（成猫），幼猫 ≥ 34%。低于 28% 的别考虑。
3. **粗脂肪 10%-20%** 合理。
4. **无谷物 / 低谷物优先**：猫不需要碳水，玉米小麦大豆主要是凑低成本和成型。无谷粮碳水来自豌豆 / 鹰嘴豆 / 木薯。
5. **牛磺酸必须有**：配料表或添加剂里应列出。
6. **避免诱食料**：口味增强剂、宠物复合调味料这种，本质是诱食，让猫爱吃没营养的粮。
7. **避免人工防腐**：BHA / BHT / 乙氧基喹啉，看到这仨基本可以 pass。

## 三、常见猫粮品牌参考（价位梯度）

> 价格仅供参考，会波动。这是写作素材，不是购买建议。

### 顶级进口（40-60 元/斤）
- **渴望（Orijen）**：六种鱼、鸡肉。高蛋白高脂肪，蛋白 40%+，猫爱吃但部分猫会软便（蛋白太高）。
- **爱肯拿（Acana）**：渴望的"平价版"，蛋白略低，性价比更高。
- **纽翠斯（Nutrience）**：黑钻系列冻干粮，中高端口碑稳。

### 中端进口 / 国产高端（25-40 元/斤）
- **Go! Solutions**：九种肉口碑好，蛋白高，同样注意软便问题。
- **Now Fresh**：无谷系列，配方干净。
- **网易严选**：国产双 11 高蛋白款，性价比标杆。
- **诚实一口**：冻干双拼，蛋白实诚，配料表清晰。
- **高爷家 / 网易 / 卫仕 / 伯纳天纯**：国产新势力，性价比梯队。

### 中低端（15-25 元/斤）
- **皇家（Royal Canin）**：处方粮线最全，普通粮中规中矩偏贵。英短专用、绝育猫专用是细分款。
- **比瑞吉 / 伯纳天纯普通款**：配方一般，胜在稳定易买。

### 警示区
- 超市 / 五金店那种十几块一斤散装粮、"宠物调味"重口味的，基本是诱食料 + 劣质原料，长期吃肝肾要出事。
- 三无猫粮、淘宝 9.9 包邮的，别碰。

## 四、湿粮 / 罐头

### 主食罐 vs 零食罐
- **主食罐**：营养完整可替代干粮，配料表里通常有"完整营养"标识，蛋白 8%-12%（含水高）。
  - 常见：希尔斯科学计划、 ziwi 巅（巅峰）、K9、宏榴、迈格迷斯、卡比。
  - ziwi 巅（新西兰）300g 一罐 30-50 元，贵但质量硬。
- **零食罐**：补充水分 / 适口性用，营养不完整，不能当主食。泰源、伊纳宝那些一条条的就是零食罐。

### 喂法建议
- 干湿搭配最理想：早晚各一餐，一餐干粮一餐主食罐，水盆另备。
- 罐头开封后冷藏不超 48 小时，吃前回温。
- 不爱喝水的猫靠主食罐补水效果立竿见影。

## 五、喂食频率与量

| 阶段 | 频率 | 单次量（参考） |
|---|---|---|
| 幼猫（1-3 月） | 一天 4 顿 | 少食多餐，泡软幼猫粮 |
| 幼猫（3-6 月） | 一天 3 顿 | 干粮自由采食也行 |
| 成猫（6 月+） | 一天 2 顿 | 早 7 晚 7，一顿 30-40 克干粮 |
| 绝育后 | 一天 2 顿 | 减量 10-20%，绝育后代谢慢易胖 |
| 老年猫（10 岁+） | 一天 2-3 顿 | 易消化的老年粮，蛋白别降太多 |

- 胖瘦判断：摸肋骨，能轻松摸到是正常；摸不到 = 胖，骨头硌手 = 瘦。
- 7 公斤以上的英短 / 布偶 / 缅因不算胖，骨架大。

## 六、饮水

- **每天饮水量**：大约 40-60ml/kg。4 公斤猫一天 160-240ml。
- 只喂干粮的猫喝水不够是常态，泌尿结石、慢性肾病高发与此相关。
- **催喝水的招**：
  - 流动水：宠物饮水机（小米 / 雪貂 / 美的，50-200 元），很多猫就爱喝流动的。
  - 多个水点：家里放 2-3 个水碗，不同位置。
  - 玻璃 / 陶瓷碗比塑料好，塑料留味儿猫嫌弃。
  - 水里加一点冻干碎 / 一勺泡水罐头，骗水喝。
  - 水盆别放猫砂盆旁边。

---

## 七、换粮

- 换粮必须 7-10 天过渡，比例从 75% 旧粮慢慢到全新粮，避免肠胃不适应拉肚子。
- 突然换粮拉稀是常见翻车点。
- 换粮期可以拌点益生菌（布拉迪酵母、宠物益生菌）。

---

## 八、猫不能吃的东西（红线）

- **葱 / 蒜 / 洋葱 / 韭菜**：破坏红细胞，溶血，致命。
- **巧克力 / 可可**：可可碱中毒。
- **葡萄 / 葡萄干**：急性肾衰，少量都不行。
- **咖啡 / 茶 / 功能饮料**：咖啡因中毒。
- **酒精**：猫代谢不了，极少量就中毒。
- **木糖醇**：低血糖、肝损伤。
- **生鸡蛋清**：含抗生物素蛋白，影响生物素吸收。熟鸡蛋可以。
- **生鱼**：硫胺素酶破坏维生素 B1，长期吃会神经症状。
- **骨头（特别是煮熟的鸡骨）**：碎裂刺穿肠胃。
- **牛奶**：多数猫乳糖不耐受，拉肚子。要喝用宠物羊奶粉或无乳糖奶。
- **人的剩饭**：盐分油分都超，长期吃肝肾负担大。

---

## 九、营养品 / 补剂

- **牛磺酸**：好粮里够，不用单独补。
- **化毛膏 / 猫草**：长毛猫 / 掉毛季可喂。
- **鱼油**：Omega-3 对皮肤毛发好，掉毛季可加。别贪多，油大易软便。
- **益生菌**：换粮、软便、应激时短期用。
- **营养膏**：本质是糖 + 脂肪 + 维生素，当零食 / 应激期补能量，不是必需品。
- **钙 / 微量元素**：吃合格猫粮的健康猫不用补，乱补反而出事。
