# 品种专题 · 金毛寻回犬

> 写金毛相关文章时直接调用本文件。带体型、价位、易发问题、性格、饲养细节。

---

## 一、基本档案

- **价格**：宠物级 1500-5000，带血统 6000-1.5 万，赛级 2 万+。
- **体重**：公犬 29-34 公斤，母犬 25-29 公斤，超大型个体能到 40+。
- **肩高**：公 56-61cm，母 51-56cm。
- **寿命**：10-12 年，少数能到 14。
- **毛色**：奶白、浅金、金、深金、红金（偏红）。英系偏浅奶白，美系偏深金。
- **掉毛量**：★★★★★ 巨量，一年两次换毛"炸毛期"，平时也是行走的蒲公英。

---

## 二、性格画像

- **友善度拉满**：对人（含陌生人）、对狗、对猫都友好。看家？别指望，跟贼走都可能。
- **耐心**：对小孩容忍度极高，被揪耳朵、被骑都不太还嘴。家庭犬天花板。
- **聪明 + 服从**：智商第 4，服从性比边牧好训，工作犬出身（寻回猎物）。
- **热情 + 笨拙**：成年前是个不知轻重的大家伙，30 公斤扑上来能把人撞倒。
- **贪吃**：金毛的胃是个无底洞，"拉布拉猪"的称号也适用。极易胖。
- **口水**：嘴边常年挂哈喇子，尤其喝水后甩一脸。

---

## 三、必看的"易发问题"清单

买之前 / 养之前必须知道，这些是金毛医疗大头：

### 1. 髋关节发育不良（CHD）
- **概率**：遗传 + 环境共同作用，金毛高发。
- **症状**：后腿摇摆、"兔子跳"（后腿一起跳）、起立困难、不爱跳车 / 上楼。
- **预防**：买时问父母有没有 OFA 髋关节评分（优良以上）；幼犬期别剧烈运动、别补钙过量、别让胖。
- **管理**：控体重、补关节营养（葡萄糖胺 / 软骨素 / 鱼油）、止痛药（美洛昔康）、严重时手术。

### 2. 肘关节发育不良（ED）
- 同样遗传相关，前腿跛行。买时问父母肘关节评分。

### 3. 肿瘤 / 癌
- 金毛是"肿瘤大户"，老年金毛相当比例会得：肥大细胞瘤、淋巴瘤、血管肉瘤、骨肉瘤。
- 发现任何肿块别等，立刻穿刺 / 切除活检。
- 老年每半年体检 + 触诊全身淋巴结。

### 4. 皮肤病
- 长毛 + 厚底绒 + 垂耳 + 爱水 → 湿疹、热斑、马拉色菌、耳炎高发。
- 雨季 / 游泳后必须吹干底绒，否则半天就能长热斑。

### 5. 肥胖
- 贪吃 + 主人不舍得 → 普遍超重。
- 胖了关节、心脏、胰腺都受累。摸肋骨能轻松摸到才正常。

### 6. 甲状腺功能减退
- 老年发胖、怕冷、毛干、 lethargic，查 T4。

### 7. 心脏
- 主动脉瓣下狭窄（SAS）、扩张性心肌病（DCM）相对少见但存在。

## 四、运动与消耗

- **每天至少 1.5-2 小时**，分早晚。
- 不止跑步，还要"找东西"游戏（寻回本能满足）——丢球、藏零食让它找，脑力消耗大。
- 1 岁前**别剧烈跳跃和长跑**，骨骼未闭合，关节易伤。
- 不消耗 = 拆家（金毛拆家能力不输哈士奇，只是更"文雅"地咬）。
- 水猎犬出身，多数爱水，游泳是最佳低冲击运动。

---

## 五、喂养要点

- **大型犬幼犬粮**：别用普通幼犬粮，大型犬专用粮蛋白 / 钙适中，避免生长过快伤关节。
- **食量**：成年一天 250-400 克干粮（看活动量），分两顿。
- **别补钙**：正常吃合格粮的健康幼犬，补钙过量反而促 CHD。
- **控重**：绝育后减量 10-20%，定期称重。
- **关节营养**：6 岁起可加葡萄糖胺 / 软骨素 / 绿唇贻贝。

---

## 六、护理重点

- **梳毛**：每周 3 次，换毛季每天，针梳 + 底绒耙。
- **耳朵**：垂耳 + 厚毛，每周看一次，脏就清，有异味看医生。
- **洗澡**：3-4 周一次，必须吹透底绒。
- **美容**：金毛造型简单，自己剪脚底毛 + 耳朵周围就行，不用进店。

---

## 七、生命周期提醒

| 阶段 | 重点 |
|---|---|
| 0-3 月 | 在犬舍，断奶 + 第一针疫苗 |
| 2-4 月 | 接回家，疫苗未齐别出门，社会化靠家里来人 |
| 4-7 月 | 换牙期，给耐咬玩具，别剧烈运动 |
| 6-12 月 | "恶魔期"，精力旺盛 + 不知轻重，拆家高峰 |
| 1-2 岁 | 性格逐渐稳，但仍需大量运动 |
| 2-7 岁 | 壮年期，每年体检 |
| 7 岁+ | 老年，半年体检，关注关节 / 肿瘤 / 甲状腺 |
| 10 岁+ | 心脏、肿瘤筛查，关节止痛 |

- 30 公斤扑客人，客人差点没站稳
- 换毛季扫地机器人每天满盒
- 喝完水甩一脸口水
- 6 个月拆了三个沙发靠垫
- 老年查出肿瘤那天的心情
- 第一次发现它后腿兔子跳
- 控重失败，"我家金毛"变成"我家金毛猪"
