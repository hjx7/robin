# 品种专题 · 柯基犬

> 写柯基相关文章时直接调用本文件。短腿长身，腰是命门。

---

## 一、基本档案

- **价格**：宠物级 2000-5000，三色 / 蓝陨石 5000-1.5 万，赛级 1 万+。
- **体重**：公 10-14 公斤，母 10-13 公斤。看着小，其实沉，骨架粗。
- **肩高**：25-30cm，矮脚虎。
- **寿命**：12-15 年。
- **毛色**：黄白双色、三色（黑头 / 黑脸）、蓝陨石、红头。蓬头最贵。
- **掉毛**：★★★★★ 双层毛，一年两次"换毛大作战"，平时也是蒲公英成精。
- **断尾**：传统断尾（工作犬避免牛踩），现在很多地区不绝 / 保尾，自然短尾是基因。

---

## 二、性格画像

- **倔**：牧牛犬出身（咬牛脚踝赶牛），有想法，不听话不是不懂，是"我凭什么"。
- **爱叫**：牧牛要叫着指挥，吠叫欲强。城市公寓是重灾区。
- **会"牧人"**：小孩、家人、其他狗，跑起来它就想咬脚踝拦你。从小纠正。
- **聪明 + 调皮**：智商 11，但用聪明跟你对着干。开门、开柜、偷吃样样精通。
- **不认生**：对家人亲，对陌生人也亲，看家别指望。
- **死要面子**：挨骂能记仇，自尊心强。

---

## 三、必看的"易发问题"清单（腰是命门）

### 1. 椎间盘疾病（IVDD）—— 柯基的命门
- **原因**：长身短腿，脊椎承重大，椎间盘易突出 / 破裂压迫神经。
- **症状分级**：
  - 1-2 级：疼痛、不愿动、弓背、走路僵。
  - 3 级：后腿轻瘫，但还能走 / 有深痛觉。
  - 4 级：后腿瘫，无深痛觉。
  - 5 级：瘫 + 失禁，黄金抢救时间 < 24-48 小时。
- **预防**（重中之重）：
  - **别跳上跳下沙发 / 床**，用台阶 / 坡道。
  - **别爬楼梯**，尤其下楼。
  - **控体重**，胖了腰先遭殃。
  - **用胸背带别用项圈**，护颈护腰。
  - 玩扔球别让它猛急刹转身接。
- **发病处理**：1-2 级严格静养 + 医生用药；3 级以上尽快评估手术，越早手术预后越好。

### 2. 髋关节发育不良（CHD）
- 同样可能，柯基中大型基因遗传。

### 3. 肥胖
- 腿短 + 底盘低 + 贪吃 + 不爱长跑 → 超重普遍。胖了腰 / 膝盖全遭殃。

### 4. 退行性脊髓病（DM）
- 老年遗传病，后腿渐进性无力，无治愈。基因检测可查。

### 5. 眼：进行性视网膜萎缩（PRA）
- 遗传，逐步失明。基因检测筛查。

### 6. 皮肤病
- 双层毛 + 厚底绒，潮湿易湿疹、马拉色菌。

## 四、运动与消耗

- **每天 1-1.5 小时**，但**别剧烈跳跃**。
- 用嗅闻垫、漏食球、训练消耗脑力——柯基聪明，脑力比跑步累得快。
- 室内追激光点别太频繁，易强迫性追逐。
- 游泳是低冲击好运动，但柯基多数怕水，慢慢引。

---

## 五、喂养要点

- **食量**：成犬一天 150-220 克干粮，看活动量。
- **严格控重**：摸肋骨能轻松摸到。胖了立刻减，腰受不了。
- **关节营养**：成年后可加葡萄糖胺 / 软骨素。
- **避免高钙过量**。

---

## 六、护理重点

- **梳毛**：每周 2-3 次，换毛季每天。针梳 + 底绒耙（关键工具）。
- **洗澡**：3-4 周一次，必须吹透底绒，否则湿疹。
- **修剪脚底毛**：防滑防湿疹。
- **体重秤**：每周称，掉了 / 涨了都要警惕。

---

## 七、生命周期提醒

| 阶段 | 重点 |
|---|---|
| 0-3 月 | 在犬舍，疫苗第一针 |
| 2-4 月 | 接回家，社会化，**别让它上下沙发**从一开始就立规矩 |
| 4-7 月 | 换牙，给玩具 |
| 6-12 月 | 性格成型，训练倔脾气 |
| 1-2 岁 | 成年，运动量稳定 |
| 2-7 岁 | 每年体检 + 关注腰部 |
| 7 岁+ | 老年，半年体检，DM / 关节 / 脊柱 X 光 |
