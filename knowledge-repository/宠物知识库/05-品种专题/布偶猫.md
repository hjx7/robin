# 品种专题 · 布偶猫

> 写布偶相关文章时直接调用本文件。带体型、价位、易发问题、性格、饲养细节。

---

## 一、基本档案

- **价格**：宠物级 3000-8000，带血统 1 万-2 万，赛级 2 万-5 万。
- **体重**：公猫 6-9 公斤（绝育后能到 10），母猫 4-6 公斤。大体型，骨架粗壮。
- **寿命**：12-17 年，养得好能更长。
- **毛色**：重点色（脸 / 耳 / 四肢 / 尾深色，身体浅）。色系：海豹色、蓝色、巧克力色、淡紫色。可叠加手套 / 双色 / 高白手套。
- **眼睛**：蓝色，必须是蓝。非蓝眼是失格（可能不纯 / 有病）。
- **掉毛**：★★★★ 半长毛，掉毛量中等偏上，毛不打结是玄学。

---

## 二、性格画像

- **"小狗猫"**：跟人走、门口迎接、叫名字会来。布偶是少数像狗的猫。
- **脾气天花板**：怎么撸都不太还手，被抱起会"瘫成一张饼"——这也是名字 Ragdoll（破布娃娃）的由来。
- **痛觉迟钝**：这是品种特点，也是坑。受伤 / 生病不表现，主人难发现。要更勤观察。
- **粘人**：长时间没人陪会抑郁，不适合长期没人在家的家庭。
- **不护食、不主动攻击**：多猫家庭友好选手。
- **笨 / 笨萌**：没有田园猫那种机灵劲儿，跳不上高处是常态，摔下来也别太担心（相对）。

---

## 三、必看的"易发问题"清单

### 1. 肥厚型心肌病（HCM）
- **遗传病重灾区**。布偶有已知 HCM 突变（MYBPC3 基因，R820W 位点）。
- **买时必须问**：父母有没有 HCM 基因检测报告（阴性）。负责任猫舍会出示。
- **基因检测阴性 ≠ 不发病**（有其他突变可能），但概率低很多。
- **症状**：早期无症状，听诊有杂音 → 心超确诊。晚期：肺水肿（张嘴呼吸）、后腿血栓栓塞（突然瘫后腿）。
- **管理**：每年心超随访，心衰后用药（呋塞米、匹莫苯丹、氯吡格雷防血栓）。

### 2. 多囊肾（PKD）
- 同样遗传，肾里长囊肿，中年后影响肾功能。
- 基因检测可查，买时问父母。

### 3. 毛打结
- 半长毛 + 大体型，自己够不到后背、腋下、屁股周围。
- 每天梳一次至少，否则一周打结给你看。
- 严重打结贴皮只能剪掉，别硬拽。

### 4. 肠胃弱
- 布偶肠胃出名娇气，换粮更易软便。换粮 10 天过渡，少食多餐。

### 5. 肥胖
- 大体型 + 性格懒 + 不爱动，绝育后极易胖。胖了关节 / 心脏负担大。

### 6. 泌尿问题
- 不爱喝水是猫通病，布偶尤其要注意。鼓励湿粮 + 流动水。

## 四、喂养要点

- **高蛋白粮**：渴望六种鱼、爱肯拿、纽翠斯黑钻都行。注意软便就换低敏一点的。
- **湿粮 / 主食罐**：鼓励水分摄入，对预防泌尿 / 肾问题有用。ziwi、K9、卡比主食罐。
- **食量**：成猫一天 50-70 克干粮，分两顿。胖了减。
- **换粮 10 天**：比一般猫的 7 天更慢。
- **牛磺酸**：好粮里够，不用单独补。

---

## 五、护理重点

- **梳毛**：每天一次，排梳 + 针梳。重点腋下、耳后、屁股、大腿内侧。
- **洗澡**：2-3 个月一次，必须吹干，长毛潮湿易皮屑 / 真菌。
- **指甲**：3-4 周一次，前爪勤后爪懒。
- **耳朵**：每周看，垂耳 / 毛厚更要注意。
- **牙齿**：一周 2-3 次刷牙，布偶易牙结石。

---

## 六、生命周期提醒

| 阶段 | 重点 |
|---|---|
| 0-3 月 | 在猫舍，断奶 + 第一针疫苗 |
| 3-4 月 | 接回家，疫苗未齐别出门，慢换粮 |
| 4-8 月 | 换牙期，开始梳毛习惯 |
| 6-8 月 | 可绝育，母猫住院 2-3 天 |
| 1-3 岁 | 成年，骨架长成，HCM 首次心超 |
| 3-7 岁 | 每年体检 + 心超 |
| 7 岁+ | 老年，半年体检，关注心 / 肾 |

- 软便一周换了三种粮才稳定
- 第一次发现它后腿突然瘫了（血栓，急症！）
- 别人以为我家布偶胖，其实是骨架大
- 它跟着你上厕所，蹲门口等你出来
