# 其他细分 · 营养与处方粮专题

> 猫狗粮怎么看、处方粮什么时候用、自制 / 鲜食 / 生骨肉怎么选。写作时的"硬核"素材。

---

## 一、看配料表的底层逻辑

### 猫粮（严格肉食）
1. **前三位是肉**，且为具名（"鲜鸡肉 / 鸡肉粉 / 三文鱼"），不是"肉类及制品"。

   > **⚠️ 鲜肉 vs 肉粉反向营销："鲜肉第一" ≠ 肉多**
   > - **鲜肉（Fresh Chicken）含水 70%**：烘干成粮后水分剩 10%，实际干物质重量下降 60%+，写在第一位，烘干后可能排 6-7 位。
   > - **肉粉（Chicken Meal）蛋白密度 60%+，水分仅 10%**：同样写在第一位，提供的蛋白质可能是鲜肉的 2-3 倍。
   > - 真对比：看"鲜肉+肉粉组合"单点第一 + 保证分析的粗蛋白百分比。别被"鲜肉第一"四个字忽悠了。

2. **粗蛋白 ≥ 32%**（成猫），幼猫 ≥ 34%。低于 28% 别考虑。
3. **粗脂肪 10%-20%**。
4. **牛磺酸必有**（配料表 / 添加剂列出）。**精氨酸（Arginine）也必须有**——猫尿素循环 100% 依赖它，一顿不含精氨酸的饭，24 小时内就能高血氨→昏迷→死（比牛磺酸缺还急），自制低蛋白粮/纯素是最大坑。
5. **无谷 / 低谷优先**。猫不需要碳水。
6. **避免 BHA / BHT / 乙氧基喹啉**。
7. **避免诱食料**（"宠物复合调味料 / 风味剂"）。

### 狗粮（杂食偏肉）
1. 前三位有具名肉。
2. **粗蛋白 ≥ 22%**（成犬），幼犬 / 高活动 ≥ 28%。
3. 粗脂肪 10%-18%。
4. 碳水来源：低谷 / 优质碳水（糙米、燕麦、豌豆）优于玉米小麦。
5. 添加剂里有**葡萄糖胺 / 软骨素 / 牛磺酸**（中大型关节友好）更好。
6. 避免 BHA / BHT / 乙氧基喹啉。

## 二、常见粮 / 处方粮品牌速查

### 普通成幼粮
- **进口高端**：渴望、爱肯拿、纽翠斯黑钻、Go! Solutions。
- **国产高端 / 中端**：网易严选、诚实一口、比乐、伯纳天纯、高爷家。
- **中低端**：皇家、冠能、比瑞吉、顽皮。

### 处方粮（必须医生指导下用）

| 用途 | 品牌 / 系列 |
|---|---|
| 肾脏病（低磷优质蛋白） | 希尔斯 k/d、皇家 RSF、冠能 NF、法米娜 renal |
| 泌尿（溶鸟粪石 / 防草酸钙） | 皇家 urinary s/o、希尔斯 c/d、c/d 多护 |
| 胃肠 / 易消化 | 希尔斯 i/d、皇家 gastrointestinal、冠能 EN |
| 肝病 | 希尔斯 l/d、皇家 hepatic |
| 食物过敏 / 水解蛋白 | 皇家 anallergenic / hypoallergenic、希尔斯 z/d、冠能 HA |
| 减重 | 希尔斯 r/d、皇家 satiety、冠能 OM |
| 糖尿病 | 希尔斯 m/d、皇家 diabetic |
| 关节 | 希尔斯 j/d、皇家 mobility |
| 牙结石 | 希尔斯 t/d（大颗粒摩擦） |
| 心脏 | 希尔斯 h/d、皇家 cardiac |
| 泌尿 + 控体重 | 希尔斯 c/d 多护 + 体重管理 |
| 尿路应激 + 结石（猫） | 皇家 urinary calm |

## 三、什么时候要换处方粮

- **确诊疾病后，医生指导下换**。不是"我觉得它肠胃不好"就换 i/d。
- 处方粮是**治疗手段**，不是普通食品。健康动物长期吃会营养失衡。
- 用够疗程 / 病情稳定后，医生评估是否转维持粮或继续。
- 多猫 / 多狗家庭用 ID 芯片识别食盆，只让该动物吃。

## 四、自制 / 鲜食

### 优点
- 可控原料、新鲜、适口性高、湿粮补水。
- 对挑食 / 处方粮不吃 / 慢性肾病猫可作过渡。

### 风险
- **营养不均衡是常态**：钙磷比、牛磺酸、微量元素难调。
- 长期单一自制易缺钙、缺锌、缺牛磺酸（猫致命）。
- 生肉有寄生虫风险。

### 怎么做才靠谱
1. **参考兽医营养师配方**（Balance IT、Pet Dietician 这类工具按体重生成配方 + 维矿粉补充）。
2. **加营养粉**：钙粉、维矿预混料、牛磺酸粉 + **精氨酸粉（猫必备）**，别漏。
3. **多样化蛋白**：鸡、鱼、牛、兔轮换。
4. **⚠️ 猫长期单一自制鲜食风险最高的 3 个坑：**
   - 精氨酸不足 → 一顿就可能出大问题（高血氨）
   - 牛磺酸不足 → 几个月后致盲 / HCM
   - 钙磷比失衡 → 骨骼病、继发性甲旁亢
5. **定期体检**：长期自制的猫狗每 3-6 个月查血看指标。
6. **别照搬"鸡胸 + 米饭"土方**，营养单一。
7. **⚠️ 生熟粮 / 生骨肉和干粮不能混喂，间隔至少 4 小时。** 生肉需要胃酸 pH1-2 杀菌消化（消化周期 12-24h），熟食和干粮把胃酸稀释到 pH4-5 → 生肉里的细菌没被杀掉 → 急性肠胃炎拉血。自制鲜食和干粮同理。

## 五、生骨肉（BARF）

### 主张
- 贴近天性、毛亮、便少。
- 含生肉 + 生骨 + 内脏 + 蔬果 + 营养粉。

### 风险
- 寄生虫（生肉）。
- 营养失衡（钙磷比、微量元素）。
- 骨头刺穿（生骨相对安全，熟骨绝对不行）。
- 细菌污染（厨房 / 冰箱 / 人）。
- 不适合幼犬 / 免疫低下 / 老年动物。

### 决定喂就做足
- 定期驱虫（每月）。
- 定期体检（每 3-6 月）。
- 严格冷链。
- 用配方工具，别凭感觉。
- 大型犬幼犬期慎用（生长快 + 失衡 = 关节问题）。
- **生骨肉 / 生食 和干粮绝对不能混喂，间隔至少 4 小时。** 胃酸浓度差异大，混喂细菌活下来→肠胃炎。具体见上一条「自制鲜食」注意 7。

## 六、冻干 / 风干 / 主食罐 vs 干粮

| 类型 | 含水量 | 用途 |
|---|---|---|
| 干粮 | 6-10% | 主食方便、护牙（摩擦）、便宜 |
| 冻干生食 | 加水还原 | 接近生食、高蛋白、贵 |
| 风干粮（ziwi 巅） | 低 | 高肉含量、贵、可作主食 |
| 主食罐 | 75-80% | 营养完整、补水、贵、易牙结石 |
| 零食罐 | 高 | 补水 / 适口性，营养不完整 |

### 推荐组合
- **干 + 湿**：早干晚罐 / 反之，补水 + 护牙两不误。
- 猫强烈推荐配主食罐，泌尿 / 肾问题预防。
- 挑食 / 减重可用冻干拌干粮诱食。

## 七、喂量与频率

### 猫
| 阶段 | 频率 | 干粮量 |
|---|---|---|
| 幼猫 1-3 月 | 4 顿 | 泡软幼猫粮 |
| 幼猫 3-6 月 | 3 顿 | 自由采食也行 |
| 成猫 | 2 顿 | 30-50g / 顿 |
| 绝育后 | 2 顿 | 减 10-20% |
| 老年 | 2-3 顿 | 易消化 |

### 狗
| 阶段 | 频率 | 干粮量 |
|---|---|---|
| 幼犬 2-3 月 | 4 顿 | 泡软 |
| 幼犬 3-6 月 | 3 顿 | 按包装 |
| 幼犬 6-12 月 | 2 顿 | 大型犬可拉长 |
| 成犬 | 1-2 顿 | 150-400g 看体型活动 |
| 老年 | 2 顿 | 易消化 |

### 胖瘦判断
- 摸肋骨能轻松摸到 = 正常。
- 摸不到 = 胖，肋骨硌手 = 瘦。

## 八、换粮原则

- **7-10 天过渡**：旧 75% → 50% → 25% → 全新。
- 大型犬幼犬、敏感肠胃可拉长到 14 天。
- 换粮期加益生菌（布拉迪酵母、宠物益生菌）缓冲。
- 一款粮吃几个月状态好别折腾，吃得不好再换。频繁换反而易出问题。

## 九、营养品 / 补剂使用边界

| 补剂 | 何时用 |
|---|---|
| 牛磺酸 | 好粮够，不单独补 |
| 鱼油（Omega-3） | 皮肤毛、关节、掉毛季可加 |
| 葡萄糖胺 / 软骨素 | 中大型老年、关节问题 |
| 益生菌 | 换粮、软便、应激短期 |
| 化毛膏 / 猫草 / 化毛片 | 长毛猫 / 掉毛季。⚠️ 化毛膏≠化毛：主要成分是矿物油（润滑）+ 糖浆（调味），靠润滑粑粑把毛带出来，真化毛靠猫草/化毛片（高纤催吐/排出） |
| 营养膏 | 应激期 / 病后补能量，非必需 |
| 钙 | 仅医生诊断缺才补，乱补伤大型犬关节 |
| 微量元素 | 吃合格粮的健康动物不用补 |
