# 其他细分 · 幼犬 0-1 岁养成手册

> 接狗到一岁，每个月该做什么。新手按这个节奏走，少踩坑。

---

## 一、接狗前准备（0 月）

- **笼子 / 围栏**：从小习惯笼子（笼 = 安全窝），寄养 / 看病 / 出行都用得上。
- **食盆水盆**：陶瓷 / 不锈钢。
- **幼犬粮**：问原主人喂什么，照样买。大型犬用大型犬幼犬专用粮。
- **胸背带 + 牵引绳**：别用项圈（护气管）。
- **尿垫**：室内定点训练用。
- **玩具**：耐咬（Kong、尼龙骨）+ 漏食球 + 嗅闻垫。
- **航空箱**：训练 + 出门用。
- **医院 + 训犬师**：找好附近的医院，社会化课程预约。

---

## 二、0-3 月龄（在犬舍 / 原主人那）

- **吃奶 → 断奶**：4 周开始尝试泡软幼犬粮，8 周断奶。
- **第一针疫苗**：6-8 周龄犬联苗第一针。
- **驱虫**：2、4、8 周各一次。
- **社会化黄金期**（3-14 周）：接触人 / 狗 / 声音 / 环境，错过难补。

---

## 三、2-4 月龄（接回家第一个月）

### 接回家当天
- 体检：血常规、犬瘟细小抗原、粪检，约 200-400。
- 笼子 / 围栏安置好，放玩具。
- 别洗澡、别带出门、别接触其他狗，过了"安全期"再打后续疫苗。

### 这个月重点
1. **慢换粮**：7-10 天过渡。
2. **疫苗续针**：间隔 21 天打第二针。
3. **室内定点大小便训练**：饭后 / 睡醒 / 玩耍后立刻带去尿垫，成功猛夸 + 零食。3-4 月前别指望稳定。
4. **笼内训练**：从短时间开始，让它把笼子当窝，别把笼子当惩罚。
5. **基础口令**：名字、坐、等、来。一次 3-5 分钟，一天 2-3 次。
6. **社会化**：疫苗没齐别出门，但让家人朋友来家里接触它，接触不同声音（吸尘器、吹风机录音）。
7. **咬合力控制**：咬人手就"哎呦"+ 停游戏，让它学"咬疼 = 玩完"。

---

## 四、3-6 月龄

1. **疫苗第三针 + 狂犬**：16 周龄后打最后一针，1-2 周后产生抗体，可以出门。
2. **户外社会化**：出门接触不同环境、人、友好狗。这是关键期，错过难补。
3. **换牙期**（4-7 月）：牙痒爱咬，给耐咬玩具，别让它咬家具 / 鞋。
4. **基础口令进阶**：趴、松、放下。
5. **牵绳训练**：从家里 / 楼道开始，松绳走，别让它学会拉。
6. **继续定点训练**：逐步减少尿垫面积，过渡到户外。
7. **体重监测**：大型犬生长快，每周称。

---

## 五、6-12 月龄

1. **青春期 / "恶魔期"**：6-18 月精力旺盛 + 不知轻重，拆家高峰。坚持消耗 + 训练。
2. **绝育咨询**：小型犬 6-8 月，大型犬建议稍晚（10-18 月）让骨骼发育完全。母犬第一次发情前绝育降低乳腺瘤风险。
3. **过渡成犬粮**：小型犬 10-12 月换，大型犬 12-18 月换。
4. **进阶训练**：飞盘、敏捷、召回在不同环境练习。
5. **性格成型**：1-2 岁性格逐渐稳定。
6. **体检 + 疫苗加强**：1 岁基础体检 + 加强针。

---

## 六、第一年最常踩的坑

1. **疫苗没打全就出门 / 接触其他狗** → 犬瘟细小风险，幼犬致命。
2. **换粮没过渡** → 拉稀。
3. **洗澡太早太勤** → 皮肤问题。
4. **乱喂人食** → 洋葱、葡萄、巧克力致命。
5. **用手逗狗** → 长大学会咬人手。
6. **笼子当惩罚** → 它怕笼子，没笼内训练。
7. **追着狗跑** → 它觉得在玩，跑得更欢。
8. **叫"来"再做坏事**（剪指甲 / 洗澡）→ 学会"叫来 = 倒霉"，再也不来。
9. **事后算账** → 狗不懂为啥挨骂，只学会怕你。
10. **大型犬幼犬期剧烈跳跃 / 长跑** → 关节发育不良风险。
11. **补钙过量** → 大型犬反而伤关节。
12. **不绝育"体验一下"** → 母犬子宫蓄脓、乳腺瘤；公犬乱尿标记、走丢。

## 八、写文章可用的"梗"和场景

- 接回家第一天它在笼子里嚎了一夜，我心疼到失眠
- 第一次带它出门它腿软到不敢走
- 4 个月拆了三个沙发靠垫
- 学会"坐"用了一周，学会"开门"用了一天
- 换牙期满地牙印
- 半夜尿床，我裹被子睡沙发
- 6 个月 30 公斤扑我，差点摔倒
- 第一次发现它"管不住自己"的青春期
- 1 岁体检医生说"健康"，松了口气
