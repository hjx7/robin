# 其他细分 · 幼猫 0-1 岁养成手册

> 接猫到一岁，每个月该做什么。新手按这个节奏走，少踩坑。

---

## 一、接猫前的准备（0 月）

接猫当天就绪的东西：

- **航空箱**：硬壳，上面能开盖的最好。
- **猫砂盆 + 猫砂**：豆腐砂 / 膨润土都行，豆腐砂粉尘小不踩带，膨润土结团好。先问原主人用什么砂，照样备，别接当天换。
- **食盆水盆**：陶瓷 / 玻璃，别塑料（留味 + 黑下巴）。
- **幼猫粮**：先问原主人喂什么，照样买，别接当天换粮。
- **猫窝 / 纸箱**：纸箱永远是快乐老家。
- **抓板**：瓦楞纸或剑麻，从第一天就立规矩。
- **隔离小房间**：先单独一个小房间，别放全屋。
- **医院**：找好附近的医院，预约接猫当天体检。

---

## 二、0-3 月龄（在猫舍 / 原主人那）

- **吃奶 → 断奶**：4 周左右开始尝试泡软幼猫粮，8 周完全断奶。
- **第一针疫苗**：8 周龄打猫三联第一针。
- **驱虫**：2 周龄开始驱虫（体内），按体重用药。
- **社会化黄金期**：2-7 周接触人 / 声音 / 环境决定一辈子性格。负责任猫舍会做。

---

## 三、2-4 月龄（接回家第一个月）

### 接回家当天
- 体检：血常规、SAA、猫瘟抗原、粪检、基础体检，约 200-400。
- 单独小房间，放砂盆水粮窝。
- 别强抱、别洗澡、别带出门、别见其他宠物。
- 第一天可能不吃不喝不上厕所，正常，别慌。

### 这个月重点
1. **慢换粮**：7-10 天过渡，旧粮 75% → 50% → 25% → 全新粮。突然换必拉稀。
2. **疫苗续针**：间隔 21-28 天打第二针猫三联。
3. **驱虫**：体内外驱虫做一次。
4. **建立关系**：让它主动来你，别追它。拿零食诱导、坐地上陪它。
5. **立规矩**：抓板放好，开始让它习惯剪指甲（一周一次轻剪，养成习惯）。
6. **别出门**：疫苗未齐前不出门、不见陌生猫。

---

## 四、3-6 月龄

1. **疫苗第三针 + 狂犬**：完成核心疫苗，之后 1-2 周产生抗体，可以出门 / 见其他猫。
2. **社会化继续**：接触不同人 / 声音 / 物品，让它适应吸尘器、吹风机、提包。
3. **换牙期**（4-6 月）：开始换牙，可能咬东西，给玩具。
4. **绝育咨询**：6 月龄可以咨询绝育，母猫建议第一次发情前。
5. **梳毛习惯**：长毛猫每天，短毛每周 2-3 次，养成习惯。
6. **体重监测**：每周称，正常生长曲线稳步上升。
7. **刷牙习惯**：从现在开始让它接受刷牙嘴部触摸。

---

## 五、6-12 月龄

1. **绝育**：6-8 月龄做，疫苗齐全 + 体重达标。公猫当天出院，母猫住院 2-3 天。
2. **过渡成猫粮**：10-12 月龄开始过渡成猫粮，10 天过渡。
3. **性格成型**：1 岁前后性格基本定型，能看出粘人 / 独立 / 调皮 / 安静。
4. **运动量**：开始"成年"模式，逗猫棒每天 15-20 分钟消耗。
5. **体检**：1 岁做一次基础体检 + 疫苗加强针。

---

## 六、第一年最常踩的坑

1. **接猫当天换粮换砂** → 拉稀 + 应激。
2. **疫苗没打全就出门 / 见猫** → 猫瘟风险。
3. **洗澡太早** → 应激 + 感冒，6 月龄前别洗。
4. **喂牛奶** → 多数乳糖不耐受，拉稀。要喂用宠物羊奶粉。
5. **乱喂人食** → 洋葱、葡萄、巧克力致命。
6. **不剪指甲** → 抓坏家具 + 抓伤人，从小一周一次。
7. **不绝育"等它体验一下"** → 母猫子宫蓄脓、乳腺瘤风险升高；公猫乱尿标记。
8. **用塑料饭碗** → 黑下巴。
9. **砂盆放食盆旁** → 猫嫌弃。
10. **散养 / 阳台不封窗** → 高坠、跳楼。

## 八、写文章可用的"梗"和场景

- 接回家第一天它钻床底，我趴地上拿鸡肉哄了一晚
- 第一次剪指甲它抓花我手，三天没消
- 换粮没过渡，拉了一周我才学会
- 半夜三点跑酷踩我脸上
- 6 个月绝育戴圈那 10 天，它看我的眼神
- 第一次发情嚎叫，我以为它病了
- 1 岁体检医生说"健康"，松了口气
- 从巴掌大到抱不动，时间过得真快
