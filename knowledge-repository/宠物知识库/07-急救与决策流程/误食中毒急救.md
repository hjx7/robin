# 急救与决策流程 · 误食中毒

> 犬猫误食毒物是常见急症。前 1-2 小时是黄金时间，决策对错直接关系到能不能救回来。

---

## 一、决策总流程（先看这个）

发现 / 怀疑误食毒物后：

1. **确认是什么 + 多少 + 什么时候**：收集残余包装 / 残渣 / 呕吐物拍照，打电话给医院说明。
2. **评估状态**：清醒 / 抽搐 / 昏迷 / 呼吸是否正常。
3. **多数情况：立刻送医路上电话联系，让医院准备好。**
4. **是否催吐——看毒物种类！**（见下，别乱催）
5. **带残余物 / 包装 / 呕吐物一起到医院。**

---

## 二、绝对红线 / 何时不能催吐

**以下情况不要自己催吐，立刻送医：**

- 已经昏迷、抽搐、严重嗜睡（吸入窒息风险）。
- 误食**腐蚀性物质**（漂白水、洁厕灵、强酸强碱、电池液）：催吐会二次烧伤食道。
- 误食**石油类 / 烃类**（汽油、煤油）：吸入性肺炎风险极高。
- 误食**锐物 / 大量骨头**：可能划伤食道。
- 猫催吐比狗危险得多，多数情况**让医院处理**，别自己来。

---

## 三、常见毒物与处置

### 1. 巧克力 / 可可（犬最常见）
- **毒物**：可可碱 + 咖啡因。黑巧 / 烘焙巧克力 / 可可粉危险度高，牛奶巧克力次之。
- **中毒量参考（犬）**：黑巧 1g/kg 就要警惕，白巧基本没事（可可碱极低）。
- **症状时间**：6-12 小时内出现烦躁、多饮多尿、心跳快、心律不齐、震颤、抽搐。
- **处置**：2 小时内催吐（双氧水，医生指导下）→ 活性炭吸附 → 输液 + 苯二氮䓬控抽搐 + 心律药。
- **猫对可可碱更敏感**，少量也危险。

### 2. 葡萄 / 葡萄干（犬）
- **机制不明**，但可致急性肾衰。少量都有风险（报道中最低约 0.3g/kg）。
- **症状**：6-12 小时呕吐腹泻、24-72 小时少尿 / 无尿（肾衰）。
- **处置**：2 小时内催吐 → 输液利尿 48-72 小时监测肾指标。**哪怕没症状也要送医监测**，肾损伤滞后。

### 3. 木糖醇（犬）
- 无糖口香糖、糖果、某些花生酱。
- **机制**：刺激胰岛素大量释放，致**急性低血糖** + 部分肝损伤。
- **症状**：30 分钟-12 小时内虚弱、走路摇晃、抽搐、昏迷。
- **处置**：立刻送医，催吐（若清醒）+ 葡萄糖输注 + 监测肝功能。

### 4. 葱 / 蒜 / 洋葱 / 韭菜
- 含硫代硫酸盐，破坏红细胞 → 溶血。
- **症状**：1-5 天内虚弱、苍白、黄疸、血红蛋白尿（红色 / 酱油色尿）。
- **处置**：输血 + 输液 + 氧疗支持，无特效解毒。

### 5. 夏威夷果（犬）
- 机制不明，多数轻微。
- **症状**：12 小时内后腿无力、震颤、发烧、呕吐。
- **处置**：支持性，多数 24-48 小时自愈。

### 6. 老鼠药（犬猫）
- **抗凝血型（溴敌隆等）**：1-7 天后内出血、皮下出血、流鼻血、便血。解毒：**维生素 K1**，越早越好。
- **神经毒型（溴鼠灵等）**：1-3 天抽搐、瘫痪。无特效解毒，支持治疗。
- **处置**：2 小时内催吐 + 活性炭 + 维生素 K1（抗凝型）连续 30 天 + 监测凝血。

### 7. 百合花（猫）—— 致命
- **猫专属致命毒物**。所有部分有毒，**花瓣、花粉、花茎、泡过花的水**都算。猫踩了花粉沾到爪子上舔一下就可能中毒。
- **症状**：6-12 小时呕吐、嗜睡、24-72 小时急性肾衰。
- **处置**：2 小时内催吐 + 活性炭 + 大量输液利尿 48-72 小时，监测肾指标。**晚 6 小时预后差**。
- **⚠️ 百合科扩大版图（90% 主人只知百合）：** 下面这些全是百合科 / 同属百合目，都对猫有致命或高毒性：

| 植物 | 毒性部位 | 毒性程度 | 症状特点 |
|---|---|---|---|
| **百合 / 香水百合（Lilium）** | 全株，花粉最毒 | 极毒，舔花粉致死 | 急性肾衰（最典型） |
| **郁金香（Tulipa）** | **鳞茎毒性最强**，花和叶也有毒 | 中高毒 | 剧烈呕吐、腹泻、流口水、抽搐、心律不齐 |
| **风信子（Hyacinthus）** | 球根毒性最强 | 高毒 | 剧烈呕吐、腹泻、腹痛、震颤、严重时肾损 |
| **铃兰（Convallaria）** | **全株剧毒**（含强心苷） | 极毒 | 呕吐、心律骤变（过缓/过速/不齐）、抽搐、猝死 |
| **芦荟（Aloe vera）** | 芦荟汁液（**大黄素皂苷部分**） | 中毒 | 呕吐、腹泻（红色血便）、震颤、厌食 |
| **萱草 / 黄花菜（Hemerocallis）** | 全株 | 极毒（和百合同级） | 急性肾衰、呕吐、嗜睡、少尿 |

- 重点提醒：郁金香/风信子花卉市场春节前后大量卖（年宵花），买回家别放猫能到的地方。铃兰是婚礼花材常见，别让猫碰。芦荟很多人家里种了美容的，叶子掰破流出来的黄色汁液是毒的，透明凝胶部分毒性低但也别让猫啃。
- **预防**：有猫的家别养百合科植物，别收这类花束。朋友送花先查品种。

### 8. 扑热息痛 / 对乙酰氨基酚（猫致命，犬也有害）
- 人用感冒药常见成分。**猫极敏感**，一颗就能致命。
- **症状**：发绀（舌头发紫）、呼吸急促、面部水肿、肝损伤、溶血。
- **解毒**：N-乙酰半胱氨酸（NAC）输注，越早越好。

### 9. 布洛芬 / 萘普生等 NSAIDs
- 人用止痛药，犬猫都危险。
- **症状**：胃肠溃疡、肾损伤、神经症状。
- **处置**：催吐 + 活性炭 + 输液护胃护肾。

### 10. 重金属 / 锌（硬币、电池）
- 一元硬币含锌，吞下去会锌中毒 + 肠梗阻双重风险。
- **处置**：内窥镜 / 手术取出。

---

## 四、催吐方法（仅医生指导下，犬为主）

- **3% 双氧水**：犬 1-2ml/kg（最多 50ml / 次），口腔注入，10-15 分钟无吐再重复一次。
- **盐水 / 盐 / 芥末 / 油 / 牛奶**：**不要用**，无效或更危险。
- **催吐后**：立刻送医，给活性炭 + 输液。

---

## 五、医院后续处理

1. **催吐**（医院做）。
2. **洗胃**（深度昏迷或大量吞食，全麻下）。
3. **活性炭**：吸附肠道残余毒物，按毒物种类重复给药。
4. **解毒剂**：维生素 K1、NAC、阿托品（有机磷中毒）、纳洛酮（阿片）等。
5. **输液利尿**：加速排泄。
6. **支持治疗**：止吐、抗抽搐、抗心律、输血、氧疗、护肝护肾。
7. **监测**：肝肾功能、凝血、心电图，按毒物种类定。

---

## 六、预防（写文章可用清单）

- 巧克力、葡萄、口香糖、感冒药收好，别放桌面。
- 百合不进有猫的家。
- 老鼠药、杀虫剂、清洁剂锁柜里。
- 垃圾桶带盖，狗翻垃圾桶是误食大户。
- 散步别让它捡食，"leave it"口令救命。
- 紧急电话存好。

---

## 七、写文章可用的"梗"和场景

- 半夜发现一地巧克力包装纸，狗眼神心虚
- 催吐双氧水，第一次手抖到不行
- 葡萄干吃完没事，第二天医生说"还得监测 48 小时"
- 百合花束被猫啃了，2 小时内冲急诊
- 翻垃圾桶吃了带油的纸巾，凌晨吐了一地
- "leave it"那句话救了它命
- 急诊费 3000，比家里锁柜贵多了
