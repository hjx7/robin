# 急救与决策流程 · 夜间急症决策

> 半夜被猫狗的异常状况惊醒，慌得不行。这份是"等天亮 vs 立刻送急诊"的判断清单。

---

## 一、总原则

**三个灵魂问题，任何一个回答"是"，立刻送急诊：**

1. **它是不是快死了 / 可能几小时内恶化到死？**
2. **它是不是没法呼吸 / 严重呼吸困难？**
3. **它是不是出了某种"无法自己止住"的事（出血、梗阻、中毒）？**

都"不是"，可以先观察 + 联系白天医生预约。
**拿不准**：宁可白跑，也别赌。

---

## 二、立刻送急诊（红灯信号）

出现下面任何一条，别等天亮：

### 呼吸
- 张嘴呼吸（猫几乎不张嘴呼吸，张嘴 = 重症）、舌头发紫 / 发白。
- 持续急促喘息、腹部用力呼吸。
- 窒息、卡住东西呛到出不来气。

### 心脏 / 循环
- 突然瘫后腿（后腿冰凉、黏膜白）→ 血栓 / 失血，分秒必争。
- 持续抽搐 / 抽完未清醒。
- 黏膜（牙龈、内眼睑）苍白 / 紫绀。

### 胃肠
- 持续呕吐不止 / 呕吐物带血 / 带粪臭味 → 怀疑肠梗阻。
- 腹部急剧胀大 + 干呕无物 + 流口水（深胸犬）→ 胃扩张扭转（GDV），1-2 小时致命。

### 泌尿
- 公猫 / 公狗 24 小时尿不出 → 梗阻，48 小时内致命。

### 神经
- 抽搐不止 / 反复抽搐。
- 突然瘫、意识丧失、瞳孔不等大。

### 出血
- 大量出血止不住（撕裂伤、内出血迹象：腹肿 + 黏膜白）。

### 误食
- 误食有毒物（巧克力、葡萄、百合、老鼠药、木糖醇、扑热息痛、感冒药）2 小时内。

### 创伤
- 高坠（窗台掉下）、车祸、被狗咬贯穿、被门夹伤——即使表面没事也要查内脏 / 骨折。
- 烫伤 / 电击。

### 体温
- 体温 < 37 度或 > 41 度。
- 中暑（高温 + 喘 + 舌紫）。

### 生殖
- 未绝育母犬腹胀 + 多饮 + 阴道分泌物 → 子宫蓄脓。
- 难产（持续宫缩 30 分钟以上无产出）。

## 三、可以先观察（黄灯信号）

下面这些可以观察几小时到天亮，但**恶化立刻送**：

### 呕吐
- 吐一次（毛球 / 食物），吐完精神好、吃喝照常。
- 偶尔吐黄水（空腹），精神好。
- 处理：禁食 4-6 小时，少量水，恢复后少量多餐。

### 腹泻
- 一两次软便 / 稀便，精神好、不吐、不脱水。
- 处理：禁食 12 小时（幼犬不禁食，会低血糖）、少量水、益生菌、恢复后清淡饮食（鸡胸 + 米饭）。
- 出现带血、腥臭、精神差、呕吐 → 送。

### 不食
- 跳一两顿饭但精神好、喝水正常、其他无症状。
- 24 小时不进食（猫）或 12-24 小时（小型犬、幼犬）→ 送。

### 轻度咳嗽
- 偶尔干咳、精神好、不发热，可能犬窝咳早期，预约白天医生。
- 出现脓痰、呼吸困难 → 送。

### 跛行
- 轻度跛行、能踩地、不剧烈疼痛，限制活动，天亮看医生。
- 完全不踩地、剧痛、外伤、瘫痪 → 送。

### 皮肤问题
- 任何皮肤瘙痒、脱毛、红疹都不是急症，预约白天。

## 四、家里的应急准备清单

放在固定位置，半夜摸黑也能拿到：

- **急诊医院电话 + 地址**：存手机 + 贴冰箱。24 小时急诊医院很多城市有。
- **运输箱 / 笼**：猫必须装航空箱，狗用笼 / 安全带。
- **体温计**（肛温）。
- **止血粉 / 洗必泰 / 碘伏 / 生理盐水**。
- **伊丽莎白圈**。
- **益生菌 + 口服补液盐**。
- **3% 双氧水**（仅医生电话指导下催吐用，狗为主）。
- **活性炭**（医院会给，家里一般不必备）。
- **毯子 / 担架**：搬运伤患。

---

## 五、送医路上做什么

- **保持冷静**：你慌，宠物更慌。
- **运输箱里垫毯子**：保温 + 防滑。
- **记录症状**：什么时候开始、频率、吐 / 拉了什么、拍照。
- **别喂食水**：急症可能要麻醉 / 手术，空腹安全。
- **开车找人陪**：一人开车，一人看护。
- **电话联系医院**：让医院准备，到院直接处理。

## 六、决策流程图（半夜惊醒时按这个走）

```
半夜被异常惊醒
    ↓
检查：呼吸是否急促 / 张嘴呼吸（猫）/ 舌头颜色？
    ├─ 异常 → 立刻送急诊
    └─ 正常 → 继续
    ↓
检查：是否抽搐 / 瘫痪 / 意识异常？
    ├─ 是 → 立刻送急诊
    └─ 否 → 继续
    ↓
检查：是否持续呕吐 / 大量出血 / 腹胀 / 尿不出？
    ├─ 是 → 立刻送急诊
    └─ 否 → 继续
    ↓
检查：精神是否严重萎靡 / 完全不食 / 体温异常？
    ├─ 是 → 立刻送急诊
    └─ 否 → 观察到天亮 + 白天约医生
```

## 七、写文章可用的"梗"和场景

- 半夜被声音惊醒，第一眼摸黑找手机开灯
- 急诊医院导航跑了 20 分钟才到
- 急诊费比平时贵 1.5-2 倍，肉疼但庆幸
- 等天亮 vs 立刻送的纠结，每分钟都是煎熬
- 看医生淡定的样子，悬着的心放下一半
- "原来不是大事"的那次白跑，也值
- 备好急诊包之后，半夜不再那么慌
- 学会看牙龈颜色 / 量肛温，比啥都安心
