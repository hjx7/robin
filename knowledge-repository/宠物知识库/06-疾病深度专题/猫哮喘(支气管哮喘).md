# 疾病深度专题 · 猫哮喘（猫支气管哮喘）

> 很多主人把猫哮喘当"吐毛球没吐出来"，拖半年以上才确诊。其实一个很简单的区别：哮喘是咔咔咳，吐毛球是呕。

---

## 一、这是什么病

**猫支气管哮喘（Feline Bronchial Asthma），也叫猫下呼吸道慢性炎症性疾病。** 和人的哮喘机制类似：过敏原/刺激物 → 气道发炎 → 支气管平滑肌收缩 → 气流受限 → 咳、喘。

猫哮喘是**慢性病**，无法根治但可长期控制。中年猫高发，2-8 岁最常见。暹罗、喜马拉雅等品种似乎略多，但任何品种都可得。

---

## 二、90% 的主人搞混：哮喘咳 vs 吐毛球呕

这是延误诊断最常见的原因。一张表区分：

| 动作 | 猫哮喘（咳） | 吐毛球（呕） |
|---|---|---|
| **姿势** | 脖子往前下方伸、弓背、腹部一下一下抽（"咳"从气管出） | 腹部先有明显的胃部收缩动作（先呕后吐），头低下往前探 |
| **声音** | 咔咔咔、卡卡卡，干咳为主。严重时有"嗬嗬"的喘鸣音 | 干呕声，之后吐出来毛团/黄水/食物 |
| **有没有东西吐出来** | 90% 什么都吐不出来，就是干卡。偶尔咳一点白色泡沫 | 最后会吐出东西：毛球、黄水、未消化粮 |
| **频率** | 连续一串 3-5 下，一天发作多次，季节变化/闻刺激味后加重 | 一周 1-2 次，长毛猫换毛季多 |
| **伴随症状** | 打喷嚏、流鼻涕、偶尔呼吸加快 | 吐完就没事，精神食欲基本正常 |
| **最典型场景** | 闻到香薰/空气清新剂/尘螨/粉尘后立刻咔咔咳 | 吃完粮 1-2 小时后呕，吐出毛和食物混合物 |

你录个视频给医生看，**基本就能区分**。别再拖了。

---

## 三、常见的诱发过敏原

| 类型 | 具体例子 |
|---|---|
| **空气传播（最常见）** | 屋尘螨、粉尘、香烟/电子烟烟雾、香薰蜡烛、精油、空气清新剂、香水、喷雾剂（发胶/除味剂）、猫砂粉尘（膨润土粉尘重的那种）、装修油漆 |
| **季节性** | 花粉、霉菌孢子 |
| **环境** | 新换地毯/新沙发（布面含甲醛和化工残留）、羽绒被/羽毛枕头 |
| **感染** | 支原体、支气管败血波氏杆菌、猫疱疹病毒/杯状病毒继发 |
| **肥胖** | 胖猫腹压大，加重气道压迫，哮喘更难控 |
| **应激** | 搬家/换环境后急性发作 |

---

## 四、分级（从轻到重）

| 分级 | 表现 | 大概比例 |
|---|---|---|
| **轻度** | 偶尔咔咔咳，一天几次，不影响吃喝活动。听诊偶有喘鸣。 | 60% 左右 |
| **中度** | 每天发作，咳嗽串长，运动后加重。呼吸频率略快，听诊有啰音。 | 30% |
| **重度（急性危象）** | 张嘴呼吸、舌发紫/发白、腹式呼吸、缺氧虚脱。急诊。 | 10% 但致命。 |

---

## 五、怎么诊断

- **胸片（DR）：** 最常用。典型表现：支气管纹理增粗、"甜甜圈征"（支气管横断面壁增厚）、右下肺叶浸润。约 20% 轻度哮喘胸片正常，要结合临床。
- **气道采样（气管冲洗 / BAL）：** 金标准。麻醉下灌洗液查嗜酸性粒细胞、排除感染。怀疑重症/不典型时做。
- **心超 / NT-proBNP：** 排除心脏病（心脏引起的咳嗽 vs 哮喘，治疗完全不同）。
- **FCV/FHV 核酸 / 支原体培养：** 疑似感染诱因时做。

---

## 六、长期控制方案（重点是"控"不是"治"）

### 1. 环境控制（最基础，必须做，不做药白吃）

- **去粉尘：** 猫砂换低粉尘的（豆腐砂/沸石砂/纸砂），换砂时戴口罩+猫放另一个房间。
- **去气味刺激：** 香薰、精油、香水、空气清新剂、喷雾除臭剂全部停用。家里戒烟。
- **除螨：** 床单枕套一周一洗（60度水），羽绒被换纯棉，沙发用除螨仪。
- **控重：** 胖猫减肥 10%，哮喘会明显缓解，用药量也能降。
- **空气净化器：** 选 HEPA 滤网的，放猫常待房间，24 小时开。春秋花粉季更要。
- **加湿器：** 冬天太干时用，湿度 40-50% 能缓解气道刺激。

### 2. 药物（医生指导下用）

| 类型 | 常用药 | 说明 |
|---|---|---|
| **糖皮质激素** | **泼尼松龙（口服）**、曲安奈德（长效注射） | 抗炎首选。轻中度口服，重度注射。注意长期用糖尿病/感染风险。 |
| **吸入型激素** | 氟替卡松（Flixotide）+ 猫专用面罩 AeroKat | 副作用最小，长期控制的金标准。猫要训练接面罩。 |
| **支气管扩张剂** | 特布他林、沙丁胺醇（万托林急救用） | 急性发作时救急 + 长期和激素联用 |
| **抗组胺 / 白三烯抑制剂** | 氯雷他定、孟鲁司特 | 人用的，猫可用，部分猫有效，医生指导 |
| **环孢素** | 环孢素口服液 | 顽固性病例，替代长期激素 |
| **抗生素** | 多西环素、阿奇霉素 | 支原体/细菌感染时按疗程，不随便用 |
| **L-赖氨酸** | 赖氨酸粉/凝胶 | 疱疹病毒诱发时可作为辅助 |

### 3. 急性危象（急诊）

看到下面任意一条 = 立刻急诊：
- 张嘴呼吸（不闭合）
- 舌色发紫 / 发白
- 腹式呼吸，肚子一下一下大幅度动
- 精神极度萎靡，蹲角落里不动
- 呼吸频率 > 60 次/分（静息状态下）

急诊处理：吸氧、雾化（支气管扩张剂+激素）、静脉激素、镇静。**别自己开车晃着去，打个稳点的车，或联系医院接。**

---

## 七、预后

- 轻度：环境控制 + 吸入激素，**控制好跟正常猫没区别**，寿命不受影响。
- 中度：可能终身需要低剂量激素维持，定期复查胸片。
- 重度急性危象：一次处理不好就没了。反复发作的，气道会不可逆重塑（越犯越重）。

**关键：越早诊断越早控，气道重塑越少，预后越好。** 别再当吐毛球拖半年。

---

## 八、主人最容易踩的 4 个坑

| 坑 | 后果 |
|---|---|
| **1. 当吐毛球，买一堆化毛膏吃三个月** | 化毛膏对哮喘啥用没有，反而里面糖浆和添加剂可能加重刺激 |
| **2. 咳嗽就给吃多西环素（以为感冒）** | 哮喘绝大多数不是细菌感染，抗生素滥用反而耐药 + 肠道菌群乱 |
| **3. 吃上药不咳嗽了就自行停药** | 气道炎症没完全消，停药 1-2 个月必复发，而且越来越重 |
| **4. 继续用膨润土粉尘砂 + 家里香薰开空调内循环** | 药吃着，过敏原天天吸，越治越重 |

## 九、写文章可用的梗和场景

- 我以为它在吐毛球，咔咔卡了三个月，什么化毛膏猫草种了三遍都没用。医生看完视频说这不是吐，是咳。我：啊？
- 买了一箱香薰，插上当晚它就蹲地上咔咔卡了一分多钟。我还以为它卡了毛球。那箱香薰现在搁厕所当除臭剂用（厕所关门不让它进）。
- 换了豆腐砂 + 开了 HEPA 净化器，一周后它发作次数从一天六次变一天一次，我都想哭。
- 给它接面罩吸激素，它以为是新玩具，跟面罩打了十分钟。
- 有次急性发作，张嘴呼吸，去医院路上我手都在抖，医生说再晚半小时就要插管了。
