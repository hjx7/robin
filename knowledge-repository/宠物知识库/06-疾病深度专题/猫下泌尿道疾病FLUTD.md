# 疾病深度专题 · 猫下泌尿道疾病（FLUTD）

> 公猫尤其要注意，尿道梗阻 48 小时内可致命。这是猫最常见的急诊之一。

---

## 一、什么是 FLUTD

- 不是单一病，是一组影响膀胱 / 尿道的疾病的统称。
- 包括：**自发性膀胱炎（FIC，占 60-70%）**、尿路结石、尿道栓塞、尿道梗阻、肿瘤等。
- 公猫尿道细长 → **梗阻风险高，急症**。

---

## 二、典型症状

猫上厕所 / 在砂盆里反复蹲着：

1. **反复进出砂盆**，蹲很久尿少 / 无尿。
2. **尿带血**（红色 / 粉色尿团）。
3. **尿砂盆里嚎叫**（疼痛）。
4. **乱尿**（在床上、地毯、沙发上）。
5. **频繁舔下面**。
6. **梗阻信号（急症）**：腹部胀硬、反复使劲无尿、呕吐、虚弱、躲藏、低体温。
   - **公猫 24 小时尿不出 = 致命性急症，立刻急诊。**

---

## 三、主要病因

### 1. 自发性膀胱炎（FIC）—— 最常见
- 找不到明确感染源，但膀胱发炎。
- **与应激高度相关**：搬家、新猫、新人、装修、换粮换砂、医院、节日噪音，都易诱发。
- 体征明显（血尿、痛），但尿检无细菌，培养阴性。
- 复发率高，靠长期管理。

### 2. 尿路结石
- **鸟粪石（磷酸铵镁）**：最常见，与饮食 / 尿 pH 有关。
- **草酸钙**：老年猫、酸性尿易形成，比鸟粪石更难溶（常需手术）。
- 结石可堵塞尿道，尤其是公猫。

### 3. 尿道栓塞
- 公猫高发，栓子由矿物质 + 蛋白 + 炎性物质组成，堵住尿道。

### 4. 尿道梗阻
- 上述任何原因都可能导致，公猫最危险。
- 一旦梗阻 → 尿排不出 → 膀胱胀 → 肾损伤 → 急性肾衰 → 高钾血症 → 心脏骤停，24-48 小时内致命。

---

## 四、诊断

- **触诊**：膀胱胀硬 = 怀疑梗阻。
- **B 超**：看膀胱壁、结石、结晶、肿瘤。
- **尿检**：pH、比重、红细胞、白细胞、结晶（鸟粪石结晶 / 草酸钙结晶）。
- **尿培养 + 药敏**：排除细菌感染（猫下尿路感染率低，老年 + CKD 猫较高）。
- **X 光 / 造影**：看结石大小位置。

---

## 五、治疗

### 梗阻（急诊）
1. **导尿**：留置导尿管 24-48 小时冲洗膀胱，解除梗阻。
2. **输液**：纠正脱水、电解质、高钾。
3. **住院 2-5 天**，监测尿量、肾指标（BUN / CREA）。
4. **复发梗阻**：可能需会阴尿道造口术（PU 术），把尿道口改宽，是较大手术。

### FIC（自发性膀胱炎）
- 止痛：非甾体抗炎药（美洛昔康）、加巴喷丁（止痛 + 抗焦虑）、阿米替林。
- 解痉：哌唑嗪（放松尿道平滑肌）。
- 7-10 天多缓解，重点在**长期管理防复发**。

### 结石
- 鸟粪石：处方溶解粮（希尔斯 c/d 多护、皇家 urinary s/o）+ 增加饮水，6-8 周可溶。
- 草酸钙：无法溶，手术取出。
- 长期管理用处方粮防复发。

---

## 六、长期管理（防复发是核心）

### 1. 增加水分摄入（最重要）
- **湿粮 / 主食罐**：补水效果立竿见影，FIC 猫强烈推荐。
- 流动水：饮水机（小米、雪貂、美的）。
- 多水点：2-3 个不同位置水碗。
- 陶瓷 / 玻璃碗，远离食盆和砂盆。
- 水里加冻干碎、少量泡水罐头骗水。

### 2. 处方粮
- 皇家 urinary s/o、希尔斯 c/d、c/d 多护、法米娜 urinary。
- 溶解鸟粪石 + 调节 pH + 防复发。
- 多猫家庭用 ID 芯片识别食盆，只让该猫吃。

### 3. 降应激（FIC 核心）
- 多猫家庭减少资源争夺（砂盆 N+1）。
- 环境稳定，少大变。
- 费利威（Feliway）信息素扩散器，部分猫有用。
- 给躲藏处 + 高处。

### 4. 控重
- 胖猫 FIC / 梗阻风险高。

---

## 七、什么情况立刻急诊

公猫出现下面任意一条 → 半夜也送：

- 24 小时无尿（或反复使劲无尿）。
- 腹部胀硬、按肚子疼叫。
- 呕吐 + 虚弱 + 躲藏 + 不食。
- 已经确诊 FIC / 结石的猫，状态突变。

---

## 八、写文章可用的"梗"和场景

- 半夜听见它反复进出砂盆，去看蹲了半天没尿
- 公猫梗阻急诊，导尿住院那 3 天
- 第一次见血尿团吓得手机都拿不稳
- 换饮水机当天它喝半盆水
- 主食罐头骗水喝，它舔得碗底干净
- 复发第三次开始反省是不是我家太乱
- 医生说"再晚 6 小时就没了"
- 换了处方粮 + 湿粮组合，半年没复发
