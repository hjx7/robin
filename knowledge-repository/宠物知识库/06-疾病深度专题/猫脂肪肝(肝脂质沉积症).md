# 疾病深度专题 · 猫脂肪肝（肝脂质沉积症）

> 猫的脂肪肝，跟人脂肪肝方向刚好反。人是吃出来的，猫是饿出来的。越胖的猫饿得越快。这是宠物医院急诊"主人好心办坏事"第一名。

---

## 一、这是什么病

**猫肝脂质沉积症（Hepatic Lipidosis），俗称猫脂肪肝。** 核心机制：长期/短期严重饥饿 → 脂肪大规模动员 → 涌入肝脏 → 肝脏处理能力不足 → 甘油三酯堆积在肝细胞内 → 肝细胞被泡死、淤胆 → 黄疸 → 肝衰竭。

**与人类脂肪肝最关键的区别：**
- 人类脂肪肝：进太多（吃油、喝酒、久坐）→ 节食饥饿是治疗手段
- 猫脂肪肝：出太多（饿，脂肪被迫出仓）→ 节食饥饿是发病诱因

**越胖的猫越危险。** 14 斤以上的胖猫，断食 3-5 天就能出现临床黄疸；断食 7 天以上肝细胞开始不可逆坏死。

---

## 二、最常见的 5 个诱因

不是只有"主人故意饿减肥"才会得，医院里最常见的 5 种：

| 诱因类型 | 典型场景 | 说明 |
|---|---|---|
| 1. **其他疾病引发拒食** | 口炎牙疼、尿闭痛、胰腺炎吐、发烧拉稀 | 原发病还没咋的，脂肪肝先来了，最后比原发病还致命 |
| 2. **应激性拒食** | 搬家、新猫进家、主人出差、装修、节日鞭炮 | 胆子小、独立性强的猫几天不吃。案例：主人出差 3 天，布偶回来直接黄 |
| 3. **挑食换粮拒食** | 旧粮直接停，新粮它嫌难吃，硬扛 | 医生叫这个 "宁死不屈型脂肪肝" |
| 4. **主人故意饿减肥** | 网上"饿几天就瘦了"+"管住嘴迈开腿" | 最让医生生气的一种 |
| 5. **自动喂食器卡粮** | 节假日出门，卡粮 2 天没人发现 | 医院 3 个以上同类案例 |

---

## 三、发病时间节奏（每个阶段都有窗口）

胖猫、中等体型猫参考：

- **< 24 小时：** 只是食欲下降/一点没吃。主人这时反应 90% 是"挑食，饿两顿就好"。**错。** 食欲下降本身就是警铃。
- **24-72 小时：** 精神变差、不爱动、大便次数明显减少、尿少。
- **72 小时 - 5 天：** 黄疸出现。眼白（巩膜）黄 → 耳内侧薄皮黄 → 牙龈黄 → 肚皮无毛处黄。尿是浓橙汁色，大便浅黄/灰白色。**中重度脂肪肝。**
- **> 5-7 天：** 流口水、走路打晃、空嚼、呕吐、抽搐。血氨升高 → 肝性脑病。死亡率 50%+。

---

## 四、为什么会得（原理用人话讲）

猫的祖先来自沙漠，进化出的代谢模式是"**我随时可能几天没饭吃，多余能量全存脂肪**"。它的身体默认：

1. **糖原储备少。** 人饿了先烧糖原，能烧一整天甚至更久；猫饿一天糖原就没了。
2. **糖原没了立刻烧脂肪。** 所以猫能扛饿，这是沙漠里出来的本事。
3. **但猫肝处理脂肪特别差。** 大量脂肪（脂肪酸）一下子涌进肝，肝来不及代谢，就把多余的甘油三酯直接堆在肝细胞里。肝细胞被油泡着，没法工作 → 肝酶升高 → 胆红素排不出去（黄疸） → 肝细胞坏死。

**厨房下水道比喻（写文章好用）：** 人那个下水道粗，倒一大碗油慢慢流。猫那个下水道细，你倒一大桶，当场堵死。

## 五、黄疸看什么地方（4 个点 + 2 个辅助）

| 观察部位 | 怎么看 |
|---|---|
| **眼白（巩膜）** | 轻轻扒上下眼皮。正常瓷白，黄了从边缘往中间漫 |
| **耳内侧薄皮** | 翻耳壳看里面那层皮。最方便，不用抓猫 |
| **上牙龈** | 翻嘴唇，看前牙上方牙龈。正常粉红，黄了 = 中度以上 |
| **肚皮 / 大腿内侧无毛处** | 毛短/剃过毛的猫看 |
| **辅助：尿的颜色** | 正常淡黄清，黄疸 = 浓橙汁色 |
| **辅助：大便颜色** | 正常棕，黄疸 = 浅黄 / 灰白 |

## 六、怎么诊断

- **生化：** 肝酶 ALT/AST 升高（常翻 3-5 倍以上），总胆红素 TBIL 升高。ALKP、GGT 也常升高。
- **SDMA：** 同时评估是否已伤到肾脏（脂肪肝晚期常伴急性肾损）。
- **腹部 B 超：** 肝脏强回声（亮），密度均匀。和其他肝病区分的关键。
- **排除法：** 排除其他肝病（胆管肝炎、胰腺炎、三体炎、肿瘤、中毒）。
- 金标准是**肝穿刺活检**，但临床很少做，B 超 + 生化 + 典型肥胖饥饿史一般可以诊断。

---

## 七、治疗的核心：强制喂回去

**根本治疗不是护肝针，不是输液。是"把营养喂进去，喂够量"。** 只要蛋白、热量喂够，肝脏会自己把堆着的脂肪排出去。

临床常用方案：

### 1. 饲管（最关键）
- **鼻饲管（NG 管）：** 细软，从鼻孔插入胃，适合短期 1-2 周。优点：不用麻醉。缺点：管子细，只能打稀糊糊，猫会挠。
- **食管饲管（E 管）：** 颈部皮肤切口插入食道，可长期放 4-8 周。必须麻醉。**猫脂肪肝最常用。**
- 每天每公斤体重 60-80 大卡，6-8 周连续喂。你在家针管喂做不到这个量，别硬扛。

### 2. 护肝支持
- **腺苷蛋氨酸（SAMe）：** 肝细胞修复。
- **水飞蓟素（Silymarin）：** 稳定肝细胞膜。
- **维生素 B 族：** 饥饿 + 肝病常缺 B1。

### 3. 止吐 + 促食欲
- **马罗匹坦（止吐宁）：** 止吐。
- **米氮平贴耳、赛庚啶：** 促食欲。

### 4. 抗生素
- 继发感染或胆管肝炎时用。

**治愈率参考：** 前 3 天送医 + 饲管喂够 = 80%-90%。黄疸 1 周以上 + 神经症状 = 30%-50%。

## 八、在家应急：24h 不吃怎么办

| 时间窗口 | 处理 |
|---|---|
| **< 12 小时** | 观察，天热/吃多了都有可能 |
| **12-24h 完全没吃** | 开始引诱：主食罐/冻干/水煮鸡胸肉。手拿着喂，蹲地上陪。益生菌/营养液先喂点 |
| **24-48h 还是没吃** | 送医院。做生化+B超，看肝酶/胆红素。指标正常可回家补液+强饲+护肝 |
| **> 48h 或眼白已黄** | 必须住院，准备放饲管 |

## 九、减肥的正确节奏（预防第一）

**兽医安全线：每周减体重的 1%-2%。** 不要超，宁可慢。

- **热量：** 维持量 60 × 体重(kg)，减肥期 × 70-80%，**不低于 60%。** 一刀砍 1/4 量是谋杀。
- **吃：** 高蛋白(≥35%)中低脂肪(≤15%)粮，餐掺主食罐。
- **频率：** 每天 3-4 顿少食多餐，别一天一顿自助。让代谢一直处于"有东西进来"的状态。
- **运动：** 15-20 分钟逗猫棒，分两次。
- **每周称重：** 空腹排便后称。这周超 2%，下周加量。
