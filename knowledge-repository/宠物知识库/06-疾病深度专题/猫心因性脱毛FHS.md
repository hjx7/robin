# 疾病深度专题 · 猫心因性脱毛（FHS / 猫过度理毛）

> 主人以为是皮肤病，买了一堆药膏、泡药浴、治三个月没好。其实是焦虑。90% 的猫家长第一步就治反了。

---

## 一、这是什么病

**猫过度理毛（Psychogenic Alopecia / Feline Hyperesthesia Syndrome 相关），俗称心因性脱毛。** 核心不是皮肤有问题，是心理焦虑/压力大 → 猫通过舔毛自我安抚 → 舔太多 → 把自己舔秃。

90% 的主人第一步会当成真菌感染/螨虫/皮肤病治，治几个月没好才找到真正原因。

---

## 二、和普通皮肤病的关键区别

一张表区分：

| 特征 | 心因性脱毛（焦虑） | 皮肤病（真菌/螨虫/过敏） |
|---|---|---|
| **脱毛部位** | 对称分布：腹部、大腿内侧、腰两侧、前爪腕部。常见"对称的一大片秃" | 不规则斑块：头部、脖子先有，有红疹子、皮屑、痂皮 |
| **皮肤本身** | 秃的那块皮肤**基本正常**：不红、不肿、没皮屑、没疹子、没黑点 | 秃的那块有病变：发红、起疹、皮屑、结痂、油腻 |
| **毛茬** | 舔断为主：还有短毛茬在（不是连根拔），边界比较整齐 | 连根掉：光溜溜，常伴抓痕和红点 |
| **对称性** | **高度对称**是典型特征 | 不对称，哪里有病哪里秃 |
| **你在场时** | 你在的时候它可能反而不舔（伪装） | 不分时间，痒了就抓就舔 |
| **抓/咬** | 多为舔，咬和抓较少 | 抓+咬+蹭墙都有 |

最常见的秃的顺序：大腿内侧 → 腹部 → 腰两侧 → 前爪腕部。

---

## 三、最常见的压力源（按触发频率排）

猫是极度怕变的动物。下列任何一个发生后 1-4 周出现秃毛，要高度怀疑心因性：

1. **新猫 / 新狗进家**（占最大头）
2. **主人长时间出差 / 加班**（家里没人，猫分离焦虑）
3. **搬家 / 家具位置大变动 / 装修**
4. **家里来了新人**（室友、对象住进来、生孩子、老人来住）
5. **换粮 / 换猫砂 / 换食盆位置**（别小看这种小事）
6. **去医院、寄养、坐车**
7. **节日鞭炮、客人多、噪音**
8. **多猫家庭地位变化**（打了一架、地位掉了）
9. **户外有野猫 / 流浪猫在窗户附近徘徊**，室内猫隔窗哈气焦虑
10. **主人情绪变动大、家里吵架、工作压力传导**（猫能感知）

---

## 四、第一步要做的：先排除皮肤病（别一上来就归因为心理）

**确诊程序：先排除身体问题，再谈心理。** 这步 90% 主人会跳过。

去医院至少要做的四项检查：

1. **伍德灯 + 皮肤刮片 / 压片** → 排除真菌（猫癣）、螨虫、细菌感染
2. **跳蚤排查** → 哪怕是室内猫也要查。一只跳蚤能让过敏猫痒三个月。
3. **食物过敏排查** → 低敏处方粮试喂 8-12 周。很多所谓的心因性其实是食物过敏没查出来。
4. **皮肤活检（顽固性的）** → 排除罕见的内分泌/免疫介导性皮肤病

四项全部没查到问题，再结合压力源史，才能诊断心因性。

## 五、核心管理方法（不是药，是环境调整）

### 1. 先找到并去掉压力源

对照前面 10 条压力源，一条一条排查。能撤的先撤。典型：
- 窗外有野猫：贴磨砂贴纸，或者窗台放橘皮味喷雾驱离
- 新猫进家冲突：先彻底分房间，重新走 7-14 天缓慢见面
- 主人出差：找熟人上门喂，或者装带双向音视频的摄像头
- 家具变动：别一次全换，分几周慢慢挪

### 2. 环境丰容三件套

猫压力大，很大程度是因为"它没事做"。

- **高处 + 躲藏处：** 猫爬架放能看门口窗户的位置（别放墙角！）。纸箱 9 块 9 一个，永远受欢迎。
- **喂食改狩猎模式：** 把一天粮分成 3-4 份，藏在几个地方让它找。或者用漏食球。
- **每日高强度游戏：** 早晚各一次 15 分钟逗猫棒。**正确收尾：猎物慢下来、停下、扑上去咬住 = 有完成感。** 别甩脸突然收。

### 3. 信息素和辅助

- **费利威（Feliway）经典扩散器：** 合成猫面部信息素，让它觉得这个地盘安全。插在它常待房间，至少用 4 周看效果。
- **Zylkène（α-casozepine）：** 牛奶蛋白衍生的类镇静成分，无镇静副作用，应激期前后可短期喂。
- **加巴喷丁：** 严重的（已到出血、自残级）要医生处方开，短期抗焦虑 + 止痛。

### 4. 伊丽莎白圈的使用

注意：舔得已经发红、出血、自残 → 先戴软圈保护创面 + 医生开抗炎止痒 + 同步环境调整。**不要只戴圈不改环境。**

## 六、什么程度要上药物

| 程度 | 表现 | 处理 |
|---|---|---|
| 轻度 | 局部有点秃，皮肤完好，不红不出血 | 环境调整 + 费利威 + 增加游戏。6-8 周观察 |
| 中度 | 大面积对称秃，反复舔，但皮肤完好 | 环境调整 + Zylkène + 食物过敏排查。医生判断是否加阿米替林/氟西汀 |
| 重度 | 舔出血、自残、尾巴溃烂、FHS 抽搐式咬背 | 必须医生介入。加巴喷丁/阿米替林/氟西汀类抗焦虑药，可配合针灸/行为矫正 |

长期用药要注意嗜睡、食欲变化副作用，跟医生定方案。

---

## 七、主人最容易踩的 3 个坑

| 坑 | 后果 |
|---|---|
| **1. 直接买真菌膏/药浴 → 治反了** | 秃得更厉害，猫焦虑没解决反而药物应激 |
| **2. 戴圈就不管了，说"舔不到就好了"** | 创面好了一摘圈立刻舔回来，甚至发展成自残（因为压力没解决） |
| **3. 骂它 / 喷水惩罚 / 关起来** | 猫焦虑加焦虑，问题更严重。它舔毛是自我安抚，不是它故意的，惩罚没用 |

## 八、写文章可用的梗和场景

- 治了三个月猫癣，药浴洗了八次，最后是新换了个室友
- 我家肚子毛舔到秃，花了两千查真菌阴性，医生问我最近是不是搬过家。我说搬了，上周五。医生：大概率就是这个。
- 我以为它是长毛猫夏天自己剃毛，后来觉得不对，它怎么只剃肚子和大腿内侧啊
- 新猫进家后老大舔了两周，秃的那块我以为是猫癣，伍德灯照了一次又一次都没荧光
- 戴了三个月圈，摘圈当天舔出血，我才知道戴圈不能当治疗
