# 疾病深度专题 · 犬猫皮肤病

> 皮肤问题是犬猫最常见的就诊原因之一。看似小毛病，能折腾几个月。

---

## 一、症状识别（共同信号）

- 瘙痒：抓、舔、咬、蹭。
- 脱毛：局部 / 弥漫 / 对称。
- 皮屑、痂皮、油腻。
- 红疹、丘疹、脓疱。
- 色素沉着（皮肤变黑变厚）。
- 异味（马拉色菌、细菌）。
- 耳炎反复（常是皮肤问题一部分）。

---

## 二、主要病因（按频率）

### 1. 跳蚤过敏皮炎（FAD）
- **犬猫最常见皮肤过敏之一**。
- 一只跳蚤叮咬就能触发强烈过敏（对跳蚤唾液过敏）。
- 症状：**腰背尾根**瘙痒、脱毛、小红疹、皮肤增厚。
- 处理：**严格驱蚤**（每月一次，所有宠物一起驱，环境大清洁），短期激素 / 免疫调节止痒。
- 警示：很多主人"没看见跳蚤"就觉得不是，但跳蚤过敏只需要极少叮咬，没看见不代表没有。

### 2. 食物过敏
- 对某种蛋白过敏（鸡肉、牛肉、乳制品、小麦常见）。
- 症状：**脸、耳、脚、肚皮**反复痒、舔脚、耳炎反复。
- 诊断：**食物排除试验**——8 周以上吃单一新蛋白 / 水解蛋白粮，不喂任何其他零食，看是否好转。
- 处理：长期避免过敏原。

### 3. 环境过敏（异位性皮炎，AD）
- 对花粉、尘螨、霉菌等过敏。
- 症状：**季节性复发**，脚红、舔脚、耳炎、脸痒、腋下 / 肚皮红。
- 犬类常发品种：金毛、拉拉、德牧、西高地、沙皮。
- 处理：避免 / 减少过敏原（难）、免疫疗法（脱敏注射）、药物控制（奥克拉替尼、环孢素、糖皮质激素、抗 IL-31 单抗）。

### 4. 马拉色菌感染
- 酵母菌过度繁殖。
- 症状：**皮肤皱褶处**（腋下、脖颈、耳朵、脚趾间、肛门周围）黑泥、油腻、异味、红、痒。
- 常继发于过敏 + 潮湿 + 免疫低下。
- 处理：抗真菌药浴（咪康唑 / 酮康唑洗剂）+ 口服伊曲康唑严重时。

### 5. 细菌感染（脓皮症）
- 常继发于过敏 / 跳蚤 / 潮湿。
- 丘疹、脓疱、痂皮、"圆圈状脱毛"（癣状）。
- 处理：抗生素（头孢氨苄、阿莫西林克拉维酸、克林霉素等，按培养药敏）+ 洗必泰药浴。
- 反复发作要查原发过敏。

### 6. 真菌（皮肤癣）
- 犬猫癣（小孢子菌）。圆形脱毛、鳞屑、红圈。
- 人畜共患！家里小孩要注意。
- 处理：外用抗真菌（咪康唑）+ 严重口服伊曲康唑 + 环境消毒。
- 持续数周 / 数月。

### 7. 螨虫
- **疥螨**：剧烈瘙痒、耳缘足缘结痂，人畜共患。
- **蠕形螨**：部分痒部分不痒，脱毛 + 继发感染，幼犬免疫不成熟高发。
- **耳螨**：耳道黑褐色咖啡渣样泥，甩头抓耳。
- 处理：伊维菌素 / 塞拉菌素 / 狐立肟等驱虫药，耳螨用洗耳水 + 滴耳药。

### 8. 内分泌性皮肤病（犬）
- **甲减**：对称脱毛、皮肤变薄、怕冷、胖。
- **库欣综合征**：对称脱毛、皮薄、多饮多尿、肚子大。
- 处理：治原发内分泌病。

---

## 三、诊断流程

皮肤问题诊断麻烦，要按顺序排查：

1. **详细问诊**：痒不痒、哪痒、什么时候开始、有没有季节性、吃啥、驱蚤情况、用过什么药。
2. **皮肤刮片**：看螨虫（疥螨深刮、蠕形螨深刮）。
3. **伍德灯**：部分皮肤癣会发荧光（猫癣约 50% 发光）。
4. **真菌培养**：金标准但慢。
5. **细胞学（透明胶带 / 印片）**：看马拉色菌、细菌。
6. **拔毛镜检**：看毛根状态、癣菌。
7. **过敏排查**：跳蚤控制 → 食物排除试验 8 周 → 环境过敏（皮内试验 / 血清 IgE）。
8. **活检**：疑难病例。

---

## 四、治疗原则

- **治原发，不只治表面**。光抹药膏止痒不查过敏，会反复。
- **别滥用激素**：长期激素皮肤变薄、感染加重、内分泌紊乱。
- **别乱用抗生素**：按药敏用足疗程，否则耐药。
- **药浴有效**：洗必泰（细菌）、咪康唑（真菌 / 酵母）周 2 次药浴，停留 10 分钟再冲。
- **彻底驱虫**：所有宠物一起，每月一次。

---

## 五、护理与预防

- **定期驱虫**：跳蚤 / 螨虫是头号诱因，每月一次。
- **湿粮 + 鱼油**：Omega-3 改善皮肤屏障。
- **保持干燥**：洗澡 / 下雨 / 游泳后吹干，皱褶犬（沙皮、法斗）擦褶皱。
- **食物排除试验期绝对严格**：偷喂零食就前功尽弃。
- **环境清洁**：吸尘、洗床品、过敏原控制。
- **低敏粮 / 水解粮**：长期食物过敏的犬用。

- 药浴时它一脸"你过分了"
- 跳蚤没看见不代表没有，驱了一月才好
- 食物排除试验 8 周，全家偷喂就我严格，结果反复
- 伍德灯下癣发光那刻的视觉冲击
- 老年犬突然对称脱毛，结果不是皮肤是甲减
- 一年到头都在治皮肤，账单厚过病历
- 治好后第一眼看它不舔脚了，松一口气
