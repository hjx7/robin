# 狗 · 健康与常见病

> 常见病、急症、疫苗、绝育、体检。写作素材，别当诊断依据。

---

## 一、疫苗

### 核心疫苗
- **预防**：犬瘟（CDV）、犬细小（CPV）、犬腺病毒（CAV，传染性肝炎）、犬副流感（CPIV）、钩端螺旋体（部分组合含）。
- **组合**：二联、四联、六联、八联（多联 = 多防几种非核心病）。
- **首免时间**：6-8 周龄第一针，间隔 21 天，连续 2-3 针，最后一针在 16 周龄后（保证母源抗体消退）。狂犬 3 月龄以上一针。
- **加强**：第一年后加强一针。之后核心疫苗根据抗体 / 当地政策 1-3 年一次。

### 非核心
- 钩端螺旋体（有流行区才打，需每年）、冠状病毒、莱姆病等看地区。

## 二、驱虫

### 体内
- **频率**：幼犬 2、4、8、12 周各一次，之后 3 个月一次。散养 / 吃生肉 / 多狗家庭每月一次。
- **药**：拜宠清（绦虫）、犬心保（心丝虫 + 蛔虫）、海乐旺（多虫种）。
- **心丝虫**：南方湿热区 + 蚊子多的地方建议每月一次心丝虫预防。心丝虫晚期治疗贵且险。

### 体外
- **频率**：蚊虫季 1 月一次，全年出门遛的狗全年每月一次。
- **药**：福来恩（跳蚤）、大宠爱（内外同驱）、超宠（Super）（多谱）、尼可信（口服）。
- **注意**：滴剂滴后脖颈，48 小时不洗澡。

## 三、绝育

### 时机
- 传统 6-8 月龄、疫苗齐全后。
- 大型犬建议稍晚（10-18 月龄），让骨骼发育完全，降低某些关节和肿瘤风险。
- 母犬第一次发情前绝育 → 乳腺瘤风险大幅降低。
- 母犬过晚不绝育 → 子宫蓄脓高发，老年手术风险大。

### 公犬 vs 母犬
- **公犬**：摘睾丸，小切口，当天 / 次日出院，恢复快。300-800。
- **母犬**：开腹摘子宫卵巢，住院 2-3 天，戴圈 7-10 天，拆线 10-14 天。800-2000+。

### 术后
- 戴圈！别让舔。
- 限制活动 3-5 天，禁止跳沙发 / 上下楼。
- 母犬留意呼吸、切口渗血。

## 四、急症信号（立刻就医）

1. **持续呕吐不止 / 呕吐物带血 / 带粪臭味**：肠梗阻可能，狗尤其爱乱吃（袜子、玩具、骨头）。
2. **腹泻带血 / 呈番茄酱样腥臭**：细小可能，幼犬尤其危险。
3. **急性腹胀 + 流口水 + 干呕无物 + 黏膜发白**：胃扩张扭转（GDV），深胸大型犬（金毛、德牧、大丹）高发，黄金抢救时间 1-2 小时，致命。
4. **抽搐**：癫痫 / 中毒 / 低血糖 / 犬瘟神经期。
5. **突然瘫后腿 / 后腿冰凉 / 黏膜白**：血栓 / 脊髓损伤 / 失血。
6. **误食有毒物 1-2 小时内**：立刻送，路上打电话问医生是否催吐（部分腐蚀物 / 巧克力看量判断）。
7. **持续喘 + 舌头蓝紫 + 高热**：中暑 / 心衰 / 肺水肿。夏天车里 / 户外烈日下中暑致死极快。
8. **母犬未绝育 + 烦渴 + 腹胀 + 阴道分泌物**：子宫蓄脓，急症。
9. **吃异物后精神差、不食、腹痛（不让摸肚子）**：梗阻可能，照片确认。

## 五、常见病速查

### 犬瘟（CDV）
- 症状：发烧、脓鼻涕、咳嗽、脚垫硬、神经症状（抽搐、肌阵挛）晚期。
- 传播：接触 + 飞沫，未免疫幼犬高发，致死率高。
- 预防：疫苗！疫苗！疫苗！

### 犬细小（CPV）
- 症状：突然不食、呕吐、番茄酱样腥臭血便、白细胞骤降、迅速脱水。
- 传播：粪口，环境存活久，幼犬高危。
- 治疗：住院、输液、抗生素防继发、止吐止泻、隔离。存活率 70-90% 看护理。
- 预防：疫苗！

### 犬传染性气管支气管炎（"犬窝咳"）
- 症状：阵发性干咳、咳后作呕（像卡了东西）、流鼻涕。
- 病原：副流感、博德特菌、腺病毒等。
- 多数轻症自限，重症抗生素。寄养 / 犬舍密集环境易暴发。

### 皮肤问题（狗最常见的就诊原因）
- **跳蚤过敏**：腰背尾根瘙痒、脱毛、小红疹。
- **食物过敏**：脸、耳、脚、肚皮反复痒、舔脚。
- **环境过敏（异位性皮炎）**：季节性复发，脚红、舔脚、耳炎。
- **马拉色菌 / 真菌**：皮肤皱褶处黑泥、油腻、异味。
- **螨虫（疥螨、蠕形螨）**：脱毛、结痂、痒或不痒（蠕形螨可痒可不痒）。
- 处理：找原因（过敏原排查 + 食物试验 + 皮肤刮片），别乱抹药膏，激素类短期止痒。

### 耳炎
- 垂耳犬、游泳多的狗高发。
- 症状：甩头、抓耳、耳道黑泥 / 异味、红肿。
- 处理：洗耳水清理 + 医生开药（细菌 / 真菌 / 耳螨用药不同）。

### 关节问题（中大型犬）
- **髋关节发育不良（CHD）**：金毛、拉拉、德牧高发，后腿摇摆、兔子跳、起立困难。
- **椎间盘疾病（IVDD）**：柯基、腊肠等长身短腿犬，急性腰痛 → 后腿瘫。
- **前十字韧带断裂**：大型犬、肥胖犬，突然跛行不踩地。
- 管理：控体重、补关节营养、必要时手术。

### 肿瘤
- 老年犬高发。母犬未绝育 → 乳腺瘤高发。
- 常见：脂肪瘤（良性多）、肥大细胞瘤、淋巴瘤、骨肉瘤。
- 发现肿块别等，穿刺 / 切除活检。

### 心丝虫
- 蚊子传播，寄生肺动脉 / 心脏。
- 症状：咳嗽、运动不耐受、消瘦、晚期心衰。
- 预防：每月一次心丝虫药（南方湿热区尤其要）。
- 治疗贵且险（成虫杀死有栓塞风险），预防远胜治疗。

### 子宫蓄脓
- 未绝育母犬中老年高发。
- 症状：腹胀、烦渴多尿、阴户分泌物（开放型）/ 无分泌物（闭合型，更险）、发烧。
- 处理：手术摘子宫，急症。

### 胃扩张扭转（GDV）
- 深胸大型犬急症。
- 诱因：饱餐后大量饮水 + 剧烈运动。
- 症状：腹胀如鼓、干呕无物、流口水、黏膜白。
- 急救：1-2 小时内手术，否则致死率高。
- 预防：分餐、饭后别剧烈运动、深胸犬可考虑预防性胃固定术。

## 六、体检建议

| 年龄 | 频率 | 项目 |
|---|---|---|
| 幼犬接回 | 1 次 | 血常规、犬瘟细小抗原、粪检、基础体检 |
| 成年（1-7 岁） | 一年一次 | 体检 + 血常规 + 生化 + 尿检 + 粪检 |
| 老年（7 岁+） | 半年一次 | 加心脏（听诊 + 心超）、甲状腺、关节 / 脊柱 X 光 |

- 大型犬 5-6 岁起建议每年拍髋关节 / 脊柱看退变。

## 七、家庭常备

- 体温计：狗正常 37.5-39.2 度。
- 体重秤：定期称。
- 益生菌、电解质补液盐（腹泻脱水应急）。
- 碘伏 / 洗必泰（小伤口消毒）。
- 止血粉。
- 伊丽莎白圈（防舔咬）。
- 急诊医院电话地址。
- 双氧水（仅医生指导下用于催吐误食毒物，不可滥用）。
