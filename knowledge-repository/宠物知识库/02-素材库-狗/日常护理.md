# 狗 · 日常护理

> 狗日常要做的事。带频率、工具、价位，写文章时随手抓细节。

---

## 一、遛狗（狗和猫最大的区别）

### 运动量参考
| 体型 | 每天至少 |
|---|---|
| 小型犬（泰迪、比熊） | 30-45 分钟 |
| 中型（柯基、柴犬） | 1-1.5 小时 |
| 大型工作犬（边牧、金毛、拉拉） | 1.5-2 小时 + 脑力消耗 |
| 短鼻扁脸（法斗、八哥） | 20-30 分钟，别剧烈 |

- 不消耗 = 拆家、乱叫、焦虑。这是行为问题的头号原因。
- 不止遛弯，还要"嗅闻散步"——让它有时间闻，嗅闻消耗脑力，比跑更累。
- 雨天 / 大太阳可在家玩漏食球、嗅闻垫、训练替代。

### 牵引
- **胸背带 > 项圈**：胸背不会勒气管，特别是爱拉的狗、小型犬、柯基。
- **伸缩牵引绳慎用**：训练没做好时，狗乱跑、拉不住、爆冲。新手用固定长度牵引绳（1.2-1.8 米）更稳。
- **城市限养**：必戴项圈铭牌（名字 + 电话），必要时植入芯片。

### 排泄
- **定点大小便训练**：选一个固定点（厕所 / 阳台 / 草坪），饭后、睡醒、玩耍后立刻带去，成功就猛夸 + 零食。
- 出门遛狗排便是常态。带拾便袋，城市有要求。

## 二、梳毛

### 短毛（拉拉、法斗、杜宾）
- **频率**：每周 1-2 次，用短毛梳 / 去浮毛手套。
- 换毛季掉毛量惊人，每天梳。

### 双层毛（金毛、哈士奇、阿拉斯加、柯基）
- **频率**：每周 2-3 次，换毛季每天。
- **工具**：针梳 + 底绒耙（undercoat rake）。底绒耙能把厚厚的绒毛梳出来，避免打结 + 中暑。
- 夏天双层毛的狗怕热，别为了"凉快"给它剃毛，剃了破坏隔热层反而更容易中暑 + 晒伤。

### 长毛 / 卷毛（贵宾、比熊、西施）
- **频率**：每天梳，不梳就打结。
- **工具**：排梳 + 针梳。
- 定期美容修剪（一两个月一次）。

### 掉毛排行
- 巨量：金毛、拉拉、哈士奇、阿拉斯加、柯基、博美。
- 一般：边牧、柴犬、雪纳瑞。
- 少：贵宾、比熊、雪纳瑞（毛不掉而是往毛丝里长，要剪）。

---

## 三、洗澡

- **频率**：1-3 周一次，看脏的程度。狗皮肤比猫皮薄，别洗太勤，易脱屑。
- **水温**：35-38 度。
- **必须吹干**：毛根潮湿 → 皮肤病（马拉色菌、真菌、热斑湿疹）。双层毛尤其要吹透底绒。
- **沐浴露**：狗用，别用人的（pH 不同）。
- 美容店洗澡 50-200 不等，按体型和造型。

---

## 四、剪指甲

- **频率**：2-4 周一次。遛狗多的在水泥地跑会自己磨，少剪。
- **工具**：狗用指甲剪（剪刀式 / 磨甲器）。
- **黑指甲**：看不清血线，少量多次剪，或用磨甲器慢慢磨。
- 出血处理同猫：止血粉 / 面粉按压。

---

## 五、耳朵清理

- **频率**：每周看一次。垂耳犬（拉拉、金毛、可卡）尤其要勤，耳道闷湿易马拉色菌 / 耳炎。
- **方法**：洗耳水滴入 → 揉耳根 → 让狗甩 → 擦外耳道。
- **耳螨 / 耳炎**：黄褐色大量泥 / 异味 / 频繁甩头抓耳，要看医生开药。

---

## 六、牙齿护理

- **频率**：每天一次最好，现实一周 2-3 次。
- **工具**：狗用牙膏（人用氟化物有毒）+ 狗牙刷 / 指套。
- 狗咬胶 / 洁齿骨只能辅助，不能替代刷牙。
- 牙结石严重的要医院全麻洗牙，500-1500。

---

## 七、环境与日常

- **狗窝 / 垫子**：定期洗，除螨除味。
- **玩具**：耐咬玩具（Kong、尼龙骨）给爱拆家的狗；漏食球、嗅闻垫消耗脑力。
- **关笼训练**：笼子不是惩罚，是狗的"小窝"。从幼犬开始让它把笼子当安全区，方便送医、寄养、出差。
- **禁入区域**：厨房、卧室等可设禁入，从小立规矩。

---

## 八、社会化黄金期

- **3-14 周龄**是社会化的关键期。这期间接触过的人、狗、声音、环境，狗会一辈子不害怕。
- 错过这个期，成年后怕生、易攻击、难纠正。
- 接种疫苗不全的幼犬，可在家门口 / 安全区域接触，避免去狗多的地方直到疫苗齐全。

---

## 九、寄养 / 出门

- **航空箱 / 笼**：训练从小让它习惯，寄养 / 看病 / 出行都用得上。
- **寄养机构**：看环境、隔离、疫苗要求、是否给运动时间。
- **上门喂养**：熟悉环境、应激小，但需找靠谱的人。
- **带狗出门**：车里用安全带 / 车载笼，别让狗在副驾乱动。夏天别把狗单独留车里，几分钟就能中暑致死。
