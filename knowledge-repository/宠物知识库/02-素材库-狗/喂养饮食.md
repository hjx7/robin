# 狗 · 喂养饮食

> 狗粮、自制、喂法。带品牌、价位、配料怎么看，写文章时随手用。

---

## 一、狗是杂食偏肉食

- 比猫杂食性强，能消化一定碳水。
- 但蛋白仍是主体，好狗粮粗蛋白 ≥ 22%（成犬）、≥ 28%（幼犬 / 高活动）。
- 配方表里"肉类"应在前几位，且为具名（鸡肉 / 鸡肉粉），别是"肉类及制品"。

---

## 二、干粮怎么选

### 看配料表
1. 前三位有具名肉。
2. 粗蛋白 22%-32%，太高（35%+）未必好，过高蛋白对部分狗肠胃负担。
3. 粗脂肪 10%-18%。
4. 无谷 / 低谷优先（无谷概念不像猫那么重要，低谷 / 优质碳水如糙米、燕麦也行）。
5. 添加剂里有牛磺酸、葡萄糖胺 / 软骨素（中大型犬关节友好）更好。
6. 避免 BHA / BHT / 乙氧基喹啉。
7. 避免大量"肉类风味剂 / 诱食料"。

## 三、常见狗粮品牌参考（价位梯度）

> 价格仅供参考，会波动。写作素材，非购买建议。

### 高端进口（35-60 元/斤）
- **渴望（Orijen）**：六种鱼、红肉。蛋白高、肉多、贵。
- **爱肯拿（Acana）**：性价比稍高。
- **纽翠斯黑钻**：冻干粮口碑稳。
- **Go! Solutions**：碳水略高，配方干净。

### 中端进口 / 国产高端（20-35 元/斤）
- **比乐**：国产老牌，性价比稳。
- **伯纳天纯**：中端国产，配方清晰。
- **网易严选全犬**：双 11 高蛋白款，性价比标杆。
- **诚实一口**：冻干双拼，配料实诚。
- **比瑞吉**：中规中矩，稳定。

### 中低端（10-20 元/斤）
- **皇家**：处方粮线最全（肠道 / 关节 / 泌尿 / 减肥），普通款略贵偏油。
- **冠能**：处方系列不错，普通款中规中矩。
- **比格泰 / 顽皮**：超市 / 平价电商常见。

### 警示区
- 散装 9.9 包邮、超市十几块一斤的重口味"宠物调味"粮，长期吃肝肾出问题。
- 三无粮别碰。

## 四、湿粮 / 主食罐 / 鲜食

### 主食罐 / 鲜食包
- **ziwi 巅（巅峰）**：罐头 + 风干粮，肉含量高，贵。
- **K9 Natural**：冻干生食，加水还原。
- **诚实一口 / 网易**：国产鲜食包、冻干生骨肉，性价比高。

### 自制鲜食
- 优点：可控原料、新鲜。
- 风险：营养不均衡是常态，钙磷比、微量元素难调。长期单一自制易缺钙、缺锌。
- 建议：参考兽医营养师配方，别照搬"我家狗吃鸡胸肉 + 米饭"的土方。

### 生骨肉（BARF）
- 争议大。优点：贴近天性、毛发亮。
- 风险：寄生虫（生肉）、营养失衡、骨头刺穿。
- 决定喂就做足功课 + 定期驱虫 + 定期体检。

## 五、喂食频率与量

| 阶段 | 频率 | 备注 |
|---|---|---|
| 幼犬（2-3 月） | 一天 4 顿 | 泡软幼犬粮，少食多餐 |
| 幼犬（3-6 月） | 一天 3 顿 | 干粮，量按包装 + 看便便调 |
| 幼犬（6-12 月） | 一天 2 顿 | 大型犬可拉长到 1.5 顿 |
| 成犬（1 岁+） | 一天 1-2 顿 | 看品种和运动量 |
| 老年犬（7 岁+） | 一天 2 顿 | 易消化的老年粮，少油 |

### 胖瘦判断
- 摸肋骨，能轻松摸到 = 正常；摸不到 = 胖；肋骨硌手 = 瘦。
- 看腰线：俯视有腰收 = 正常；腰没了 = 胖。

### 大型犬幼犬特别提醒
- 大型犬生长快，吃高钙高蛋白粮反而易骨关节问题。选大型犬幼犬专用粮，蛋白适中、钙磷比合理。
- 别补钙过头，补钙过量 + 生长过快 = 髋关节发育不良风险增加。

## 六、狗不能吃的东西（红线）

- **葱 / 蒜 / 洋葱 / 韭菜**：溶血，致命。葱油饼、洋葱圈汤汁都算。
- **巧克力 / 可可**：可可碱中毒，黑巧克力和烘焙巧克力最危险。
- **葡萄 / 葡萄干**：急性肾衰，少量都不行。
- **夏威夷果**：中毒、后腿无力。
- **木糖醇**：低血糖、肝衰。
- **咖啡因 / 酒精**：中毒。
- **煮熟的鸡骨 / 鱼刺**：碎裂刺穿。
- **生鸡蛋清**：抗生物素蛋白。
- **牛奶**：多数狗乳糖不耐受，要喝用宠物羊奶粉或无乳糖奶。
- **高盐人食**：长期吃肝肾负担大，盐分超量引发掉毛、皮肤病。
- **苹果核 / 樱桃核 / 杏仁**：氰化物风险。

## 七、零食 / 补剂

- **零食**：训练用，别超每天总食量 10%。
  - 鸡胸肉干、冻干、洁齿骨、咬胶。
  - 别养成"我不吃正餐只等零食"的坏习惯，零食好就别给它，饿了再给粮。
- **补剂**：
  - 关节：葡萄糖胺 / 软骨素，中大型犬老年可加。
  - 鱼油：皮肤毛发、关节。
  - 益生菌：换粮、软便、应激。
  - 钙：除非医生诊断缺，别乱补。
  - 微量元素：吃合格狗粮的健康狗不用补。

---

## 八、换粮

- 7-10 天过渡：旧粮 75% → 50% → 25% → 全新粮。
- 突然换粮 = 软便拉稀。
- 换粮期可加益生菌缓冲。
- 一款粮吃几个月建议换一次？看狗状态，吃得好别折腾，吃得不好再换。频繁换粮反而易出问题。
