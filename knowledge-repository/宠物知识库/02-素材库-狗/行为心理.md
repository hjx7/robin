# 狗 · 行为心理

> 看懂狗在干什么，写文章才有真实的"我家狗怎么怎么了"。

---

## 一、肢体语言

### 尾巴
- **大幅左右摆（屁股跟着扭）**：开心、兴奋、打招呼。
- **夹尾巴（贴肚子）**：害怕、示弱。
- **竖起 + 僵硬**：警觉、可能攻击。
- **低垂 + 缓慢摆**：不确定、犹豫。
- **追着自己咬尾巴**：无聊 / 强迫症 / 跳蚤 / 肛门腺问题。

### 耳朵
- **朝前立起**：专注、警觉。
- **向后贴头**：害怕、示弱、紧张。
- **转向两侧**：留意中、不确定。

### 嘴 / 牙
- **咧嘴 + 露牙 + 唇上拉**：威胁、警告（区别于微笑）。
- **舔鼻、打哈欠**：安定信号，紧张 / 不舒服。
- **张嘴哈气 + 舌头放松垂出**：放松、开心（"狗笑"）。

### 眼睛
- **瞳孔骤大 / 凝视**：锁定目标，攻击前。
- **眨眼 / 转头回避对视**：安定信号，缓和紧张。
- **半眯眼**：放松。

### 整体姿态
- **玩 bow（前腿趴下 + 屁股撅起 + 尾巴摇）**：邀请玩耍的招牌动作。
- **身体压低、溜边走**：害怕、想逃。
- **僵硬站立 + 体重前压**：威慑、随时出击。

## 二、"安定信号"（狗狗沟通）

狗会用很多小动作表示"我紧张 / 我想缓和气氛"：

- 舔鼻子
- 打哈欠
- 转头、转身回避
- 慢动作走路
- 嗅地面（假装在闻）
- 分开动作（突然坐下、躺下）
- 尿一下

人看到这些别觉得"它没事"，多数是狗在说"压力大了，缓一缓"。

## 三、常见"问题行为"与成因

### 乱叫
- **分离焦虑**：主人出门后叫个不停 + 拆家 + 大小便。需要脱敏训练。
- **警觉吠叫**：门铃、陌生人、窗外动静。看家本能。
- **求关注叫**：叫了你就来 = 它学会叫 = 你来。
- **无聊 / 精力过剩**：消耗不够，发泄。
- 处理：找原因 > 一味骂。骂只会让狗觉得"你也在叫"，更来劲。

### 拆家
- **精力没消耗**：大型工作犬 + 上班族关笼一天 = 灾难。
- **换牙期**（4-7 月龄）：牙痒，咬东西缓解。给耐咬玩具。
- **分离焦虑**：焦虑性破坏，针对性训练。
- **无聊**：给漏食球、嗅闻垫、Kong 塞零食冷冻。

### 扑人
- 幼犬期"扑上来撒娇"被夸 = 学会了。长大了 30 公斤的拉拉还扑 = 灾难。
- 处理：扑上来时别理、转身、不互动，四脚着地才给关注。全家统一。

### 咬人手
- 幼犬期和同窝咬着玩的本能，需要教"咬合力控制"（bite inhibition）。
- 咬疼了就"哎呦"一声 + 停止游戏 30 秒，让它知道"咬疼 = 玩完"。
- 别用手逗狗，用玩具。

### 拉绳 / 爆冲
- 没训练过的狗出门像"被拖着走"。
- 处理：胸背带 + 短牵引；狗拉就停 / 转向，绳松了才前进，让它明白"绳松 = 走，绳紧 = 停"。
- 别一直拽，拽 = 拔河 = 它更使劲。

### 护食 / 护物
- 吃饭 / 咬玩具时靠近就低吼、呲牙。
- 成因：怕资源被抢。别强行夺，越夺越护。
- 处理：靠近它时手里有好吃的，丢给它，建立"人来 = 好事"。严重找训犬师。

### 见狗打架
- 牵引绳绷紧 + 主人紧张 + 缺乏社会化 = 见狗就炸。
- 处理：保持距离，奖励它看到狗但不激动的瞬间，逐步拉近（脱敏）。
- 别硬把两只狗按在一起"交朋友"。

### 撒尿做标记 / 兴奋尿
- 公狗抬腿做标记是本能，绝育后会改善。
- 兴奋尿（人回家 / 见客人）多发于幼犬和顺从性强的狗，长大 + 别太热情地招呼会改善。

## 四、狗的压力源

- 长时间独自在家（>8 小时）
- 主人焦虑 / 紧张（狗能感知）
- 频繁搬家 / 装修
- 新成员（婴儿、新狗）
- 寄养 / 医院
- 训练中过度纠正 / 体罚
- 不规律作息

压力反应：舔毛过度（脚、肚子）、自我啃咬、转圈、踱步、食欲差、软便。

---

## 五、多狗 / 多宠相处

- 新狗到家先隔离几天，分房间。
- 在中立区域（户外、街道）见面，别在家里直接塞一起（家里狗会护地盘）。
- 资源 N+1：食盆、水、窝、玩具按狗数 +1 配置，分开喂食避免护食。
- 真打架有伤要分开，并找训犬师评估。

---

## 六、狗的智力 / 学习特点

- 狗能学名字、几百个口令、按钮交流、看人手势和眼神。
- 学习靠"行为 → 后果"：好后果（零食、夸）= 行为重复；坏后果（忽视、停游戏）= 行为减少。
- 一次 3-5 分钟短训效果最好，多次 > 一次长。
- 正向奖励为主，惩罚（打骂）只会让狗躲你、护你、信不过你。
- 狗记不住"我两小时前咬了拖鞋，所以现在被骂"——抓现行才能纠正，事后骂它一脸懵。
