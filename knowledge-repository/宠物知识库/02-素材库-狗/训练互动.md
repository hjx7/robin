# 狗 · 训练互动

> 训狗的实操。带口令、节奏、工具，写文章时能写出"我怎么训它"的细节。

---

## 一、训练的底层逻辑

- **正增强为主**：做对了给奖励（零食 / 夸 / 玩），行为就重复。
- **抓现行**：奖励 / 纠正必须在行为发生 1-3 秒内，晚了狗不知道为啥。
- **短时多次**：一次 3-5 分钟，一天 2-3 次，比一次半小时强。
- **难度递增**：从客厅无干扰 → 院子 → 街道，逐步加干扰。
- **口令统一**：全家用一个词，"坐下"就别有的说"坐"有的说"坐好"。
- **零食分级**：低干扰环境用普通零食，高干扰环境（户外、有狗有猫）用"高价值"零食（鸡肉干、奶酪、肝脏）。

---

## 二、基础口令（必备 6 个）

### 1. 坐（Sit）
- 手里拿零食，从鼻子上方慢慢往后移，它抬头追零食屁股自然落地，立刻说"坐"+ 给零食。
- 反复几十次，它听到"坐"就知道坐。
- 应用：吃饭前坐下、出门前坐下、见人坐下（替代扑人）。

### 2. 等（Wait / Stay）
- 让它坐下，伸手掌挡住它，说"等"，原地 1 秒 → 给零食。
- 慢慢拉长时间和距离：3 秒、5 秒、退一步、退两步。
- 应用：吃饭前等、开门前等、过马路前等。

### 3. 来（Come / Recall）
- 这是最重要的口令，关键时刻能救命。
- 训练：低干扰环境，叫名字 + "来"，它过来就猛夸 + 高价值零食。
- 千万别"叫来 = 骂一顿"（如"叫它来剪指甲 / 洗澡"），它学会"叫来 = 倒霉"就再也不来了。
- 真正能放手的召回要在不同环境、不同干扰下反复练几个月。

### 4. 趴下（Down）
- 从坐开始，零食贴地面从鼻尖往它身下拉，它顺势趴下，立刻给。
- 比坐更难（趴是顺从姿势，部分狗抗拒），耐心。

### 5. 松绳走（Heel / Loose leash）
- 狗拉绳 → 停下 / 转身，绳松了才继续走。
- 它学会"绳松 = 前进，绳紧 = 停"。
- 初期慢，坚持一两周明显改善。

### 6. 放下（Drop it / Leave it）
- 狗嘴里有东西，拿高价值零食换，说"放下"，它吐出来给零食。
- 应用：捡了危险物（巧克力、袜子）时救命。

## 三、室内大小便训练

1. 选固定点（尿垫 / 阳台草坪块 / 户外草地）。
2. 关键时机带去：睡醒、吃完饭 5-15 分钟内、玩耍后。
3. 在指定点等，成功立刻猛夸 + 零食。
4. 失误别打，悄悄清理（用生物酶除味剂彻底去味，否则狗循味再来）。
5. 3-4 个月前别指望稳定，幼犬憋不住。
6. 习惯养成后逐步减少尿垫面积 / 拉长出门间隔。

## 四、社会化（3-14 周黄金期）

让幼犬接触：
- 不同的人：男的女的、高的矮的、戴帽子的、戴眼镜的、推车的、坐轮椅的。
- 不同的狗：友好、疫苗齐全的成犬。
- 不同的环境：草地、水泥、楼梯、电梯、车内。
- 不同的声音：吸尘器、吹风机、鞭炮（远距离低音量开始）、雷声录音。
- 不同的表面：水、沙、网、金属格栅。

每次接触 = 好事（零食 + 夸），别强迫，让它自己探索。

## 五、常见问题训练思路

### 分离焦虑
- 出门别大告别，回家别过分热情，让出门 / 回家变"无趣"。
- 从离开 1 秒开始，逐步加长，回来时它没焦虑才进屋。
- 给"只在你走后才有的"漏食玩具（Kong 塞花生酱 + 冻冰箱），让它把你走 = 好事。
- 严重找训犬师 / 行为兽医，可能需药物辅助。

### 见狗就炸
- 找一个"安全距离"——狗看到其他狗但还能吃东西、还能听你话的距离。
- 在这个距离反复奖励它"看到狗但不激动"。
- 慢慢拉近，几周 / 几月为单位。
- 别硬拽过去"交朋友"。

### 护食
- 靠近它吃饭时手里拿更好吃的（鸡肉），丢给它，走开。
- 反复建立"人靠近 = 加餐"。
- 严重（呲牙、咬）找训犬师，别硬上。

### 扑人
- 全家统一：扑上来 = 转身 / 不理 / 走开，四脚着地才摸。
- 给它替代行为：客人来让它"坐下"才有奖励。

## 六、训练工具

- **clicker（响片）**：5-10 块一个，按下"咔嗒"+ 零食，标记正确行为。比口令精确。
- **胸背带**：防爆冲、保护气管。
- **漏食玩具 / Kong**：消耗脑力、缓解焦虑。
- **嗅闻垫**：藏零食让它闻，10 分钟嗅闻 ≈ 1 小时散步的脑力消耗。
- **长牵引绳（5-10 米）**：户外训练用，给空间但不失控。
- **零食包腰包**：随手掏零食，及时奖励。

---

## 七、训练禁忌

- **别打骂**：狗不知道为啥挨打，只会怕你。
- **别事后算账**："回来看到家里一团糟"再骂，它一脸懵。
- **别叫来 = 坏事**：召回训练的禁忌。
- **别追逐**：狗跑了你追，它觉得在玩，跑得更欢。该反过来跑 / 蹲下叫它。
- **别在它激动时下口令**：脑子一片空白时听不见。

---

## 八、和狗玩什么

- **拔河**：规则明确（"松"口令），玩完它主动松开。能消耗精力 + 增进关系。
- **寻回（Fetch）**：丢球 / 玩具，它叼回来。消耗体力。
- **嗅闻游戏**：零食藏起来让它闻，雨天 / 老年狗特别适合。
- **敏捷训练**：跳栏、钻圈、绕杆，边牧 / 德牧 / 拉拉这类聪明狗热爱。
- **嗅闻散步**：别总赶时间，让它闻 5 分钟一棵树，消耗脑力比跑步还累。
