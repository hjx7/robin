# 考古与文物合集

> 每个条目带【出土时间地点】【现存博物馆】【具体数字】【争议点】【个人视角切入点】。

## 一、镇国级文物

### 1. 越王勾践剑
- **出土**：1965年，湖北江陵望山一号楚墓
- **年代**：春秋晚期，约前5世纪
- **现存**：湖北省博物馆
- **尺寸**：通长55.7厘米，宽4.6厘米，重875克
- **铭文**：8字鸟篆铭文"越王鸠浅自作用剑"（"鸠浅"即"勾践"）
- **特殊之处**：
  - 出土时插在髹漆木质剑鞘里，拔出来寒光闪闪，无一锈斑
  - 现场人员拿纸试，能划开20余层
  - 剑身含铜80-83%，锡16-17%，还有少量铅、铁、硫、砷
  - 剑格上嵌有蓝色琉璃和绿松石
- **争议**：表面含铬？有学者说是刻意镀铬（西方1937年才发明镀铬技术），也有学者认为是表面处理的副产物，不是刻意镀的
- **【切入点】**："这把剑在地下埋了2500年，出土的时候一点锈都没有，还能划纸。你想想2500年是什么概念——从勾践那会儿到今天，多少王朝更迭了，这把剑一直在地下，安安静静的，不氧化不腐蚀。我前几年去武汉的时候专门去湖北省博看了，就一个小玻璃柜里放着，比我想象的短——55厘米，真的就是一把短剑。但凑近了看那个剑刃的寒光，还是会打个寒颤。"

### 2. 鎏金舞马衔杯纹银壶
- **出土**：1970年，陕西西安何家村唐代窖藏
- **年代**：唐代
- **现存**：陕西历史博物馆
- **尺寸**：高14.8厘米，重549克
- **特殊之处**：
  - 壶身仿皮囊形，侧面錾刻一匹鎏金舞马，马颈系绶带，口衔酒杯
  - 中国境内出土的唯一一件舞马形象文物
  - 制作工艺：先锤揲成型，再錾刻图案，局部鎏金
- **背景故事**：唐玄宗时期训练了几百匹舞马，千秋节（玄宗生日八月初五）在勤政楼下表演，舞马衔杯给皇帝祝寿。安史之乱后舞马被安禄山部下接管，军人以为是普通马，要它们跳舞，不跳就打，结果舞马越打越跳（以为还是在表演），军人以为是妖怪，全打死了。
- **【切入点】**："我在陕历博见过这个壶，巴掌大，马的鬃毛一根一根都刻得清清楚楚，嘴里还叞着一个酒杯。据说唐朝训练了几百匹舞马，每年皇帝生日的时候跳舞祝寿。结果安史之乱之后，这帮舞马被当成了普通马，越打越跳，当妖怪打死了。一只巴掌大的银壶，记录了一个心碎的故事。"

### 3. 曾侯乙编钟
- **出土**：1978年，湖北随州（今随县）擂鼓墩一号墓
- **年代**：战国早期，约前433年下葬
- **现存**：湖北省博物馆
- **尺寸**：总长7.48米，高2.73米，总重约4400公斤
- **组成**：65件钟（含1件镈钟），分三层八组悬挂在曲尺形钟架上
- **音域**：五个半八度（C2到D7），只比现代钢琴少一个八度
- **特殊之处**：
  - 一钟双音——正鼓部和侧鼓部各有一个音，相差三度
  - 每件钟上有铭文，标注音名和乐理
  - 出土后还能演奏，1984年曾用它演奏《东方红》
- **【切入点】**："编钟你只在课本上见过的话，是没有概念的。我去湖北省博看过实物——7.5米长，2.7米高，4.4吨重，65件钟挂在一个L形的木架上。站它面前你会觉得渺小。而且一钟双音这个技术太逆天了——敲正面一个音，敲侧面另一个音，差三度。2500年前中国人就能造出这个，音域只比钢琴少一个八度。你说牛不牛？"

## 二、重要考古发现

### 4. 马王堆汉墓
- **出土**：1972-1974年，湖南长沙马王堆
- **年代**：西汉初期，约前168年-前2世纪
- **现存**：湖南省博物馆
- **墓主**：轪侯利苍（长沙国丞相）、其妻辛追、其子利豨
- **出土文物**：3000余件
- **辛追夫人**：
  - 尸体埋了2100多年，出土时皮肤还有弹性，关节能活动
  - 血管里还有血（A型血）
  - 身高154厘米，体重34.3公斤（出土时），约50岁死亡
  - 解剖发现胃里有138.5个甜瓜子——死前不久吃了大量甜瓜
  - 死因推测：胆结石导致的胆绞痛诱发心肌梗死
- **素纱襌衣**：
  - 49克，叠起来能放进火柴盒
  - 面料是素纱（没有花纹的平纹纱），薄如蝉翼
  - 复制这件衣服花了专家13年，最接近的一件也有49.5克
- **帛书**：出土了《老子》甲乙本（最早的版本）、《战国纵横家书》《五星占》等大量帛书，许多是失传版本
- **【切入点】**："辛追夫人是最让我震撼的考古发现之一。2100年前的尸体出土时还有弹性，还有血。而且解剖发现她胃里有138粒甜瓜子——她死前不久吃了西瓜子。这就很具体了：一个2100年前的贵妇人，夏天吃了一堆甜瓜，然后胆绞痛发作，心脏病发了，死了。太具体了，具体到你闭上眼睛能想象她最后一天。"

### 5. 海昏侯墓
- **出土**：2011年发现，2015-2016年发掘
- **年代**：西汉
- **墓主**：刘贺（第一代海昏侯，汉废帝，当了27天皇帝被霍光废掉）
- **现存**：江西省博物馆
- **出土文物**：1万余件
- **金器**：478件，总重超过120公斤（金饼385枚、马蹄金48枚、麟趾金25枚、金板20版）
- **五铢钱**：约200万枚，重约10吨
- **竹简**：5000余枚，含《齐论语》（失传1800年，终于重见天日）、《论语》知道篇
- **孔子屏风**：上有孔子画像，标注孔子身高"七尺九"，换算约1.82米
- **争议**：刘贺真当了27天皇帝干了1127件坏事？一天40多件，平均醒着每小时干1.7件坏事——明显是霍光编的
- **【切入点】**："刘贺这哥们儿太惨了。当了27天皇帝被废了，霍光给他列了1127条罪状。一天40多件坏事，你信吗？我反正不信。但后来他被封到江西当海昏侯，死的时候陪葬了120公斤黄金、10吨铜钱——你说他冤不冤？冤。但你说他惨不惨？也不是太惨，至少下葬的时候金子没少带。"

### 6. 三星堆
- **出土**：1986年首次大规模发掘，2019-2022年新一轮发掘
- **年代**：商代晚期，距今约3000-3200年
- **地点**：四川广汉
- **现存**：三星堆博物馆
- **代表性文物**：
  - **青铜纵目面具**：宽1.38米，高0.65米，重80多公斤，眼球突出眼眶16厘米，耳朵像两个大翅膀
  - **青铜大立人像**：高2.62米（连座），人像1.72米，双手夸张地大，呈环握状（拿什么？不知道）
  - **青铜神树**：高3.96米，三层九枝，每枝站一只鸟，共九只鸟（对应《山海经》扶桑树神话）
  - **黄金面具**：2021年新出土，宽37.2厘米，重约280克
  - **青铜太阳轮**：直径85厘米，五芒星状
- **争议**：
  - 来源：外星人？西亚？中原影响？至今没定论
  - 文字：目前没发现文字，但出土了大量青铜器
  - 消失：三星堆文明突然消失了，原因不明
- **【切入点】**："三星堆那些面具你看了会觉得不像中国人。眼球突出16厘米，耳朵像翅膀，鼻子又高又直。有人说这是外星人，有人说来自西亚。我去年去看了，第一反应是：这不像是青铜器，像是科幻电影道具。尤其是3.96米的青铜神树，九只鸟站在上面，对应《山海经》里扶桑树上有十个太阳的故事。3000多年前的人造出这个，太超前了。"

### 7. 兵马俑
- **出土**：1974年3月，农民杨志发打井时发现
- **年代**：秦始皇时期（前3世纪）
- **现存**：秦始皇帝陵博物院（西安临潼）
- **规模**：
  - 一号坑：长230米，宽62米，约6000件陶俑陶马
  - 二号坑：约1400件
  - 三号坑：68件（指挥所）
  - 总计：约8000件陶俑陶马
- **特殊之处**：
  - 每个陶俑面部表情不同，发型不同，手势不同
  - 出土时是彩色的——脸是粉色，衣服是绿红蓝紫，颜料见空气几分钟就氧化掉了
  - 兵马俑没有两个一样的
- **【切入点】**："兵马俑刚挖出来的时候是彩色的，这个很多人知道。但你知道颜料几分钟就掉了吗？考古队的人亲眼看着粉色的脸变成土灰色。后来技术进步了，新出土的俑能保住颜色了。我在一号坑看的时候，最大的震撼不是数量——是每一个人都不一样。8000个人，8000张脸。你想想需要多少工匠做多少年。而且这些俑都是面朝东，背对着秦始皇陵——在地下替皇帝戍守东方。两千年了，还站着。"

### 8. 殷墟
- **出土**：1928年开始发掘（中国第一次科学考古发掘）
- **年代**：商代晚期，约前1300年-前1046年
- **地点**：河南安阳
- **现存**：殷墟博物馆、中国国家博物馆
- **出土内容**：
  - 甲骨文：约15万片（历年来出土总数）
  - 司母戊鼎（后母戊鼎）：高1.33米，重832.84公斤，最大的青铜器
  - 妇好墓：1976年发掘，出土468件铜器（其中青铜钺130多斤），755件玉器
  - 人殉人祭坑：大量斩首、砍肢的人骨
- **妇好**：商王武丁的王后，也是女将军。甲骨文记载她带兵打仗，最多一次带1.3万人。她的墓里出土了青铜钺——上面刻着"妇好"二字，是她的兵器。
- **【切入点】**："妇好这个人太酷了。她是商王武丁的王后，还是女将军，甲骨文记载她带兵打仗，最多带1.3万人。她墓里出土了铜钺，上面刻着她的名字。这是中国历史上第一个有名字的女将军，而且有文字记载、有实物出土。甲骨文里还有武丁占卜'妇好会不会生男孩''妇好牙痛会不会好'——你看这就是商朝的日常。"
