## 已规划的选题方向

### 1. 一级文物 / 国宝级文物（每个都值得单独写一篇）

- **何家村遗宝（陕西历史博物馆）**
  - 1970年西安何家村出土，两个陶瓮+一个银罐，装了1000多件文物，金器总重14918克，银器总重195537克
  - 代表：鎏金舞马衔杯纹仿皮囊银壶、鸳鸯莲瓣纹金碗、镶金兽首玛瑙杯
  - 出处：《花舞大唐春：何家村遗宝精粹》（陕历博出的图录）
  - 个人视角："我在陕历博见过那个鎏金舞马衔杯银壶，巴掌大，马的鬃毛一根一根都刻得清清楚楚，嘴里还叼着一个酒杯。据说唐玄宗的时候，训练了几百匹舞马，千秋节的时候在勤政楼下跳舞，跳到高潮，舞马就衔着酒杯给玄宗敬酒。后来安史之乱，这些舞马被安禄山抓去，他手下的军人以为是普通马，要它们跳舞，不跳就打，结果舞马越打越跳，军人以为是妖怪，全打死了。"

- **马王堆汉墓（湖南省博物馆）**
  - 1972-1974年长沙马王堆出土，西汉长沙国丞相利苍和他老婆辛追、儿子利豨的墓
  - 辛追的尸体，埋了2100多年，出土时皮肤还有弹性，关节能活动，血管里还有血（A型血）
  - 出土了3000多件文物：素纱襌衣（重49克，叠起来能塞进火柴盒）、T型帛画、大量帛书（《老子》甲乙本、《战国纵横家书》、《五星占》、五十二病方……）
  - 出处：《长沙马王堆二、三号汉墓发掘报告》、湖南省博物馆官网
  - 争议点：辛追的尸体为什么能保存这么好？科学家说是棺液的作用，但棺液的成分至今没完全搞清楚

- **海昏侯墓（江西省博物馆）**
  - 2011-2016年南昌出土，第一代海昏侯刘贺的墓（就是当了27天皇帝被霍光废掉的那个汉废帝）
  - 出土文物1万多件，其中黄金478件，总重超过120公斤（金饼、马蹄金、麟趾金、金板），还有200万枚五铢钱（约10吨）
  - 出土了失传1800年的《齐论语》、孔子屏风画像（上面写了孔子的身高"七尺九"，换算下来1.82米）
  - 争议点：刘贺真的干了1127件坏事吗？（霍光给他列的罪状，27天干了1127件，平均一天40多件，喝水的功夫就能干一件坏事？明显是编的）

- **越王勾践剑（湖北省博物馆）**
  - 1965年湖北江陵望山楚墓出土，春秋晚期越国的剑，主人是越王勾践
  - 长55.7厘米，宽4.6厘米，重875克
  - 出土时插在髹漆的木质剑鞘里，拔出来的时候寒光闪闪，一点锈都没有，现场工作人员拿纸试了一下，能划开20多层纸
  - 成分：含铜80-83%，锡16-17%，还有少量铅、铁、硫、砷
  - 为什么两千多年不生锈？①剑身镀了一层含铬的金属（镀铬技术，西方1937年才发明专利）；②埋藏环境好，中性土层，完全浸水，隔绝氧气
  - 争议点：镀铬技术是不是真的？有学者认为不是刻意镀的，是表面处理的副产物

- **三星堆青铜面具、青铜神树（三星堆博物馆）**
  - 1986年四川广汉三星堆出土，距今约3000-3200年，商代晚期
  - 青铜纵目面具：宽1.38米，高0.65米，重80多公斤，眼球突出眼眶16厘米，耳朵像两个大翅膀
  - 青铜神树：高3.96米，共分三层，每层三根树枝，每根树枝上站一只鸟，共九只鸟（对应《山海经》里的扶桑树，树上有十个太阳，九个在下面，一个在上面值日）
  - 争议点：这些面具的造型（纵目、大耳、高鼻）怎么看都不像东亚人，有人说来自外星，有人说来自西亚，至今没定论

### 2. 有意思的考古现场故事

- **定陵挖掘**：1956-1958年，明神宗万历皇帝和他两个皇后的墓，中国唯一主动挖掘的帝王陵。挖开之后，因为当时技术不行，丝织品、木器、帝后棺椁很快就朽坏了，万历的尸骨文革时被红卫兵拖出来烧了。后来考古界有了铁律：不主动挖掘帝王陵。
  - 出处：《风雪定陵》（杨仕、岳南著）

- **兵马俑的颜色**：刚挖出来的兵马俑是彩色的，脸是粉的，衣服是绿的红的蓝的，颜料见了空气，几分钟就氧化掉了，变成现在的土灰色。现在技术进步了，新挖的兵马俑能保住颜色了。
  - 出处：《秦始皇陵兵马俑坑一号坑发掘报告》

## 写文物 / 考古文章的注意事项

1. 数字要准确：重量、高度、年代、出土地点、现在藏于哪个博物馆
2. 如果自己亲眼见过，一定要写个人感受："我在陕历博看见这个的时候，趴在玻璃上看了十分钟"
3. 可以写点文物背后的故事，比干巴巴介绍尺寸更有意思
4. 有争议的地方（比如镀铬技术、三星堆来源）要明说有争议，别瞎下结论
5. 最好配个图（Obsidian 里插本地图片），没图的话至少说清现在藏在哪，有机会可以去看
