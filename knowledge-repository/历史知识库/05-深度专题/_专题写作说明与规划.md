# 深度专题 - 说明

> 这个目录放的是"深度拆解"类的内容。不是一个知识点，而是一条线、一个系统、一个长期的过程，前后关联、因果链条长，需要几万字甚至更多才能说清楚的。
>
> 每个专题单独一个 md 文件，文件标题直接用专题名。

## 已规划的专题方向（想到就写，不急）

### 1. 丞相制度是怎么一步步死掉的？
- 从先秦的相邦→秦朝的丞相→汉朝的三公→隋唐的三省六部→宋朝的二府三司→明朝废丞相
- 写清楚每一阶段谁掌权、相权跟皇权怎么博弈、为什么每次变革
- 最后落点在胡惟庸案——为什么朱元璋非要废掉丞相不可，废掉之后明朝又靠什么运转

### 2. 皇位继承这事儿，怎么就没人能玩明白？
- 嫡长子继承制：立长不立贤，为什么？因为"贤"没标准，"长"有标准
- 但嫡长子继承也有问题：傻皇帝（晋惠帝）、小皇帝（东汉一堆娃娃皇帝）
- 然后是秘密立储制：雍正发明的，写两份遗诏，一份放乾清宫正大光明匾后面，一份皇帝随身带
- 每个朝代的继承制度是什么，出过什么幺蛾子，写透

### 3. 古代的税收，怎么从收粮食变成收银子的？
- 先秦两汉：租庸调制（收粮食+布匹+服劳役）
- 唐中期：两税法（按资产征税，夏秋两季收）
- 明万历：一条鞭法（各种税合并成一条，一律折成银子收）
- 清雍正：摊丁入亩（人头税并入田赋，彻底废除人头税）
- 每次税制改革为什么来的、改了之后效果怎么样、有什么副作用

### 4. 古代的兵，从征兵制到募兵制，再到世兵制，怎么越改越乱？
- 先秦两汉：征兵制（义务兵，成年男子都要服役几年）
- 三国：世兵制（军户，父死子继，当兵是世袭的）
- 唐前期：府兵制（均田制配套，兵农合一，自备武器粮食）
- 唐后期-宋：募兵制（职业兵，国家花钱雇，终身制，导致冗兵冗费）
- 明清：卫所制→八旗绿营→湘军淮军→新军

### 5. 那些"大一统"的王朝，是怎么一步步统一全国的？
- 秦统一：函谷关→三川→南阳→巴蜀→逐个灭六国（先后顺序韩赵魏楚燕齐，前230-前221，十年）
- 汉统一：刘邦→先入关中→项羽分封→还定三秦→出关跟项羽打四年→垓下决战
- 隋统一：北周灭北齐（577）→杨坚代周建隋（581）→隋灭陈（589），中间隔了8年
- 元统一：蒙古灭金（1234）→打南宋（1235-1279），打了45年
- 清统一：入关（1644）→灭大顺→灭南明→灭三藩（1681）→收台湾（1683），前后近40年
- 每一次统一，先打哪后打哪，为什么这个顺序，关键转折点在哪

## 写专题的注意事项

1. 一个专题至少写 3000 字，最好 5000 字以上，别怕长
2. 要有明确的"线"：按时间顺序，或者按逻辑顺序，一条线串到底
3. 每个节点都要有史料出处和具体数字，不能空泛
4. 可以穿插小故事、个人吐槽，但主线要清晰
5. 别结尾升华"这就是历史的必然"，历史没有必然，全是偶然叠加出来的
