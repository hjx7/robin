# 典章制度变迁速查

> 这份文件是写文章时的制度类背景资料。写人物和事件的时候随时查阅，把制度背景融入叙述。

---

## 一、丞相制度

### 演变线索
1. **先秦**：相邦/相国（一人之下万人之上）
2. **秦朝**：丞相（左丞相+右丞相），太尉（军事），御史大夫（监察），合成"三公"
3. **西汉**：三公 → 大司马大将军领尚书事（实权转移）→ 东汉以太傅录尚书事
4. **东汉**：三公变虚职，实权在尚书台（皇帝的秘书机构）
5. **隋唐**：三省六部制。中书省（决策）、门下省（审核）、尚书省（执行），六部（吏户礼兵刑工）。没有单一"丞相"，但有"同中书门下三品""同平章事"等头衔行相权。
6. **宋朝**：二府三司。中书门下（民政），枢密院（军事），三司（财政）。进一步分散相权。
7. **元朝**：中书省（一省制），设左右丞相
8. **明朝**：洪武十三年（1380年）废丞相，六部直接对皇帝负责。后来设内阁，首辅相当于"准丞相"，但没有法定地位。
9. **清朝**：内阁 + 军机处（雍正设立），军机大臣是实际上的宰相，但还是没有法定地位。

### 关键转折
- 朱元璋废丞相是最大的转折。理由：胡惟庸案。代价：皇帝要亲自处理所有政务，累死。朱元璋8天处理3291件事，平均5分钟一件。后来明朝皇帝扛不住，设了内阁，但内阁大学士只有建议权没有决定权，导致了"票拟—批红"制度。
- 清朝军机处更离谱：军机大臣连办公地点都没有正式编制，就是皇帝的私人秘书班子。所以清朝的"宰相"是"有名无实"的。

【切入点】"丞相这个职位，从秦到明，存在了1600年。朱元璋一刀把它废了，从此皇帝一个人干所有活。他不累吗？他不累谁累？后面的皇帝受不了，又变相恢复了——内阁首辅、军机大臣，其实都是没有名分的丞相。但区别在于：以前丞相是有法定权力的，皇帝想换还得找理由；后来这些'准丞相'的权力全是皇帝给的，随时可以收回。所以明清两代的皇权，比之前任何朝代都大。"

## 二、地方制度

### 演变线索
1. **西周**：分封制（封邦建国）
2. **秦朝**：郡县制（36郡，后增至40余郡）
3. **汉朝**：郡国并行（一半郡县一半封国，后来推恩令把封国越分越小）
4. **魏晋南北朝**：州郡县三级（州从监察区变成行政区）
5. **隋唐**：道州县（道是监察区）→ 安史之乱后藩镇割据，道变成实权行政区
6. **宋朝**：路州县（路相当于省）
7. **元朝**：行省制（10行省），这是"省"的由来
8. **明清**：省府县（布政使司/承宣布政使司 = 省）

### 关键点
- "省"字来源于元朝的"行中书省"——中书省的派出机构。
- 州县的数量：唐代约350州1500县，宋代约300州1300县，清代约300府1500县。两千年间县级数量基本稳定在1300-1500个左右。
- 【切入点】"中国两千多年的县级数量基本稳定在1300-1500个左右，这不是巧合。一个县官能管的人口和面积是有上限的，在古代交通和通讯条件下，这个上限就是这么大。你要管更多的人，就得加层级。所以制度演变的核心动力不是谁设计了什么，而是人口增长倒逼出来的。"

## 三、选官制度

### 演变线索
1. **先秦**：世卿世禄（贵族世袭）
2. **汉代**：察举制（地方推举"孝廉"）+ 征辟制（皇帝征召）
3. **魏晋南北朝**：九品中正制（按门第品评）→ "上品无寒门，下品无世族"
4. **隋唐至清**：科举制（587年隋文帝开始，1905年废除，约1300年）

### 科举的关键数据
- 唐代：共取进士约7000人（平均每年不到30人）
- 宋代：共取进士约60000人（平均每年约200人，最多一年998人，宋徽宗时期）
- 明代：共取进士约25000人（平均每年约90人）
- 清代：共取进士约27000人（平均每年约100人）
- 状元总数：唐至清约600个状元
- 【史料】《通典·选举》《宋史·选举志》《明史·选举志》《清史稿·选举志》
- 【切入点】"科举制最大的贡献是给普通人一条上升通道。但通过率极低——明清时期一个县大概每三年出一个1-2个秀才的概率，一个府大概每三年出1-2个举人，一个省每三年出3-5个进士。你算算这个比例，比今天考上清北还难。但至少有一个明确的制度：你考得上就行，不看你是谁的儿子。这在全世界都是超前的。"

## 四、军事制度

### 演变线索
1. **先秦**：征兵制（成年男子义务服役，"寓兵于农"）
2. **汉代**：征兵制 + 募兵制（汉武帝开始大规模用募兵）
3. **三国**：世兵制（军户，父死子继）
4. **西魏北周-隋唐**：府兵制（均田制配套，兵农合一，自备弓矢衣装）
5. **唐中后期-宋**：募兵制（终身职业兵）
6. **明朝**：卫所制（军户屯田，类似府兵制，但不设将军常驻，"将不专兵，兵不属将"）
7. **清朝**：八旗制（满洲军户）+ 绿营（汉人职业兵）
8. **晚清**：湘淮军 → 新军

### 关键点
- 府兵制崩溃原因：均田制崩溃。府兵需要授田才能自备装备，土地兼并之后没田了，谁还当府兵？
- 宋朝冗兵：北宋禁军+厢军约125万（仁宗时期），军费占财政支出七八成。
- 明朝卫所衰败：到明朝中后期，军户大量逃亡，卫所名存实亡。
- 【切入点】"中国兵制有个循环：征兵→世兵→募兵→财政崩溃→改革→再征兵。因为募兵制太烧钱了，宋朝就被军费拖死的。但征兵制需要老百姓有地种、有时间训练，土地一兼并，这套就玩不转了。这个死循环，两千年来一直没解开。"

## 五、税收制度

### 演变线索
1. **西周-春秋**：井田制（公田劳役 + 私田产出归己）
2. **春秋战国**：初税亩（鲁国前594年，按亩收税，不再分公田私田）
3. **汉代**：田租（三十税一）+ 口赋（人头税）+ 更赋（徭役）
4. **唐前期**：租庸调制（租=粮食，庸=劳役或代役绢布，调=布匹）
5. **唐中后期**：两税法（780年，杨炎改革，按资产收税，夏秋两季）
6. **明朝**：一条鞭法（1581年，张居正改革，各种税合并折银征收）
7. **清朝**：摊丁入亩（1723年，雍正改革，人头税并入田赋，取消人头税）

### 关键数据
- 汉初田租三十税一（3.3%），汉景帝后一直保持。但实际不止，因为还有人头税和徭役。
- 明朝一条鞭法：把田赋、徭役、杂税合并，一律折银征收。一亩地大概交0.03-0.04两银子。
- 清朝摊丁入亩：之前老百姓要交两份税——一份按地（田赋），一份按人头（丁银）。摊丁入亩之后只按地收，没有地的人不用交税了。
- 【史料】《通典·食货》《明史·食货志》《清史稿·食货志》
- 【切入点】"摊丁入亩这事儿我觉得是清朝最大的德政。以前穷人有几个孩子就多交几份人头税，现在不按人头收了，按地收。穷人没地，就不用交。大地主有地，多交。这不就是'累进税制'吗？雍正干这事儿得罪了地主，但老百姓得了实惠。所以雍正口碑不好，是因为地主阶层掌握了话语权，骂了他三百年。"
