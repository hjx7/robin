# 先秦 - 文人墨客与文化

> 素材使用说明：每个知识点都尽量带【史料出处】【具体时间/数字】【可写的个人视角切入点】。

---

## 一、孔子

### 1. 基本信息
- 生卒：前551年-前479年，享年73岁
- 名丘，字仲尼
- 籍贯：鲁国陬邑（今山东曲阜）
- 3岁丧父，17岁丧母，年轻时当过仓库管理员（委吏）和牧羊人（乘田）

### 2. 具体可写细节
- **孔子有多高？**
  - 《史记·孔子世家》写"孔子长九尺有六寸，人皆谓之长人而异之"。
  - 西周的一尺约19.9-20.5厘米，九尺六寸约191-196厘米。
  - 孔子他爸叔梁纥是个武士，力大能扛城门（偪阳之战"纥抉悬门以出"——把城门的门栓托起来）。
  - 【史料】《史记·孔子世家》《左传》襄公十年
  - 【切入点】"我去年去曲阜三孔，孔庙里那棵桧树说是孔子种的，两千多年了。我还在想，孔子到底什么样？一米九的大个子，祖上是扛城门的武士，搁现在，是打篮球的身高。你以为的文弱书生形象，对不上号的。他老爸能手托城门，他能驾车能射箭，六艺精通。这种体格加这种学问，在当时确实是独一份。"

- **周游列国**
  - 前497年（55岁）开始，前484年（68岁）回鲁国，前后14年。
  - 去了：卫、曹、宋、郑、陈、蔡、楚……辗转了七八个国家。
  - 最惨的时候在陈蔡之间绝粮，弟子们饿得爬不起来。子路问"君子亦有穷乎？"孔子答"君子固穷，小人穷斯滥矣。"
  - 【数字】周游14年，走过7-8个国家
  - 【史料】《史记·孔子世家》《论语·卫灵公》
  - 【切入点】"55岁出发，68岁回来，走了14年。在陈蔡之间断粮那回，弟子们饿得站不起来，子路都开始发牢骚了——'君子也有这么惨的时候？'孔子说'君子固穷，小人穷斯滥矣'——君子穷了还守着底线，小人穷了就什么都干了。这句话我觉得不是鸡汤，是真话。你看他后半辈子都在碰壁，但始终没改弦更张。你可以说他轴，但你不能说他怂。"

- **《论语》不是孔子写的**
  - 《论语》是孔子死后，弟子们根据记忆整理的语录。
  - 《论语》的编者有争议，一说是曾子的弟子编的（因为书中曾子称"子"，且有较多曾子的语录）。
  - 成书时间约在战国初期。
  - 【切入点】"《论语》不是孔子写的，是学生记的笔记整理的。孔子'述而不作'，自己不写书，只讲。讲完了学生记下来，他死后学生们整理。所以你看《论语》里各种'子曰'，不同的人记的，记的时候场景也不一样。这就像你上课记的笔记，跟同学记的笔记肯定不一样。所以《论语》里有些地方前后矛盾，正常——不是孔子自相矛盾，是不同学生记的不同场合的话。"

## 二、老子与《道德经》

### 1. 基本信息
- 老子，姓李名耳，字聃，约前571年-约前471年
- 楚国苦县（今河南鹿邑）人
- 做过周朝的"守藏室之史"——相当于国家图书馆馆长

### 2. 具体可写细节
- **老子出关**
  - 《史记·老子韩非列传》："居周久之，见周之衰，乃遂去。至关，关令尹喜曰：'子将隐矣，强为我著书。'于是老子乃著书上下篇，言道德之意五千余言而去，莫知其所终。"
  - 老子骑青牛出函谷关，关令尹喜拦住他，说你得留点东西再走。老子就写了《道德经》5000字，写完走了，没人知道他去了哪。
  - 【数字】《道德经》5000余字
  - 【史料】《史记·老子韩非列传》
  - 【切入点】"老子出关这个故事我特别喜欢。一个图书馆馆长，看周朝不行了，辞职骑牛走人。走到函谷关被关长拦住，说你得写本书再走。老头子5000字一挥而就，写完扬长而去，再无音讯。你说帅不帅？比后来那些写了几百万字还要蹭热度的文人潇洒多了。5000字，影响了中国两千多年。"

### 3. 《道德经》的金句
- "道可道，非常道。名可名，非常名。"
- "上善若水。水善利万物而不争。"
- "天下莫柔弱于水，而攻坚强者莫之能胜。"
- "祸兮福之所倚，福兮祸之所伏。"
- "千里之行，始于足下。"
- "治大国若烹小鲜。"
- 【切入点】"'治大国若烹小鲜'——别老翻动。煎小鱼的时候你老翻它，就碎了。治理国家也一样，别老折腾。这道理今天也适用。"

## 三、诸子百家速查

| 学派 | 代表人物 | 核心主张 |
|------|---------|---------|
| 儒家 | 孔子、孟子、荀子 | 仁、礼、义 |
| 道家 | 老子、庄子 | 无为、自然 |
| 法家 | 韩非子、商鞅 | 法、术、势 |
| 墨家 | 墨子 | 兼爱、非攻、节用 |
| 兵家 | 孙武、孙膑 | 兵者，国之大事 |
| 纵横家 | 鬼谷子、苏秦、张仪 | 合纵连横 |
| 名家 | 公孙龙 | 白马非马 |
| 阴阳家 | 邹衍 | 五德终始 |

### 速查要点
- **商鞅变法**：前356年+前350年两次变法。废井田开阡陌、重农抑商、奖励军功、连坐法、统一度量衡。结果：秦国从二流变一流。代价：商鞅自己被车裂。
- **孟子**：约前372年-前289年。"民为贵，社稷次之，君为轻。"——朱元璋看了这句话，把孟子从孔庙里踢出去了。
- **韩非子**：约前280年-前233年。法家集大成者，被李斯害死。嬴政看了他的文章说"寡人得见此人与之游，死不恨矣"——我要是能见到这个人，死了都值。
- **鬼谷子**：据说教了苏秦张仪孙膑庞涓四个徒弟。苏秦张仪搞外交，孙膑庞涓搞军事。这四个人的故事几乎撑起了战国一半的戏份。
- 【史料】《史记·商君列传》《史记·孟子荀卿列传》《史记·老子韩非列传》《鬼谷子》（真伪有争议）
- 【切入点】"诸子百家最让我感慨的是：他们吵了三百年，最后赢的是法家。秦灭六国靠的就是法家那一套。但秦朝15年就亡了，法家的严刑峻法管用但不得人心。后来汉朝学乖了，'外儒内法'——嘴上说儒家，实际干的还是法家。这个模式从此统治了中国两千年。"
