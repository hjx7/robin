# AI 生图技巧与参数详解（完全零基础也能看懂）

> 如果你从没用过 AI 画图工具，看这篇就够了。
> 我会先用**大白话**讲清楚每个词是什么，再给你**能直接抄去出图**的模板，最后才展开细节。
> 本文以 Stable Diffusion（SD 1.5）为例，但思路适用于几乎所有 AI 画图工具。

---

## 一、先搞懂：AI 到底是怎么画图的？

你可能会以为 AI 是「像人一样一笔一笔画」的。其实不是。

AI 画图的过程更像这样：

> 电脑先生成一张**满屏雪花点的电视噪点图**，然后像「慢慢擦掉雾气」一样，一点一点把噪点擦掉，最后露出一张清楚的画。

而**你的提示词（那段文字）**，就是告诉它：「往『猫』的方向擦、往『动漫风』的方向擦」。

所以你调的所有参数，归根结底只管两件事：
1. **擦多少步才停**（对应「步数」）
2. **往你写的文字那个方向擦**（对应「提示词」「引导强度」）

记住这个「擦雾气」的画面，后面所有参数都好理解了。

---

## 二、两种最基本的画法

| 说法 | 大白话 | 你给它什么 | 它吐出什么 |
| :--- | :--- | :--- | :--- |
| **文生图**（txt2img） | 凭空画 | 一段文字 | 一张全新的图 |
| **图生图**（img2img） | 改图 | 一张图 + 一段文字 | 改过的图 |

**怎么选？**
- 脑子里有个画面、想从零画出来 → 用**文生图**
- 已经有张图、想换个风格/换身衣服 → 用**图生图**

---

## 三、提示词：你写给 AI 的「画画要求」

### 3.1 正向提示词 = 「我要画什么」

就是一段描述。但 AI（尤其是 SD 1.5）只懂**英文**，而且它不是看「句子通不通顺」，是看**一个个关键词**。

所以别写：「请画一只可爱的猫坐在椅子上」。
要写：「cat, sitting on chair, cute, anime style, best quality」（用**逗号**隔开关键词）。

**最简单的写法公式**（照抄填空就行）：

```
[画什么] , [什么风格] , [长什么样/什么细节] , [什么光线] , [画质好]
```

举例：
```
a cat, anime style, big eyes, soft fur, warm light, masterpiece, best quality
```
（一只猫，动漫风，大眼睛，软毛，暖光，杰作级画质）

### 3.2 反向提示词 = 「千万别画什么」

这个特别重要，几乎每次都要写。因为 AI 很容易画出丑东西（多手多脚、模糊、水印）。

你只要写一句「通用避雷词」，以后每次都粘上：

```
low quality, lowres, worst quality, bad anatomy, bad hands, extra fingers, blurry, watermark, text
```
（低质量、模糊、畸形、手画坏、多手指、带水印、带文字——统统不要）

### 3.3 新手直接照抄的提示词模板

**想画二次元角色**：
```
1girl, anime style, silver hair, blue eyes, smile, cherry blossoms background, masterpiece, best quality
```

**想画写实照片**：
```
photorealistic, a man in coffee shop, natural lighting, detailed skin, 8k, highly detailed
```

**想画像素游戏素材**：
```
pixel art, game item, golden sword, isolated on white, 16-bit retro style
```

> 把里面你不想要的词换掉就行。写英文怕麻烦？用翻译软件翻成英文再粘进去。

## 四、文生图的几个旋钮（每个都用比喻讲）

在界面里点「文生图」后，你会看到一堆数字框。下面一个个说，全都用生活比喻。

### 4.1 步数（Steps / num_inference_steps）——「擦几遍雾气」

比喻：擦雾气擦 5 下和擦 30 下，当然是擦得多更清楚。但擦到 30 下之后，再擦也看不出差别了，还费时间。

| 步数 | 实际感觉 |
| :--- | :--- |
| 10-15 | 快，但偏糊 |
| **20-30** | ✅ 刚刚好，清楚又不慢 |
| 40+ | 几乎没更好，白白等 |

**新手建议：填 25。**

### 4.2 引导强度（CFG Scale / guidance_scale）——「听不听你的话」

比喻：你让 AI 画「猫」，这个值就是「它有多听你的」。
- 值太小（比如 2）：AI 自由发挥，可能画出狗，或者不搭界的
- 值太大（比如 20）：AI 死板照做，画出来很假、很生硬
- **中间（7-9）**：既听话，又自然

**新手建议：填 7.5。**

### 4.3 尺寸（Width / Height）——「画布多大」

SD 1.5 这个模型是在 **512×512** 的小图上「学画画」的，所以它最擅长画 512。

| 你设的尺寸 | 结果 |
| :--- | :--- |
| 512×512 | ✅ 最稳，构图正常 |
| 512×768（竖） / 768×512（横） | 可以 |
| 1024×1024 这种大图 | ❌ 容易画出两个头、重复的身体 |

> 想放大图？先画 512 的，再用「放大功能」把图变清晰，别直接把画布拉大。
> 另外宽度高度都必须是 **8 的倍数**（512、768 都行，511 不行）。

**新手建议：512×512。**

### 4.4 随机种子（Seed）——「从哪团噪点开始」

比喻：每次画图，AI 起点是不同的「雪花噪点」。种子就是「指定用哪一团噪点开头」。

- **不固定种子**：每次都不一样（适合「随便出一批挑喜欢的」）
- **固定种子**（比如填 42）：同样设置每次出完全一样的图（适合「挑中一张后慢慢改」）

**新手工作流**：先不固定种子，一次出 4-8 张 → 挑一张最顺眼的 → 把它的种子固定住 → 再微调文字精修。

## 五、图生图多出来的关键旋钮：重绘强度（strength）

图生图比文生图多一个最重要的滑块：**重绘强度（strength）**。

比喻：你给 AI 一张照片说「改改」，这个滑块管「改多大动干戈」。

| 强度 | 意思 | 什么时候用 |
| :--- | :--- | :--- |
| 0.2 | 几乎不动，只修修小瑕疵 | 去个水印、调一点点色 |
| **0.5** | ✅ 中等改动，风格大变但人还在 | **照片转动漫、换风格** |
| 0.8 | 大改，只留个大概轮廓 | 换姿势、换服装 |
| 1.0 | 完全重画，原图当摆设 | 基本等于文生图 |

**新手建议：想要「换成别的风格但还是原来那东西」，填 0.5~0.6。**

> 坑提醒：如果你给的原图带透明背景（比如 PNG 抠好的图），AI 处理不了透明，会画出发白。把背景填成白色再喂给它就行。

---

## 六、采样器（Sampler）——「用哪套擦雾气手法」

这就是「步数」里每一步具体怎么擦。不同手法速度和质量不同。

| 采样器 | 速度 | 质量 | 新手怎么选 |
| :--- | :--- | :--- | :--- |
| **UniPC** | 快 | 够好 | ✅ 你的电脑没独显（Intel CPU）就选它 |
| **DPM++ 2M Karras** | 慢 | 最好 | 有显卡、不嫌等，选它 |
| **DDIM** | 中 | 好 | 想结果稳定可复现选它 |
| Euler | 快 | 一般 | 随便试试 |

**新手建议：没独显就选 UniPC，25 步足够。**

---

## 七、ControlNet：让 AI「照着姿势画」

有时候光写文字，AI 把人画得歪七扭八。ControlNet 就是给你一个「骨架参考」：

> 你上传一张人像 → AI 先把人的姿势（骨骼）提取出来 → 再照这个姿势画新图。

不只是姿势，还能控制：
- **姿势**（OpenPose）：指定动作
- **轮廓**（Canny）：照着线稿/实物边缘画
- **深度**（Depth）：保持远近层次
- **线稿**（Lineart）：给线稿上色

一句话：**提示词管「长相风格」，ControlNet 管「姿势构图」，两个一起用不冲突。**

---

## 八、照着做：从零出一张好图的 9 步

1. 选**文生图**（从零画）还是**图生图**（改图）
2. 正向提示词：套第三节的模板，换成你想要的内容
3. 反向提示词：把「通用避雷词」粘上去
4. 步数填 **25**
5. 引导强度填 **7.5**
6. 尺寸填 **512×512**
7. 采样器选 **UniPC**
8. 种子先不固定，一次出 **4-8 张**
9. 挑一张喜欢的 → 固定它的种子 → 微调文字再出

## 九、画丑了？对着表改

| 你看到的毛病 | 大概率原因 | 怎么改 |
| :--- | :--- | :--- |
| 多手多脚 | 没写避雷词 / 步数太低 | 反向词加 `extra fingers`，步数提到 30 |
| 脸歪嘴斜 | 图太大、脸太小 | 尺寸回到 512，提示词加 `detailed face` |
| 整张糊 | 步数低 / 引导强度太低 | 步数 25+，引导强度 7+ |
| 颜色假、塑料感 | 引导强度太高 | 降到 7-9 |
| 画的和写的不搭边 | 引导强度太低 / 词矛盾 | 引导强度 8，删掉矛盾词 |
| 图生图发白 | 原图透明背景 | 填白底再喂 |
| 图生图太像原图 | 重绘强度太低 | 提到 0.7 |
| 图生图完全不像 | 重绘强度太高 | 降到 0.5 |

## 十、一张表记住所有参数

| 参数 | 大白话 | 新手填多少 |
| :--- | :--- | :--- |
| 提示词 prompt | 我要画什么 | 套模板写 |
| 反向提示词 negative | 别画什么 | 粘通用避雷词 |
| 步数 steps | 擦几遍雾 | 25 |
| 引导强度 CFG | 听不听话 | 7.5 |
| 尺寸 size | 画布多大 | 512×512 |
| 种子 seed | 从哪团噪点开始 | 先随机，挑中再固定 |
| 重绘强度 strength（仅图生图） | 改多大动干戈 | 0.5 |
| 采样器 sampler | 擦雾手法 | UniPC（没独显） |

---

## 十一、小结

AI 画图一点都不玄学，就是几个旋钮：

- **提示词**决定画什么、**反向词**决定不画什么
- **步数**管精细、**引导强度**管听不听话
- **尺寸**锁 512、**种子**管能不能复现
- **重绘强度**是图生图的灵魂（改多少）
- **采样器**选 UniPC 最稳

心法就一句：**先随机出一批挑喜欢的，固定种子再精修。** 去画吧 🎨
